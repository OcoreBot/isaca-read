# Security & Audit Digest — 2026-08-18

## Top items

### 1. China-nexus actor exploits VMware vCenter RCE, deploys Babuk-derived ransomware
**Why it matters for audit/CISO/VAPT:** A suspected nation-state actor weaponized a critical vCenter flaw within days of the patch — a textbook case for testing patch-velocity controls on virtualization infrastructure, which underpins most enterprise environments.
Researchers attribute exploitation of CVE-2026-59310 (CVSS 9.8), a severe directory-traversal flaw in Broadcom VMware vCenter, to a China-nexus APT deploying Babuk-derived ransomware. A patch is available; unpatched instances should be treated as compromised. ([source](https://thehackernews.com/2026/08/suspected-china-nexus-actor-exploits.html))

### 2. Unisoc VoLTE exploit chain gives attackers full Android kernel access
**Why it matters for audit/CISO/VAPT:** No fix is currently available from the chipset maker, so this is a live, unmitigated risk for any Android fleet using Unisoc modems — a priority item for mobile device inventories and VAPT scoping.
SSD Secure Disclosure published a two-stage exploit chain achieving full kernel access via a VoLTE video call on Unisoc modem firmware, affecting a wide range of Android devices. ([source](https://thehackernews.com/2026/08/unisoc-volte-video-call-exploit-chain.html))

### 3. Critical GitLab GraphQL flaw allows unauthenticated deletion of public projects
**Why it matters for audit/CISO/VAPT:** Affects both self-hosted and SaaS deployments and threatens source-code availability and CI/CD integrity — auditors should confirm patched versions are in place before the next code-freeze window.
GitLab shipped updates for a critical GraphQL vulnerability in CE and EE that, under certain conditions, let unauthenticated attackers remotely modify or delete public projects and user data. ([source](https://thehackernews.com/2026/08/critical-gitlab-graphql-flaw-could-let.html))

### 4. Certighost: AD Certificate Authority flaw lets a standard user become Domain Controller
**Why it matters for audit/CISO/VAPT:** Illustrates standing-privilege risk in PKI infrastructure that's often excluded from Tier 0 reviews — a strong prompt for auditors to add CA delegation and Certificate Enrollment Agent roles to identity audits.
CVE-2026-54121 lets a standard domain user escalate an Enterprise CA into a Domain Controller by abusing implicit trust in certificate infrastructure. A patch exists, but the underlying design issue calls for a policy-level review of CA privilege delegation. ([source](https://www.bleepingcomputer.com/news/security/certighost-and-the-privilege-hiding-in-your-certificate-authority/))

### 5. Snowflake GitHub Actions workflow injection via crafted issues
**Why it matters for audit/CISO/VAPT:** A supply-chain flaw in a major data-platform vendor's CI/CD pipeline, exploitable through something as ordinary as a GitHub issue — a useful test case for reviewing Actions workflow permissions and approval gates.
Wiz disclosed a workflow-injection vulnerability in Snowflake's public snowflake-connector-net repository, where a crafted GitHub issue can trigger command execution in an insufficiently sanitized workflow. ([source](https://thehackernews.com/2026/08/snowflake-github-actions-flaw-lets_0330881554.html))

### 6. French tax authority (DGFiP) breach exposes 678,000 individuals
**Why it matters for audit/CISO/VAPT:** A government financial-data breach at this scale is a benchmark case for control-failure lessons and regulatory notification timelines in the public sector.
The French Ministry of the Economy and Finance disclosed that an attacker accessed DGFiP systems and stole personal data belonging to 678,000 individuals. ([source](https://www.bleepingcomputer.com/news/security/french-tax-authority-data-breach-affects-678-000-individuals/))

### 7. Forminator WordPress plugin RCE risks 600,000+ sites
**Why it matters for audit/CISO/VAPT:** A high-severity, unauthenticated RCE in a widely installed plugin is a common initial-access path — worth adding to external attack-surface scans immediately.
CVE-2026-15748 (CVSS 9.8) in the Forminator Forms plugin allows unauthenticated attackers to achieve arbitrary code execution via malicious PHP uploads. ([source](https://thehackernews.com/2026/08/forminator-wordpress-flaw-can-enable.html))

### 8. Ray-Project code injection flaw added to CISA KEV catalog
**Why it matters for audit/CISO/VAPT:** Federal agencies face a remediation deadline of 2026-08-20; any organization running Ray should treat this as a compliance-tracking priority alongside the technical fix.
CISA added CVE-2025-62593, a code injection vulnerability in Ray-Project Ray, to its Known Exploited Vulnerabilities catalog based on evidence of active exploitation. ([source](https://www.cisa.gov/news-events/alerts/2026/08/17/cisa-adds-one-known-exploited-vulnerability-catalog))
