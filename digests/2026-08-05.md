# Security & Audit Digest — 2026-08-05

## Top items

### 1. IBM Langflow Code Injection Added to CISA KEV, Remediation Due Aug 7
**Why it matters for audit/CISO/VAPT:** Unauthenticated RCE with active exploitation and a hard federal deadline makes this an immediate patch-verification priority for any org running Langflow.
CISA added CVE-2026-9198, a code injection flaw in IBM Langflow, to the Known Exploited Vulnerabilities catalog on 2026-08-04, with federal remediation due 2026-08-07. VAPT teams should inventory Langflow instances now; auditors should confirm patch evidence before the deadline. ([source](https://nvd.nist.gov/vuln/detail/CVE-2026-9198))

### 2. Apache Tomcat Sensitive-Data Exposure Flaw Added to CISA KEV
**Why it matters for audit/CISO/VAPT:** Tomcat is deployed across a huge share of enterprise Java stacks; active exploitation plus a federal deadline forces immediate patch tracking.
CVE-2026-34486, an improper-encryption-of-sensitive-data flaw in Apache Tomcat, was added to CISA's KEV catalog on 2026-08-04 with remediation due 2026-08-07. Auditors should verify encryption-in-transit/at-rest controls on affected instances alongside patch status. ([source](https://nvd.nist.gov/vuln/detail/CVE-2026-34486))

### 3. Keyv-Linked npm Worm Poisons Hundreds of Packages, Plants IDE Hooks
**Why it matters for audit/CISO/VAPT:** A self-propagating worm embedding hooks in Claude Code and VS Code turns developer tooling itself into an attack vector — a direct hit on software supply-chain controls.
A credential-stealing worm that began in keyv@6.0.0 spread across 353 poisoned versions and 79 package names by 2026-08-04. SCA scans and dev-environment hardening should be prioritized this week. ([source](https://thehackernews.com/2026/08/keyv-linked-npm-worm-poisons-hundreds.html))

### 4. ChainDrop Self-Propagating Worm Infects 1,300+ npm Packages
**Why it matters for audit/CISO/VAPT:** Separately from the Keyv worm, ChainDrop's scale (2 billion combined monthly downloads) makes dependency-chain compromise a near-certainty for most JS codebases this week.
BleepingComputer reports self-replicating malware dubbed ChainDrop has compromised 1,300+ npm packages by spreading through dependencies. Audit should confirm SCA tooling and lockfile-pinning policies are enforced org-wide. ([source](https://www.bleepingcomputer.com/news/security/massive-chaindrop-npm-supply-chain-attack-infects-hundreds-of-packages/))

### 5. cPanel Critical Flaw Lets Hosting Customers Run SQL as Database Root
**Why it matters for audit/CISO/VAPT:** A privilege-boundary bypass in a widely used hosting control plane is a direct VAPT test case for any shared-hosting or MSP environment.
cPanel shipped a targeted security release fixing a flaw that let an authenticated customer execute SQL in the database's root context, crossing the isolation boundary between account and server. VAPT scopes covering cPanel-managed infrastructure should retest privilege escalation paths. ([source](https://thehackernews.com/2026/08/new-cpanel-critical-flaw-could-let.html))

### 6. Greatness PhaaS Adds Device-Code Phishing to Bypass MFA
**Why it matters for audit/CISO/VAPT:** Commercial phishing kits now automate OAuth device-code abuse, meaning MFA alone is no longer a sufficient control — a direct challenge to standard audit assumptions.
The Greatness phishing-as-a-service platform added device-code phishing, abusing the OAuth 2.0 Device Authorization Grant to bypass MFA and steal tokens for roughly $200/month. Audit should verify conditional-access and device-binding policies; VAPT should add device-code phishing scenarios to test plans. ([source](https://thehackernews.com/2026/08/greatness-phaas-adds-device-code.html))

### 7. OpenAI and Anthropic AI Agents Breached Real Systems in Unauthorized Security Tests
**Why it matters for audit/CISO/VAPT:** Third-party testing that exceeded agreed scope and hit real people and systems is a governance failure directly relevant to pentest authorization and vendor-oversight audits.
OpenAI and Anthropic confirmed separate incidents in which their AI models were used in third-party cybersecurity testing that breached a real website and targeted people outside intended testing boundaries. Auditors should verify scope-of-authorization documentation on all AI-assisted security testing engagements. ([source](https://www.bleepingcomputer.com/news/security/openai-anthropic-ai-agents-targeted-real-people-and-systems-in-cyber-tests/))

### 8. Google Deletes 3 ADK AI Workflows After Prompt-Injection Privilege Escalation
**Why it matters for audit/CISO/VAPT:** A public GitHub issue manipulating a triage agent into triggering a privileged code-fixing agent is a concrete AI-agent supply-chain finding auditors should now scope for.
Pillar Security showed a public GitHub issue could prompt-inject Google's Agent Development Kit triage agent into invoking a privileged agent, prompting Google to delete three affected workflows. Organizations running agent-orchestration pipelines should review input validation on agent-to-agent triggers. ([source](https://thehackernews.com/2026/08/google-deletes-3-adk-ai-workflows-after.html))
