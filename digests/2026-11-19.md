# Security & Audit Digest — 2026-11-19

## Top items

### 1. CISA adds four exploited flaws to KEV: REDCap, Apache Axis, LiteLLM, Synology DSM
**Why it matters for audit/CISO/VAPT:** Federal due date for three of them is 2026-11-21, so these are the most time-critical patch items today. Check REDCap hosts and any LiteLLM instance in front of AI workloads.
CISA added CVE-2026-90817 (REDCap code injection), CVE-2026-90436 (Apache Axis unsafe reflection), CVE-2026-40217 (LiteLLM unprotected alternate channel) and CVE-2024-10441 (Synology DSM output encoding). LiteLLM is due 2026-12-02. ([source](https://www.cisa.gov/news-events/alerts/2026/11/18/cisa-adds-four-known-exploited-vulnerabilities-catalog))

### 2. NGINX "nginx2root" HTTP/2 flaw (CVE-2026-123007) allows unauthenticated code execution
**Why it matters for audit/CISO/VAPT:** Internet-facing NGINX is easy to miss in asset inventories. Confirm versions and add NGINX to external test scope.
The flaw has been in NGINX since version 1.9.5 and needs only HTTP/2 enabled. Rapid7 published a PoC that works against containerized NGINX, and researchers chained it with a kernel privilege-escalation flaw to reach root. Patch first. Disabling HTTP/2 is a temporary stopgap. ([source](https://thehackernews.com/2026/11/10-year-old-nginx-http2-flaw-lets.html))

### 3. Apache Roller critical RCE under active exploitation
**Why it matters for audit/CISO/VAPT:** No authentication is needed and attacks are already happening, so this is a short-SLA patch. Look for Roller blogs on internet-facing hosts.
Apache released fixes for CVE-2026-129448 (CVSS 9.8), an unauthenticated RCE that attackers are using to run code on vulnerable servers. ([source](https://www.bleepingcomputer.com/news/security/apache-warns-of-roller-rce-vulnerability-exploited-in-attacks/))

### 4. PHP warns of critical flaws in all supported versions; fixes due today
**Why it matters for audit/CISO/VAPT:** PHP sits under many web apps. Plan the patch window and test capacity now.
Maintainers announced a security release for 2026-11-19, between 14:00 and 14:30 UTC. Details were not public when the advisory was issued. ([source](https://thehackernews.com/2026/11/php-warns-of-critical-security-flaws.html))

### 5. Amazon: AI agents are hunting LiteLLM, Dify and One API for stored provider keys
**Why it matters for audit/CISO/VAPT:** Stolen AI provider keys mean direct cost and data exposure. Review gateway exposure, key storage and rotation.
Amazon's decoy servers recorded attacker AI agents probing internet-exposed AI apps for API keys. SANS also saw scans for LiteLLM/Starlette CVE-2026-42271 and CVE-2026-48710 on 2026-11-16. ([source](https://thehackernews.com/2026/11/amazon-uncovers-ai-agent-campaign.html))

### 6. N-able patches 17 N-central flaws after attackers deployed crypto miners
**Why it matters for audit/CISO/VAPT:** RMM platforms have admin reach across client endpoints. Check hotfix status and look for miner indicators.
N-central 2026.4 Hotfix 3 is a critical update. Attackers had already exploited earlier bugs in the platform. ([source](https://thehackernews.com/2026/11/n-able-patches-17-n-central-flaws-as.html))

### 7. F5 warns of six critical BIG-IP flaws that can crash TMM
**Why it matters for audit/CISO/VAPT:** Load balancers are high-impact perimeter and availability assets. Check which configurations make each flaw exploitable before setting urgency.
Unauthenticated attackers can crash the Traffic Management Microkernel. Each flaw needs a specific setup, such as a particular iRule command or APM configuration. Some may allow RCE. ([source](https://thehackernews.com/2026/11/f5-warns-6-critical-big-ip-flaws-can.html))

### 8. Flash-chip attack bypasses TPM lockout to crack Windows Hello and BitLocker PINs
**Why it matters for audit/CISO/VAPT:** It weakens the assumption behind PIN-based disk encryption. Revisit PIN policy for high-risk laptops.
TU Berlin researchers say that on AMD and some Intel PCs, someone with physical access can reset the TPM lockout and guess short PINs in days. ([source](https://thehackernews.com/2026/11/flash-chip-attack-bypasses-tpm-lockout.html))

### 9. Google: attackers use autonomous AI agents to build exploits from patches
**Why it matters for audit/CISO/VAPT:** A shorter gap between patch and exploit supports tighter SLAs for internet-facing systems.
Google describes frameworks such as ARTEX, CAIRN, CyberStrikeAI and PentAGI running multi-stage intrusions. ([source](https://thehackernews.com/2026/11/google-finds-hackers-using-ai-agents-to.html))
