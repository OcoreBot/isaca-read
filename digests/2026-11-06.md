# Security & Audit Digest — 2026-11-06

## Top items

### 1. Zyxel GS1900 patch fails to block the zero-day exploit (CVE-2026-107441)
**Why it matters for audit/CISO/VAPT:** "Patched" is not enough evidence for these switches. Verify the exact build and management-interface exposure, and treat stored switch credentials as exposed.
Binarly found that GS1900 switches running Zyxel's earlier fix are still open to the exploit used in the attacks. Anyone who can reach the web management interface can run commands without logging in. SANS says Zyxel recommends the 2.90 Patch 3 builds. ([source](https://thehackernews.com/2026/11/zyxel-gs1900-patch-fails-to-block-zero.html))

### 2. OpenSSH "sshole": oversized password bypasses auth on Alpine/musl systems (CVE-2026-123158)
**Why it matters for audit/CISO/VAPT:** Accounts that are meant to be key-only can be logged into. Check musl-based hosts (Alpine, OpenWrt) and add this to SSH test scope.
A password of 257 to 1,024 bytes lets an attacker log in to accounts with no password set on some musl-based systems without libpam. The attacker needs network access and an account name. SANS reports the fix is OpenSSH 10.6p2. ([source](https://thehackernews.com/2026/11/openssh-issues-emergency-fix-for-flaw.html))

### 3. CISA adds WordPress core race condition (CVE-2026-119977) to KEV
**Why it matters for audit/CISO/VAPT:** The federal due date is today (2026-11-06). Check WordPress core versions across the estate and track any overdue KEV items.
The high-severity (CVSS 8.1) time-of-check/time-of-use flaw is being exploited during software upgrades. ([source](https://www.cisa.gov/news-events/alerts/2026/11/03/cisa-adds-one-known-exploited-vulnerability-catalog))

### 4. cPGuard update channel hijacked to backdoor Linux servers
**Why it matters for audit/CISO/VAPT:** A security tool's own update path was the supply-chain vector. Inventory cPGuard, hunt for the backdoor, and rotate credentials on affected hosts.
An attacker broke into cPGuard's update system on November 2 and pushed a script that installed a backdoor and collected password hashes and other sensitive files. ([source](https://thehackernews.com/2026/11/cpguard-update-channel-hijacked-to.html))

### 5. FBI and CISA warn of attacks on industrial refrigeration and cold-chain systems
**Why it matters for audit/CISO/VAPT:** Scope OT for food, healthcare and logistics clients. Check remote management exposure and default credentials on refrigeration controllers.
CISA, FBI, HHS, USDA and DoT urge hardening after active targeting worldwide. Related incidents include remote setpoint changes at European supermarkets and a cyberattack that raised temperatures at three French blood-service sites. ([source](https://www.cisa.gov/resources-tools/resources/us-government-partners-urge-hardening-industrial-refrigeration-and-cold-chain-monitoring-systems))

### 6. Synology NAS devices hit by ransomware via a December 2024 DSM flaw
**Why it matters for audit/CISO/VAPT:** A flaw left unpatched for nearly two years is a patch-SLA failure. Check DSM builds and backup isolation for NAS-held data.
Synology says attackers are exploiting the already-patched DSM vulnerability to deliver ransomware and urges customers to update. ([source](https://thehackernews.com/2026/11/synology-nas-devices-targeted-in.html))

### 7. Siemens SIMATIC IoT2050 CVSS 10.0 flaw exploited (CVE-2026-58115)
**Why it matters for audit/CISO/VAPT:** Missing authentication on a critical function in an edge device. Confirm whether any units are internet- or IT-reachable.
VulnCheck reports active exploitation to plant remote command backdoors on IoT2050 Advanced devices. ([source](https://thehackernews.com/2026/11/attackers-exploit-critical-siemens.html))

### 8. Red Hat patches 9.8-rated Linux kernel TCP use-after-free RCE
**Why it matters for audit/CISO/VAPT:** Ubuntu hosts stay exposed until the regular fix ships, so record a compensating control or accepted risk.
Fixed kernels are out for RHEL 8, 9 and 10. Ubuntu's fixes for its three newest LTS releases are only in the opt-in testing channel, with no date for regular release. ([source](https://thehackernews.com/2026/11/red-hat-patches-98-rated-linux-tcp-rce.html))
