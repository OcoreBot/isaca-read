# Security & Audit Digest — 2026-11-13

## Top items

### 1. N-able N-central zero-days exploited in the wild
**Why it matters for audit/CISO/VAPT:** RMM platforms give broad reach into MSP customer estates. Inventory N-central instances and run a compromise assessment on exposed servers.
Attackers are exploiting the 4EverAble2Shell and Agent2Shell flaws and have infected at least 21 servers, 19 of them on Hotfix 2. N-able is restricting some features and integrations. Hosted N-central was taken offline on 2026-11-10 after a researcher disclosed dozens of flaws with PoCs. Stormcast reports public exploit code on GitHub (unverified). ([source](https://thehackernews.com/2026/11/hackers-exploit-n-central-flaws-to.html))

### 2. ScreenConnect rogue-client campaign hits MSPs (SCKit)
**Why it matters for audit/CISO/VAPT:** Third-party remote-access tooling is a supply-chain path into client networks. Check ScreenConnect version, plugin inventory and MSP-side access logs.
At least 288 endpoints across 48 organisations received rogue ScreenConnect clients through compromised MSP environments. ConnectWise disabled five third-party extensions. The worm-like SCKit toolkit targets MSP technicians' machines. Stormcast advises updating to 26.6.5. ([source](https://thehackernews.com/2026/11/screenconnect-attacks-target-at-least.html))

### 3. CISA KEV additions: Barracuda ESG, Cisco BroadWorks, Outlook, Chromium
**Why it matters for audit/CISO/VAPT:** These are hard federal deadlines and a ready patch-verification checklist. The two Barracuda entries are due today.
On 2026-11-10 CISA added six exploited flaws, including Barracuda ESG CVE-2026-116606 and CVE-2026-111560 (due 2026-11-13), Cisco BroadWorks CVE-2026-20320, Outlook CVE-2026-124194 and Chromium CVE-2026-125350 (all due 2026-11-24). ([source](https://www.cisa.gov/news-events/alerts/2026/11/10/cisa-adds-six-known-exploited-vulnerabilities-catalog))

### 4. Critical Apache HTTP Server mod_http2 RCE (CVE-2026-119618)
**Why it matters for audit/CISO/VAPT:** This is an unauthenticated RCE on the internet-facing web tier. VAPT should confirm version and HTTP/2 status on external hosts.
It affects Apache 2.4.55–2.4.70 with HTTP/2 enabled. It is fixed in 2.4.71, released 2026-11-11. ([source](https://thehackernews.com/2026/11/critical-apache-http2-flaw-could-let.html))

### 5. Microsoft November Patch Tuesday: exploited Outlook zero-day
**Why it matters for audit/CISO/VAPT:** Patch volume this large forces risk-based prioritisation. Install failures and SQL Server regressions affect patch-compliance evidence.
Microsoft fixed roughly 1,100–1,260 flaws (counts differ by outlet), including Outlook CVE-2026-124194, which may expose NTLMv2 hashes and is in KEV. BleepingComputer reports Windows 11 install failures (KB5132061) and SQL Server performance issues after recent updates. ([source](https://krebsonsecurity.com/2026/11/microsoft-fixes-nearly-1100-security-vulnerabilities/))

### 6. 4,837 hijacked GitHub accounts used to plant CI secret stealer
**Why it matters for audit/CISO/VAPT:** CI/CD secrets and account-takeover hygiene are direct control points: token rotation, MFA, OIDC-scoped credentials.
Stolen credentials were used to push secret-stealing code into 1,806+ repositories writable by those accounts, targeting CI secrets and cloud credentials. ([source](https://thehackernews.com/2026/11/4837-hijacked-github-accounts-ran-ci.html))

### 7. Critical Red Hat Quay flaw exposes private container images
**Why it matters for audit/CISO/VAPT:** Registry integrity underpins container supply-chain trust. Check the anonymous-access setting and image verification.
An attacker with network access can read and overwrite private images in all repositories. Anonymous access is on by default, so no account is needed. ([source](https://thehackernews.com/2026/11/critical-red-hat-quay-flaw-lets.html))

### 8. Xen Orchestra auth bypass exploited for admin access
**Why it matters for audit/CISO/VAPT:** Compromising the hypervisor management plane gives tenant-wide control. Test management interfaces and confirm patch level.
Vates warned that a critical REST cookie-parsing auth bypass is being exploited in the wild. No CVE has been assigned yet. ([source](https://thehackernews.com/2026/11/hackers-exploit-critical-xen-orchestra.html))

### 9. Railway breach: stolen customer AI keys cause ~$740,000 in charges
**Why it matters for audit/CISO/VAPT:** Third-party secret storage and the lack of API-key spend caps and monitoring are a practical control gap.
AI provider keys stored on Railway were stolen in an October breach and used for an estimated $740,000 of unauthorised spend. Railway says it will cover charges where providers won't refund. ([source](https://thehackernews.com/2026/11/railway-says-stolen-customer-ai-keys.html))
