# Security & Audit Digest — 2026-09-23

## Top items

### 1. CISA Adds Four Actively Exploited Vulnerabilities to KEV Catalog
**Why it matters for audit/CISO/VAPT:** Four new binding federal remediation deadlines in one day, spanning perimeter, SD-WAN, and load-balancing infrastructure — a concentrated vulnerability-management audit control point.
CISA added Check Point's CVE-2026-93616 (path traversal, unauthenticated script execution) and CVE-2026-85102 (certificate validation bypass), Arista VeloCloud Orchestrator's CVE-2026-93952 (CVSS 10.0, unauthenticated privilege escalation), and F5 BIG-IP APM's CVE-2026-94127 (heap overflow) to KEV on 2026-09-22, all under active exploitation. Federal remediation is due 2026-09-25. ([source](https://www.cisa.gov/news-events/alerts/2026/09/22/cisa-adds-four-known-exploited-vulnerabilities-catalog))

### 2. WordPress Patches Two Critical RCE-Capable Core Flaws
**Why it matters for audit/CISO/VAPT:** Unauthenticated attack paths in a platform running millions of sites, with a PoC already public for one flaw — immediate patch-verification item for VAPT and change-management audits.
WordPress 6.7.1, released 2026-09-22, fixes CVE-2026-93485 ("Comment2Shell," anonymous comment XSS that runs code when an admin views the page) and the previously reported "Click2Shell" CSRF flaw enabling PHP execution on some server configurations. ([source](https://thehackernews.com/2026/09/wordpress-issues-patch-for-critical.html))

### 3. Microsoft Disrupts EvilTokens AI-Driven Device-Code Phishing Service
**Why it matters for audit/CISO/VAPT:** A court-authorized takedown of a phishing-as-a-service platform that used AI throughout its attack chain to bypass MFA — directly relevant to identity-governance and MFA-control testing.
Microsoft's Digital Crimes Unit, with U.S. District Court authorization, took down EvilTokens, a device-code phishing service tied to over 12,000 Microsoft account compromises across 10,000+ organizations. ([source](https://thehackernews.com/2026/09/microsoft-takes-down-eviltokens-device.html))

### 4. SharePoint Flaw Reclassified From Spoofing to Authenticated RCE
**Why it matters for audit/CISO/VAPT:** Shows a CVSS 6.5 "spoofing" rating masked a full remote-code-execution path — a caution for risk-scoring reliance in vulnerability-management audits.
Full technical details published 2026-09-22 by a Viettel Cyber Security researcher show a SharePoint Server flaw Microsoft initially rated as low-severity spoofing actually enables authenticated RCE. ([source](https://thehackernews.com/2026/09/sharepoint-flaw-initially-listed-as.html))

### 5. Critical Unauthenticated RCE in Bifrost AI Gateway
**Why it matters for audit/CISO/VAPT:** AI infrastructure is now a direct RCE target with a single unauthenticated HTTP request — a new asset class VAPT and change-control programs need to inventory and test.
CVE-2026-90898 (CVSS 9.8) in the open-source Bifrost AI gateway, which routes requests to 20+ LLM providers, lets an unauthenticated attacker run arbitrary commands on the gateway server. ([source](https://thehackernews.com/2026/09/critical-bifrost-ai-gateway-flaw-lets.html))

### 6. Contagious Interview Campaign Compromises 30,000 Devices, Steals $10.71M
**Why it matters for audit/CISO/VAPT:** Large-scale, nation-state financial theft via fake-job social engineering — a control-failure lesson for hiring-process and endpoint-onboarding reviews.
A joint advisory attributes North Korea's Contagious Interview campaign to over 30,000 device compromises across 100+ countries, siphoning funds from 7,000+ crypto wallets for a total of $10.71 million. ([source](https://thehackernews.com/2026/09/contagious-interview-campaign.html))

### 7. ClosedQuorum Malware Uses AI Models to Drive Attack Decisions
**Why it matters for audit/CISO/VAPT:** A working example of AI-autonomous post-compromise decision-making, relevant to detection-logic and threat-model updates.
New Windows malware ClosedQuorum queries Google Gemini, DeepSeek, Qwen, and Mistral models to autonomously choose post-compromise actions on infected hosts. ([source](https://www.bleepingcomputer.com/news/security/new-closedquorum-windows-malware-uses-ai-for-attack-decisions/))
