# Security & Audit Digest — 2026-11-25

## Top items

### 1. Check Point Security Management servers compromised in 22 organizations
**Why it matters for audit/CISO/VAPT:** Firewall management consoles are trust anchors. Review whether they are internet-reachable and check admin access logs.
An unknown actor is using AI-driven offensive tooling, tracked by GreyNoise, to exploit multiple vulnerabilities and compromise about two dozen Check Point management servers. The campaign is ongoing. ([source](https://thehackernews.com/2026/11/hackers-compromise-24-check-point.html))

### 2. VMware vCenter critical auth bypass (CVE-2026-123903, CVSS 9.8)
**Why it matters for audit/CISO/VAPT:** vCenter controls the virtualization estate. Confirm patch levels against the advisory and look for unexpected admin sessions.
Broadcom's VMSA-2026-0011 fixes 23 flaws across ESX, vCenter, Workstation, Fusion and Avi Load Balancer. The lead item is an unauthenticated vCenter authentication bypass, following earlier zero-day exploitation. ([source](https://thehackernews.com/2026/11/vmware-vcenter-hit-by-another-critical.html))

### 3. CISA adds Drupal Core RCE and Optimizely Web Experimentation flaws to KEV
**Why it matters for audit/CISO/VAPT:** Both have a 2026-11-27 federal deadline. Check Drupal estates and inventory Optimizely as a third-party dependency.
On 2026-11-24 CISA added CVE-2026-132165 (Drupal Core RCE) and CVE-2026-132224 (Optimizely Web Experimentation), plus Idunno.AntiCsrf (CVE-2026-131914, covered yesterday), citing active exploitation. ([source](https://www.cisa.gov/news-events/alerts/2026/11/24/cisa-adds-three-known-exploited-vulnerabilities-catalog))

### 4. Backdoored WP Connect WordPress plugins removed
**Why it matters for audit/CISO/VAPT:** This is a plugin supply-chain compromise. Inventory WordPress plugins and check for installs or updates since 2026-11-22.
WordPress removed six WP Connect plugins that were backdoored on 2026-11-22 to allow arbitrary code execution, after a suspected compromise of the developer's account. Look for unexpected admin users and outbound connections. ([source](https://thehackernews.com/2026/11/wordpress-blocks-six-backdoored-wp.html))

### 5. Com-affiliated actors hijack cloud accounts via vishing
**Why it matters for audit/CISO/VAPT:** Help-desk identity checks and MFA reset flows are testable controls. Add vishing scenarios to VAPT scope.
Unit 42 reports numerous waves of vishing since August 2026 leading to cloud account takeover, data theft and extortion, including against financial services. ([source](https://thehackernews.com/2026/11/com-affiliated-hackers-hijack-cloud.html))

### 6. Radware breach exposes customer cloud access keys
**Why it matters for audit/CISO/VAPT:** A security vendor leaked customer credentials through an exposed management API. Rotate Radware-held keys and ask vendors about management-plane exposure.
Attackers reached some customers' account details and cloud access keys through an internal Cloud WAF management API left exposed online. ([source](https://www.bleepingcomputer.com/news/security/radware-discloses-breach-exposing-customer-cloud-access-keys/))

### 7. Rackspace shuts down Spot cloud after breach
**Why it matters for audit/CISO/VAPT:** Third-party Kubernetes secrets were exposed, and there is a hard exit deadline. Review vendor-exit plans and rotate secrets.
Attackers accessed customer Kubernetes clusters and secrets. Customers have until 2026-12-08 to migrate and export data. ([source](https://www.bleepingcomputer.com/news/security/rackspace-shuts-down-spot-cloud-platform-after-security-breach/))

### 8. WHMCS unauthenticated SQL injection
**Why it matters for audit/CISO/VAPT:** Billing platforms hold customer PII and admin hashes. Confirm patching and rotate admin credentials where WHMCS is used.
A flaw in WHMCS's shopping cart lets anyone retrieve customer records and administrator password hashes without logging in. ([source](https://thehackernews.com/2026/11/whmcs-sql-injection-flaw-could-expose.html))
