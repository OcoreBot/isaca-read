# Security & Audit Digest — 2026-09-22

## Top items

### 1. CISA Adds Zyxel GS1900 Switch Flaw to KEV Catalog
**Why it matters for audit/CISO/VAPT:** A new KEV entry carries a binding federal remediation deadline and is a standard vulnerability-management audit control point; it also flags actively exploited network infrastructure that many enterprises run unmanaged.
CISA added CVE-2026-7273, a stack-based buffer overflow in Zyxel GS1900 Series managed switches, to the KEV catalog on 2026-09-21 based on evidence of active exploitation. Federal remediation is due 2026-09-24. ([source](https://www.cisa.gov/news-events/alerts/2026/09/21/cisa-adds-one-known-exploited-vulnerability-catalog))

### 2. Jade Sleet (North Korea) Linked to Indian IT Provider Breach
**Why it matters for audit/CISO/VAPT:** A nation-state compromise of a managed IT services provider is a textbook third-party/vendor-risk audit finding, since attackers can pivot into every downstream client.
North Korean threat actor Jade Sleet was attributed to the compromise of a smaller India-based IT services firm, deploying the FLATROOF and ROOFDECK backdoors for persistence and lateral movement. ([source](https://thehackernews.com/2026/09/jade-sleet-linked-to-indian-it-provider.html))

### 3. Google Fined €403 Million Over GDPR Location-Data Violations
**Why it matters for audit/CISO/VAPT:** A board-level enforcement action showing regulators will penalize historical privacy practices; reinforces data-minimization and consent-documentation as ongoing audit focus areas.
Ireland's Data Protection Commission fined Google €403 million on 2026-09-21 for GDPR violations in how three products handled location data between May 2018 and February 2020. ([source](https://thehackernews.com/2026/09/google-fined-403-million-over-gdpr.html))

### 4. BigCommerce Merchants Breached via Compromised Ribon App Credentials
**Why it matters for audit/CISO/VAPT:** Illustrates how stolen third-party app credentials become a script-injection vector into e-commerce environments — a direct case for vendor API access reviews and integration governance.
BigCommerce alerted merchants that attackers used stolen credentials for third-party Ribon applications to inject malicious scripts into online stores. ([source](https://www.bleepingcomputer.com/news/security/bigcommerce-alerts-merchants-of-data-breach-linked-to-ribon-apps/))

### 5. TASK#STOMP PowerShell Backdoor Harvests Documents and Credentials
**Why it matters for audit/CISO/VAPT:** A new, actively used backdoor with document/Wi-Fi/clipboard exfiltration capability is directly relevant to endpoint detection tuning and DLP control testing.
Researchers disclosed TASK#STOMP, a PowerShell backdoor that automatically harvests and exfiltrates business documents, Wi-Fi passwords, and clipboard data from compromised Windows hosts. ([source](https://thehackernews.com/2026/09/taskstomp-powershell-backdoor-steals.html))

### 6. TerminalFix Campaign Hides Executable Payloads in PNG Steganography
**Why it matters for audit/CISO/VAPT:** A fully valid, fully executable PE hidden inside an image file defeats static file-type detections — relevant to incident-response playbooks and forensic tooling gaps.
Microsoft Security Research documented the TerminalFix campaign, which embeds executable payloads inside PNG files (not just subtle bit changes) to establish reverse tunnels for data exfiltration. ([source](https://isc.sans.edu/diary/rss/33318))

### 7. ClickFix Lures Deploy ChainScript RAT Using Blockchain for C2 Rotation
**Why it matters for audit/CISO/VAPT:** Blockchain-based C2 rotation is a novel evasion technique that outpaces IP/domain blocklists, requiring updated detection logic for VAPT and blue-team programs.
ClickFix-style social engineering is delivering a previously undocumented RAT called ChainScript, which uses the Polygon blockchain to rotate command-and-control infrastructure and evade takedown. ([source](https://thehackernews.com/2026/09/clickfix-lures-deploy-chainscript-rat.html))
