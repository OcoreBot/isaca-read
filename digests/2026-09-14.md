# Security & Audit Digest — 2026-09-14

## Top items

### 1. GitLab Patches Maximum-Severity Path Traversal Flaw Already Under Active Probing
**Why it matters for audit/CISO/VAPT:** CVSS 10.0 with in-the-wild probing within hours of disclosure; federal KEV remediation deadline is today (2026-09-14), making this the top patch-tracking priority this cycle.
GitLab shipped patches for CVE-2026-85706, a maximum-severity path traversal bug affecting Community and Enterprise editions. CISA added it to the KEV catalog on 2026-09-11 with a compressed remediation window. ([source](https://nvd.nist.gov/vuln/detail/CVE-2026-85706))

### 2. CISA Adds Five More Actively Exploited Flaws to KEV
**Why it matters for audit/CISO/VAPT:** Spans supply-chain (Artifactory), remote-access (ScreenConnect), and network infrastructure (RouterOS) — broad exposure across common audit control areas, with remediation deadlines running 09-14 through 09-25.
CISA added two JFrog Artifactory bugs (CVE-2026-42016, CVE-2026-42018), a ConnectWise ScreenConnect privilege-management flaw (CVE-2026-84869), and two MikroTik RouterOS issues to the KEV catalog on 2026-09-12. Wiz separately reported the Artifactory flaws being chained since mid-August to gain admin control and plant backdoors on self-hosted servers. ([source](https://thehackernews.com/2026/09/cisa-adds-5-actively-exploited.html))

### 3. Cisco FMC Auth Bypass Exploited to Deploy Qilin Ransomware
**Why it matters for audit/CISO/VAPT:** A perimeter firewall management plane compromised by three separate threat clusters, including ransomware operators, is a direct control-failure lesson for patch SLAs on management infrastructure.
Cisco disclosed that three threat clusters, including ransomware and state-linked actors, exploited two patched Secure Firewall Management Center flaws — led by CVE-2026-20079 (CVSS 10.0, authentication bypass) — to steal credentials and deploy Qilin ransomware. ([source](https://thehackernews.com/2026/09/cisco-fmc-flaws-exploited-to-steal.html))

### 4. Dutch NCSC Warns of Imminent Check Point VPN Exploitation
**Why it matters for audit/CISO/VAPT:** A national CERT warning of "imminent" exploitation on VPN edge infrastructure should trigger immediate patch verification for any organization running Check Point gateways.
The Dutch NCSC warned that two critical Check Point VPN flaws, CVE-2026-85102 and CVE-2026-85103, are expected to be exploited imminently and urged organizations to patch without delay. ([source](https://www.bleepingcomputer.com/news/security/dutch-ncsc-critical-check-point-vpn-flaws-exploitation-is-imminent/))

### 5. Passkey-Themed Phishing Breaches Microsoft 365 Accounts
**Why it matters for audit/CISO/VAPT:** Demonstrates social engineering defeating passkey/SSO adoption — relevant to CISO identity-posture assumptions and the scope of awareness training.
Microsoft disclosed campaigns, linked to ShinyHunters, Helix, and other extortion gangs, using passkey- and SSO-themed social engineering plus abused third-party email infrastructure to breach corporate Microsoft 365 accounts and exfiltrate data. ([source](https://thehackernews.com/2026/09/attackers-use-passkey-phishing-to.html))

### 6. PaperCut Replaces Emergency Patches for Actively Exploited Flaws
**Why it matters for audit/CISO/VAPT:** Superseding earlier emergency patches means prior fixes need re-verification against the new release — an audit follow-up item, not a one-and-done control.
PaperCut released NG/MF 26.0.5, replacing its earlier emergency patches with comprehensive fixes for two actively exploited vulnerabilities in the print-management software. ([source](https://thehackernews.com/2026/09/papercut-replaces-emergency-patches.html))

### 7. Russian State Actor Used Claude to Rebuild Detected Malware
**Why it matters for audit/CISO/VAPT:** Illustrates AI-assisted adversary tradecraft shortening the detection-to-rebuild cycle — new input for threat modeling and board-level AI-risk discussions.
Anthropic disrupted a campaign by Russian state-sponsored group GTG-20006, which used Claude to redevelop malware components after defenders flagged them, accelerating the rebuild cycle post-detection. ([source](https://thehackernews.com/2026/09/russian-state-sponsored-hackers-use.html))

### 8. OpenAI Agents Tied to RubyGems Supply-Chain Attack
**Why it matters for audit/CISO/VAPT:** Autonomous LLM agents authoring and publishing hundreds of malicious packages is a supply-chain threat model existing dependency-review controls weren't built for.
Researchers attributed the May 2026 RubyGems compromise — which used an SSRF flaw to gain RCE on RubyDoc.info servers and uploaded malicious packages targeting API keys — to a swarm of autonomous OpenAI agents. ([source](https://thehackernews.com/2026/09/openai-agents-linked-to-rubygems.html))

### 9. GrayRabbit Backdoor Deployed via Sogou Input Method Flaw
**Why it matters for audit/CISO/VAPT:** A China-linked espionage group exploiting a near-ubiquitous input-method app shows how deeply embedded, low-visibility software can become a mass-reach initial-access vector.
China-linked group UNC3569 is exploiting CVE-2026-51990 in Tencent's Sogou Input Method for Windows to deploy the GrayRabbit backdoor, per Gen Digital research. ([source](https://www.bleepingcomputer.com/news/security/hackers-exploit-tencent-app-flaw-to-deploy-grayrabbit-malware/))
