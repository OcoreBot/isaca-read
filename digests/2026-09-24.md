# Security & Audit Digest — 2026-09-24

## Top items

### 1. Chinese Hackers Exploit Zyxel KEV Flaw and WordPress Bugs to Steal Government Data
**Why it matters for audit/CISO/VAPT:** A concrete breach outcome — not just a vulnerability — tied to a flaw CISA had already flagged for active exploitation, illustrating the cost of missed patch-management deadlines.
A Chinese-speaking threat actor exploited Zyxel GS1900 switch flaw CVE-2026-7273 (added to CISA's KEV catalog on 2026-09-21) alongside WordPress vulnerabilities to compromise 996 devices and exfiltrate over 18,500 records from government backend databases. ([source](https://www.bleepingcomputer.com/news/security/chinese-hackers-exploit-multiple-technologies-to-steal-govt-data/))

### 2. cPanel CalDAV/CardDAV Flaw Lets Hosting Accounts Run Code as Root
**Why it matters for audit/CISO/VAPT:** A privilege-escalation path from ordinary shared-hosting access to full root control, plus a second WP Toolkit bug enabling account hijacking — both need patch-verification on any shared hosting estate.
cPanel disclosed on 2026-09-22 that a flaw in its CalDAV/CardDAV service lets any hosting account holder run code as root and take full server control. ([source](https://thehackernews.com/2026/09/new-cpanel-flaw-lets-hosting-account_0272795595.html))

### 3. MikroTrick Chain Lets Attackers Take Over MikroTik Routers Without Credentials
**Why it matters for audit/CISO/VAPT:** Zero-authentication, full administrative takeover of Internet-exposed edge devices — a priority test case for perimeter and network-access-control audits.
CERT Polska disclosed "MikroTrick," a chain of two RouterOS SSH vulnerabilities that together grant attackers full admin control of Internet-facing MikroTik routers without a password, SSH key, or completed authentication. ([source](https://thehackernews.com/2026/09/mikrotrick-chain-let-attackers-take.html))

### 4. Malicious Terraform Providers Deliver Go Malware via HashiCorp Registry
**Why it matters for audit/CISO/VAPT:** The first known case of the HashiCorp registry itself being used as a malware distribution channel — a new supply-chain vector for IaC and CI/CD vetting controls.
Researchers disclosed two Go modules and two Terraform providers seeded with Go-based malware and distributed through HashiCorp's public registry. ([source](https://thehackernews.com/2026/09/attackers-use-malicious-terraform.html))

### 5. Compromised MemTensor Packages Deliver sckit Credential Stealer via npm and PyPI
**Why it matters for audit/CISO/VAPT:** Another legitimate-package takeover reaching both npm and PyPI simultaneously — reinforces the need for software composition analysis on cross-ecosystem dependencies.
Threat actors compromised two legitimate MemTensor packages to push a cross-platform Go-based credential stealer dubbed "sckit" to Windows, Linux, and macOS targets. ([source](https://thehackernews.com/2026/09/compromised-memtensor-packages-deliver.html))

### 6. Exploit Released for Unpatched Ubuntu Kernel Flaw Enabling Container-to-Host Root Escape
**Why it matters for audit/CISO/VAPT:** A working exploit for a container-escape bug that was fixed upstream over a month ago shows how patch lag turns known issues into live risk in cloud-native environments.
Security firm DepthFirst published research on 2026-09-22 showing a use-after-free in the Linux kernel's AF_UNIX socket subsystem (CVE-2026-80521, CVSS 7.8) can escape a container and gain root on the host; many Ubuntu systems remain unpatched despite an August 6 upstream fix. ([source](https://thehackernews.com/2026/09/exploit-released-for-unpatched-ubuntu.html))

### 7. Leaked GitLab Issue-Email Address Lets Attackers Push Code and Run CI/CD Jobs as You
**Why it matters for audit/CISO/VAPT:** A per-user "credential" most teams don't treat as one — directly relevant to access-control and CI/CD change-management audits.
Research published this week shows GitLab's private per-user issue-filing email address can be used by anyone who obtains it to email commits to any branch a user can push to, including main, and trigger CI/CD jobs running as that user. ([source](https://thehackernews.com/2026/09/a-leaked-gitlab-issue-email-address.html))
