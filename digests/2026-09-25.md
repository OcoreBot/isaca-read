# Security & Audit Digest — 2026-09-25

## Top items

### 1. AI-Assisted Code Commits Leak Secrets at Twice the Rate of Human-Written Code
**Why it matters for audit/CISO/VAPT:** Quantifies a control gap auditors keep flagging anecdotally — AI coding agents are outpacing secrets-management controls, directly implicating SAST/SCA and CI/CD scanning coverage.
GitGuardian's 2026 State of Secrets Sprawl Report found commits identified as AI-assisted leak credentials at roughly 2x the rate of manually written commits, reflecting rapid AI-coding-tool adoption without matching guardrails. ([source](https://thehackernews.com/2026/09/secrets-sprawl-is-identity-problem-that.html))

### 2. CISA Warns Ransomware Gangs Are Now Exploiting a Critical TeamCity Flaw
**Why it matters for audit/CISO/VAPT:** A CI/CD build-server compromise enables code tampering and supply-chain-wide impact; the two-month gap since patch release is a textbook patch-management audit finding.
CISA alerted federal agencies on 2026-09-24 that ransomware operators are now exploiting a critical JetBrains TeamCity vulnerability that was patched in July 2026. ([source](https://www.bleepingcomputer.com/news/security/cisa-ransomware-gangs-now-exploiting-critical-teamcity-flaw/))

### 3. TeamFiltration Campaign Compromises 5,700+ Microsoft 365 Accounts Across 28 Tenants
**Why it matters for audit/CISO/VAPT:** Large-scale cloud-identity compromise driven by default/weak passwords — a direct test of MFA enforcement and credential-hygiene controls.
Proofpoint disclosed an active TeamFiltration campaign, tracked as UNK_CondorFiltration, targeting over 5,700 M365 accounts across 28 tenants, concentrated in Chilean retail and financial firms. ([source](https://thehackernews.com/2026/09/teamfiltration-compromises-seven.html))

### 4. F5 Patches Critical BIG-IP APM Zero-Day Exploited for Unauthenticated RCE on OAuth Servers
**Why it matters for audit/CISO/VAPT:** Unauthenticated code execution on infrastructure issuing OAuth access tokens undermines identity and SSO controls enterprise-wide.
F5 confirmed active exploitation of CVE-2026-94127, a heap-based buffer overflow in BIG-IP Access Policy Manager instances configured as OAuth authorization servers. ([source](https://thehackernews.com/2026/09/f5-patches-critical-big-ip-apm-zero-day.html))

### 5. CVSS 10.0 VeloCloud Orchestrator Flaw Actively Exploited
**Why it matters for audit/CISO/VAPT:** A maximum-severity, no-login flaw in an SD-WAN orchestrator threatens confidentiality, integrity, and availability of an entire WAN fabric — a priority item for network-perimeter audits.
Arista disclosed active exploitation of CVE-2026-93952 in on-premises VeloCloud Orchestrator, letting unauthenticated remote attackers escalate privileges in certificate-based deployments. ([source](https://thehackernews.com/2026/09/new-cvss-100-velocloud-orchestrator.html))

### 6. Check Point Management Server Zero-Day Exploited in Targeted Attacks
**Why it matters for audit/CISO/VAPT:** Compromise of the management plane for network security appliances enables firewall-policy tampering and lateral movement from the perimeter inward.
Check Point disclosed that CVE-2026-93616, a path traversal and file-upload flaw, was exploited in targeted attacks against Security Management Server as early as July 23, 2026, letting attackers run scripts without logging in. ([source](https://thehackernews.com/2026/09/check-point-warns-of-management-server.html))

### 7. WordPress CVE-2026-87902 Exploited Within Hours of Disclosure
**Why it matters for audit/CISO/VAPT:** Illustrates how thin the patch window has become for public-facing CMS platforms — automated exploitation now starts before most patch cycles complete.
Threat actors moved from probing to active file-write and shell-command exploitation of the critical (CVSS 9.2) unauthenticated RCE flaw within hours of public disclosure. ([source](https://thehackernews.com/2026/09/attackers-exploit-wordpress-cve-2026.html))
