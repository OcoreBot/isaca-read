# Security & Audit Digest — 2026-11-11

## Top items

### 1. Microsoft November Patch Tuesday: record flaw count, Outlook zero-day exploited
**Why it matters for audit/CISO/VAPT:** An exploited Outlook bug (CVE-2026-124194) is now on CISA KEV with a 2026-11-24 federal deadline. Critical AD LDAP and Windows TCP/IP RCEs also need triage.
BleepingComputer counts 1,235 flaws (SANS says 1,260, Krebs about 1,100). The exploited Outlook flaw is a missing user-interaction check. SANS also lists a critical AD LDAP RCE (CVE-2026-119958) and a critical Windows TCP/IP RCE (CVE-2026-113859). ([source](https://www.bleepingcomputer.com/news/microsoft/microsoft-november-2026-patch-tuesday-fixes-1-235-flaws-outlook-zero-day/))

### 2. CISA adds six KEVs: Cisco BroadWorks, Barracuda ESG, Openwave, Chromium, Outlook
**Why it matters for audit/CISO/VAPT:** This is a ready patch-priority list. The two Barracuda deadlines (2026-11-13) are the nearest.
Added 2026-11-10: CVE-2026-20320 (BroadWorks XXE), CVE-2026-116606 and CVE-2026-111560 (Barracuda ESG), CVE-2026-111793 (Openwave), CVE-2026-125350 (Chromium UAF) and CVE-2026-124194 (Outlook). Most federal deadlines are 2026-11-24. ([source](https://www.cisa.gov/news-events/alerts/2026/11/10/cisa-adds-six-known-exploited-vulnerabilities-catalog))

### 3. Barracuda ESG flaws exploited for root command execution
**Why it matters for audit/CISO/VAPT:** Email gateways are internet-facing and high-value. Check for unpatched appliances and signs of compromise.
Attackers have begun exploiting two recently patched ESG vulnerabilities to run commands as root. These are the two Barracuda KEV entries above. ([source](https://www.bleepingcomputer.com/news/security/hackers-exploit-barracuda-email-security-gateway-flaws-to-get-root-access/))

### 4. SAP patches four CVSS 10.0 flaws; attackers already hunting NetWeaver webshells
**Why it matters for audit/CISO/VAPT:** Unauthenticated RCE on ERP systems is a top audit and pentest concern.
Three flaws are in NetWeaver Application Server and one is in the Web Dispatcher/Gateway area. SANS reported attackers probing honeypots for SAP NetWeaver webshells on 2026-11-09, so check for existing compromise as well as patching. ([source](https://thehackernews.com/2026/11/sap-patches-four-cvss-100-flaws.html))

### 5. Xen Orchestra auth bypass exploited (VSA-2026-062)
**Why it matters for audit/CISO/VAPT:** Hypervisor management compromise exposes every VM on the host.
An authentication bypass in REST cookie parsing is being exploited to gain admin access and take over XCP-ng hosts. It has no CVE yet. ([source](https://www.bleepingcomputer.com/news/security/critical-xen-orchestra-auth-bypass-flaw-exploited-to-hijack-vm-servers/))

### 6. Qubole's trusted AWS access used to breach customer accounts
**Why it matters for audit/CISO/VAPT:** This is a third-party IAM and cross-account trust failure, useful for access-review scoping.
Wiz says compromised IAM credentials for Qubole's AWS account were used between October 14 and 26 to steal secrets and data from multiple customers' environments. ([source](https://thehackernews.com/2026/11/hackers-exploit-quboles-trusted-aws.html))

### 7. Railway breach: about $740,000 in fraudulent AI charges
**Why it matters for audit/CISO/VAPT:** Stolen secrets turned directly into financial loss, which bears on API-key management and cloud-provider risk.
Attackers exploited Railway infrastructure flaws and stole customer authentication secrets. Credentials for up to 100,000 workspaces may be exposed. ([source](https://www.bleepingcomputer.com/news/apple/railway-breach-leads-to-740-000-in-fraudulent-ai-charges/))

### 8. Fireworks AI breach widens
**Why it matters for audit/CISO/VAPT:** AI-vendor risk: customers should rotate secrets and review vendor due diligence.
Fireworks says further activity affected account and billing data, secrets, datasets and incomplete model weights for a limited set of accounts. ([source](https://thehackernews.com/2026/11/fireworks-ai-breach-widens-to-expose.html))

### 9. Ethersphere bee-js and Swarm Desktop trojanized via release automation
**Why it matters for audit/CISO/VAPT:** This is a build-pipeline supply-chain compromise, relevant to dependency governance and CI/CD controls.
Malicious bee-js 13.3.0 and Swarm Desktop 0.56.2 were published through the project's own pipeline and steal the wallet key. ([source](https://thehackernews.com/2026/11/hackers-compromise-etherspheres-bee-js.html))

### 10. Git flaw: code execution on recursive clone of a malicious repo
**Why it matters for audit/CISO/VAPT:** Developer workstations and CI runners are exposed.
Fixed in Git 2.56.1, with backports to the 2.50–2.55 series. ([source](https://thehackernews.com/2026/11/git-patches-flaw-that-lets-malicious.html))
