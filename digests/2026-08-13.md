# Security & Audit Digest — 2026-08-13

## Top items

### 1. VMware vCenter CVE-2026-59310 Actively Exploited for Persistent Remote Access
**Why it matters for audit/CISO/VAPT:** vCenter is a single control point for entire virtualization estates — compromise here has blast radius across every guest workload, making it a priority segmentation and patch-status check.
Threat actors are actively exploiting a directory-traversal flaw (CVSS 9.8) in Broadcom VMware vCenter to gain persistent remote access, per new findings from QUIRSO. ([source](https://thehackernews.com/2026/08/attackers-exploit-vmware-vcenter.html))

### 2. SAP Commerce Cloud CVSS 10.0 Unauthenticated RCE
**Why it matters for audit/CISO/VAPT:** Maximum-severity, no-authentication-required flaw in a widely deployed e-commerce platform — a hard patch-compliance item for any org running Commerce Cloud.
SAP shipped patches for CVE-2026-58231, a Data Hub Adapter flaw allowing unauthenticated attackers to execute arbitrary code. ([source](https://thehackernews.com/2026/08/sap-commerce-cloud-flaw-could-let.html))

### 3. Adobe Patches Three CVSS 10.0 Flaws — One (Commerce) Already Under Attack
**Why it matters for audit/CISO/VAPT:** Three simultaneous maximum-severity flaws across ColdFusion, Campaign Classic, and Commerce is a major single-vendor remediation sprint, and the Commerce flaw is already being abused.
Adobe patched three critical RCE/privilege-escalation bugs; separately, attackers are exploiting CVE-2026-71362 in Adobe Commerce/Magento to hijack customer accounts. ([source](https://thehackernews.com/2026/08/adobe-patches-three-cvss-100-coldfusion.html))

### 4. ShieldBreak PoC Bypasses Microsoft Defender for SYSTEM Access
**Why it matters for audit/CISO/VAPT:** A public, working exploit against Microsoft's own endpoint-protection product undermines the assumption that Defender-only estates are adequately covered — a direct input for control-effectiveness testing.
Researcher "Chaotic Eclipse" released a PoC named ShieldBreak that escalates privileges to SYSTEM by bypassing Microsoft Defender, days after August Patch Tuesday. ([source](https://thehackernews.com/2026/08/shieldbreak-zero-day-poc-claims.html))

### 5. Flaw in OpenAI, Anthropic, and Google APIs Exposed Hidden Reasoning and Secrets
**Why it matters for audit/CISO/VAPT:** Any pipeline logging API session data may have inadvertently retained recoverable API keys and passwords — an immediate trigger for secret-rotation and log-retention review.
A disclosed weakness in how encrypted reasoning objects were carried between API calls let researchers recover internal model reasoning and embedded secrets, including API keys, from session logs. ([source](https://thehackernews.com/2026/08/openai-anthropic-google-api-flaw-let.html))

### 6. Malicious LiteLLM PyPI Releases Tied to Trivy Hack Affected 2,100+ Organizations
**Why it matters for audit/CISO/VAPT:** A four-month gap between a credential-stealing supply-chain compromise and its public discovery is a control-failure lesson for SBOM and dependency-pinning practices.
Two malicious LiteLLM releases sat on PyPI for roughly 40 minutes in March harvesting cloud, SSH, and Kubernetes credentials; CloudSEK now estimates over 2,100 organizations were exposed. ([source](https://thehackernews.com/2026/08/malicious-litellm-releases-tied-to.html))

### 7. Picus Labs Blue Report 2026: Defenses Catch Noise, Miss Silent Attackers
**Why it matters for audit/CISO/VAPT:** A board-level metrics problem — alert-based detection KPIs look healthy while low-and-slow lateral movement goes uncaught, a gap penetration tests should specifically probe.
Picus Labs measured 338+ million attack simulations across production environments and found enterprise defenses reliably catch noisy attacks but consistently miss silent reconnaissance and lateral movement. ([source](https://thehackernews.com/2026/08/enterprise-defenses-recovered-at-edge.html))
