# Security & Audit Digest — 2026-11-24

## Top items

### 1. CISA adds N-able Mail Assure SSRF and MONAI Label path traversal to KEV
**Why it matters for audit/CISO/VAPT:** Both have short federal deadlines. Check email-filtering SaaS dependencies and any MONAI Label deployments.
CISA added CVE-2026-134624 (N-able Mail Assure/SpamExperts SSRF) and CVE-2026-133968 (MONAI Label path traversal) on 2026-11-23, citing active exploitation. Remediation is due 2026-11-26. N-able found its flaw while investigating its own breach. ([source](https://www.cisa.gov/news-events/alerts/2026/11/23/cisa-adds-two-known-exploited-vulnerabilities-catalog))

### 2. Azure API Management Classic flaw exploited to steal stored API credentials
**Why it matters for audit/CISO/VAPT:** Stored API keys are a cloud secrets exposure. Rotate APIM-held credentials and confirm the patched version.
Microsoft warned that a vulnerability in APIM Classic tiers was used to steal stored API credentials. Norwegian authorities link it to attacks on energy companies. ([source](https://www.bleepingcomputer.com/news/security/microsoft-azure-flaw-exploited-to-steal-customers-api-credentials/))

### 3. ConnectWise ScreenConnect flaw (CVE-2026-84869, CVSS 9.9) exploited against MSPs
**Why it matters for audit/CISO/VAPT:** Remote-support tools are privileged third-party trust paths. Confirm patch level and review MSP-side access logs.
Attackers are exploiting this patched client flaw, which lets a guest transfer and execute files, against MSP servers and technician PCs. Risk sits with unpatched instances. ([source](https://thehackernews.com/2026/11/hackers-exploit-critical-screenconnect.html))

### 4. Legacy ASP.NET library Idunno.AntiCsrf exploited for unauthenticated RCE (CVE-2026-131914)
**Why it matters for audit/CISO/VAPT:** Unmaintained dependencies are an inventory and SBOM finding. VAPT should look for the DLL in .NET applications.
Researchers urge users to stop using the library after in-the-wild exploitation. It is unmaintained, so a patch may not exist. ([source](https://thehackernews.com/2026/11/hackers-exploit-critical-aspnet-anti.html))

### 5. binary-parser flaw (CVE-2026-134814) allows JavaScript injection
**Why it matters for audit/CISO/VAPT:** This is an npm supply-chain component. Check SBOMs and whether untrusted input can reach parser definitions.
An attacker who controls parser definitions can run code in Node.js. SANS notes the earlier fix was incomplete; the recommended version is 2.3.1. ([source](https://thehackernews.com/2026/11/critical-binary-parser-flaw-enables.html))

### 6. Webworm suspected of modifying SoftEther VPN to evade detection
**Why it matters for audit/CISO/VAPT:** Signature-based detection may miss it. Hunt for unapproved VPN bridges and "monitoring" tools.
The China-aligned group is suspected of using a custom SoftEther VPN Bridge with detection fingerprints removed, disguised as network-monitoring software. ([source](https://thehackernews.com/2026/11/webworm-suspected-of-modifying.html))

### 7. KEPCO breach affects 1.5 million people
**Why it matters for audit/CISO/VAPT:** A critical-infrastructure operator with a large data exposure is a useful case for data classification and network segmentation reviews.
A threat actor breached KEPCO's internal network and accessed two systems holding customer, employee and contractor data. ([source](https://www.bleepingcomputer.com/news/security/south-koreas-power-giant-kepco-confirms-data-breach-impacting-15-million/))

### 8. CERT-In warns of AI-assisted attacks causing unauthorized payments at Indian banks
**Why it matters for audit/CISO/VAPT:** Relevant to payment-authorization and fraud-control testing, and to AI-enabled threats in risk assessments.
CERT-In reports AI-assisted attacks on ICT assets that led to unauthorized payments at banks and fintechs. ([source](https://thehackernews.com/2026/11/ai-assisted-cyberattacks-trigger.html))
