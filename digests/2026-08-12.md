# Security & Audit Digest — 2026-08-12

## Top items

### 1. Microsoft August 2026 Patch Tuesday: 400 Flaws, Active Zero-Day in Core Kernel Driver
**Why it matters for audit/CISO/VAPT:** A massive monthly remediation burden with a kernel driver already under active exploitation and added to CISA KEV — a hard patch-compliance checkpoint for every Windows/Office estate.
Microsoft patched roughly 398–400 vulnerabilities (62 critical), including CVE-2026-68820, a use-after-free in the Windows Ancillary Function Driver for WinSock that's already being exploited (KEV deadline 2026-08-25), plus two publicly disclosed zero-days and critical DNS Server/DHCP RCEs. ([source](https://www.bleepingcomputer.com/news/microsoft/microsoft-august-2026-patch-tuesday-fixes-400-flaws-3-zero-days/))

### 2. CISA KEV: Metabase SQL Injection and Cisco ASA/FTD Heap Inspection Flaws — Federal Deadline Aug 14
**Why it matters for audit/CISO/VAPT:** Two actively exploited flaws with a two-day federal remediation window; both a common BI tool and perimeter firewalls are in play.
CISA added CVE-2026-72898 (Metabase SQL injection) and CVE-2026-20349 (Cisco Secure Firewall ASA/FTD heap inspection) to the KEV catalog on 2026-08-11, both with evidence of active exploitation and remediation due 2026-08-14. ([source](https://www.cisa.gov/news-events/alerts/2026/08/11/cisa-adds-three-known-exploited-vulnerabilities-catalog))

### 3. SharePoint Unauthenticated RCE (CVE-2026-55040) Now Exploited by Ransomware Gangs
**Why it matters for audit/CISO/VAPT:** CISA-confirmed ransomware exploitation of a CVSS 9.1 flaw letting attackers act as any user, including admin, with no valid account.
The flaw, found partly through AI-assisted research, affects multiple SharePoint Server releases; CISA confirmed ransomware gangs began abusing it in the wild. ([source](https://www.bleepingcomputer.com/news/security/cisa-microsoft-sharepoint-flaw-now-exploited-in-ransomware-attacks/))

### 4. Zoom Annotation Flaws Enable Cross-Client Remote Code Execution
**Why it matters for audit/CISO/VAPT:** A ubiquitous conferencing tool where either the presenter or any viewer can be hijacked mid-meeting — a PoC is already public.
Three memory-allocation bugs in Zoom's screen-annotation feature let a participant sharing their screen take over viewers' machines, and vice versa. Patches are available. ([source](https://thehackernews.com/2026/08/zoom-annotation-flaws-could-let-meeting.html))

### 5. Windows USB Plug-and-Play Chain Escalates to SYSTEM on Fully Patched Windows 11
**Why it matters for audit/CISO/VAPT:** A local- and RDP-triggerable privilege-escalation path that works against a fully updated machine, undermining patch-status assumptions.
Researchers abused Windows PnP's signed-driver installation flow for an emulated USB device to chain to SYSTEM access, reproducible over Remote Desktop without physical access. ([source](https://thehackernews.com/2026/08/researchers-turn-usb-auto-install-into.html))

### 6. Sandworm-Linked UAC-0145 Uses Fake Job Interviews to Push Trojanized VPN
**Why it matters for audit/CISO/VAPT:** Nation-state HR-channel social engineering targeting IT/sysadmin staff directly — relevant to security-awareness and vendor-software-verification controls.
CERT-UA disclosed a Russian-linked campaign posing as recruiters to trick Ukrainian IT workers into installing a trojanized WireGuard client capable of running attacker commands. ([source](https://thehackernews.com/2026/08/sandworm-linked-uac-0145-uses-fake-job.html))

### 7. Mozilla Revokes Firefox/Thunderbird Linux Signing Key After Accidental Exposure
**Why it matters for audit/CISO/VAPT:** A software-integrity trust-anchor rotation event — a direct checkpoint for configuration-management and software-deployment audits.
An unencrypted copy of the GPG key used to sign Firefox and Thunderbird Linux releases was committed to a private Mozilla repository; the key has been revoked and replaced, primarily affecting RPM packaging and manual signature verification. ([source](https://www.bleepingcomputer.com/news/security/mozilla-updates-gpg-key-for-signing-firefox-thunderbird-releases-after-exposure/))

### 8. Polish Power Plant Breach via Private Cellular Network Shuts Down Turbine
**Why it matters for audit/CISO/VAPT:** Demonstrates that "private" cellular links relied on for OT/ICS remote access are not equivalent to an air gap — a challenge to segmentation assumptions in critical-infrastructure audits.
Attackers reached a Polish combined heat and power plant over the private cellular network used for remote equipment access, shutting down a steam turbine and water-treatment system affecting roughly 50,000 residents. ([source](https://thehackernews.com/2026/08/hackers-breach-polish-power-plant.html))
