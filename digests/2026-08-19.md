# Security & Audit Digest — 2026-08-19

## Top items

### 1. CISA adds four Known Exploited Vulnerabilities, including SharePoint weak-auth flaw
**Why it matters for audit/CISO/VAPT:** Active exploitation confirmed with a tight federal remediation deadline (2026-08-21) — audit teams should verify patch status on SharePoint and IKE-exposed systems immediately, and VAPT scoping should add these CVEs to next-cycle testing.
CISA added CVE-2026-33824 (Microsoft IKE Service Extensions double-free), CVE-2026-55040 (SharePoint weak authentication), CVE-2026-65400 (Apple macOS improper authentication), and a fourth vulnerability to the KEV catalog based on evidence of active exploitation. ([source](https://www.cisa.gov/news-events/alerts/2026/08/18/cisa-adds-four-known-exploited-vulnerabilities-catalog))

### 2. TWINLOOT Python implant hides C2 inside SharePoint and Teams
**Why it matters for audit/CISO/VAPT:** Command-and-control traffic that blends into trusted Microsoft 365 services defeats simple allow-listing — a strong case for auditing egress-filtering logic and testing detection coverage on SharePoint/Teams abuse patterns.
Researchers disclosed TWINLOOT, a modular, PyArmor-hardened Python implant that runs its entire C2 infrastructure inside trusted Microsoft services to steal credentials and move laterally without triggering exfiltration alerts. ([source](https://thehackernews.com/2026/08/twinloot-abuses-sharepoint-and-teams-to.html))

### 3. Single actor has scraped Salesforce and ServiceNow portals since 2025
**Why it matters for audit/CISO/VAPT:** A textbook third-party/SaaS risk case — auditors should review portal access controls and API-key hygiene, since the activity went undetected for over a year via over-permissioned integrations.
Reco researchers identified a single piece of infrastructure, dubbed City Forum, that has been harvesting records from Salesforce and ServiceNow customer portals across multiple industries by exploiting weak access controls. ([source](https://thehackernews.com/2026/08/one-attacker-has-scraped-both.html))

### 4. Clop built a custom web shell targeting PTC Windchill and FlexPLM
**Why it matters for audit/CISO/VAPT:** Purpose-built tooling against PLM systems signals targeted supply-chain and manufacturing-data risk — worth prioritizing Windchill/FlexPLM inventory and checking build/deploy logs for web-shell indicators.
Analysts linked a bespoke Java web shell, built specifically to exploit PTC Windchill and FlexPLM servers, to the Clop ransomware gang; it can decrypt credentials, enumerate repositories, and exfiltrate files. ([source](https://www.bleepingcomputer.com/news/security/clop-created-custom-web-shell-for-windchill-data-theft-attacks/))

### 5. Windows Task Host flaw now actively exploited by ransomware gangs
**Why it matters for audit/CISO/VAPT:** A patch-lag case study — the flaw was flagged as exploited back in April and is only now seeing ransomware weaponization, useful evidence for testing patch-velocity and EDR detection gaps.
CISA confirmed ransomware gangs are exploiting a high-severity Windows Task Host vulnerability, with exploitation now widespread. ([source](https://www.bleepingcomputer.com/news/security/cisa-windows-task-host-flaw-now-exploited-by-ransomware-gangs/))

### 6. Microsoft Copilot Personal flaws enable single-click data exfiltration
**Why it matters for audit/CISO/VAPT:** An emerging AI-agent attack surface — a crafted link can silently pull data from apps connected to a user's Copilot session, warranting policy review on Copilot connection permissions.
Varonis Threat Labs disclosed three vulnerabilities in Microsoft Copilot Personal that could let a single click on a malicious link exfiltrate data from connected apps and other information available to the victim's session. ([source](https://thehackernews.com/2026/08/microsoft-copilot-personal-flaws-could.html))

### 7. MLflow SSRF and FUXA SCADA flaws under active exploitation
**Why it matters for audit/CISO/VAPT:** Dual exposure across AI infrastructure and OT — MLflow SSRF can steal cloud credentials while FUXA affects industrial control systems, so both ML deployment inventories and OT segmentation deserve immediate review.
Two critical vulnerabilities in MLflow (AI platform) and FUXA (web-based SCADA/HMI) are seeing malicious scanning and exploitation in the wild. ([source](https://thehackernews.com/2026/08/attackers-exploit-mlflow-ssrf-flaw-to.html))
