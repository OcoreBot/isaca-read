# Security & Audit Digest — 2026-10-28

## Top items

### 1. Compromised eMudhra CA keys force emergency Microsoft/Apple distrust updates
**Why it matters for audit/CISO/VAPT:** A stolen certificate authority key lets an attacker mint valid-looking certificates for any eMudhra-signed domain, undermining the trust chain itself rather than a single product.
Microsoft shipped out-of-band Windows updates distrusting compromised eMudhra intermediate CA certificates after their private keys were exposed; Apple blocks them in Safari, Mail, and native networking. Command-line tools, Python `certifi`, Homebrew, and some Linux CA bundles may still trust them pending separate updates. Audit should verify CA bundle updates across all platforms, not just OS-level trust stores, and watch for suspicious eMudhra-signed issuance. ([SANS Stormcast](https://isc.sans.edu/podcastdetail/10154))

### 2. PHP2Shell exploitation confirmed against internet-exposed PAN-OS management interfaces
**Why it matters for audit/CISO/VAPT:** Builds on yesterday's KEV addition — the federal remediation deadline is one day out, and attackers are now confirmed hitting a widely deployed network-security product directly.
Palo Alto Networks confirmed active exploitation of CVE-2026-109618/109619 against internet-exposed PAN-OS management interfaces; some appliances lack full ASLR, easing exploitation. Apply Palo Alto hotfixes immediately and confirm management interfaces aren't internet-facing. ([SANS Stormcast](https://isc.sans.edu/podcastdetail/10154))

### 3. CISA KEV adds Adobe Commerce/Magento and Google Brotli flaws as actively exploited
**Why it matters for audit/CISO/VAPT:** Yesterday's Brotli supply-chain flaw is now confirmed under active exploitation, and a Magento file-upload bug joins it — both carry a November 10 federal deadline.
CISA added CVE-2026-48356 (Adobe Commerce/Magento unrestricted file upload) and CVE-2026-111497 (Google Brotli unchecked return value) to the KEV catalog on October 27. Patch-compliance tracking should prioritize Magento storefronts and any software bundling Brotli decompression. ([CISA](https://www.cisa.gov/news-events/alerts/2026/10/27/cisa-adds-two-known-exploited-vulnerabilities-catalog))

### 4. Microsoft Authenticator Android flaw let permissionless apps steal work tokens
**Why it matters for audit/CISO/VAPT:** Undermines the core assumption behind phone-as-second-factor — that only the legitimate user's apps can read authentication tokens.
CVE-2026-80097 let a malicious Android app with zero permissions impersonate trusted Microsoft apps like Teams and collect sign-in tokens for work accounts. Fixed in Authenticator 6.2606.4246+. Audit: review MDM app-vetting policy and whether device-based MFA needs stronger isolation. ([The Hacker News](https://thehackernews.com/2026/10/microsoft-authenticator-flaw-let.html))

### 5. GoAhead embedded web server never enforces loaded certificate revocation lists
**Why it matters for audit/CISO/VAPT:** IoT and embedded devices using mutual TLS for authentication can be accessed with certificates that were supposed to be revoked.
FoxIO researchers found GoAhead (common in IoT/embedded devices) loads CRLs but never enables revocation checking, so revoked client certificates still authenticate on OpenSSL-backed mTLS deployments. GoAhead 6.1.1 fixes it, but affected devices need vendor firmware updates. Audit should inventory GoAhead-based deployments and push for firmware updates or network segmentation in the meantime. ([SANS Stormcast](https://isc.sans.edu/podcastdetail/10154))

### 6. Lazarus Group deploys post-quantum encrypted malware against South Korean targets
**Why it matters for audit/CISO/VAPT:** Nation-state actors are now abusing legitimate local security software as a delivery vector and adopting post-quantum cryptography to resist future decryption.
Operation FlashHole targeted at least three South Korean organizations in construction, software, and telecom-equipment manufacturing, abusing local security software to deploy malware encrypted with post-quantum algorithms. Critical-infrastructure audit teams should inventory security software for abuse potential and begin crypto-agility planning. ([The Hacker News](https://thehackernews.com/2026/10/lazarus-abuses-south-korean-security.html))
