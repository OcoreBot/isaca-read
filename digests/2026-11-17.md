# Security & Audit Digest — 2026-11-17

## Top items

### 1. Optimizely scripts hijacked to serve card skimmers and iOS exploit kits
**Why it matters for audit/CISO/VAPT:** Third-party JavaScript is direct client-side risk. Audit should inventory third-party tags and check SRI/CSP, especially on payment pages.
An attacker exploited a flaw in Optimizely Web Experimentation and planted malicious code in scripts that customer sites load. Visitors to at least 178 organizations, including CNN, the BBC and Zoom, were exposed to card skimmers and iOS exploit kits. BleepingComputer also lists Fox News, Salesforce and GitLab. ([source](https://thehackernews.com/2026/11/hijacked-optimizely-scripts-served-card.html))

### 2. N-able ships N-central Hotfix 3 (17 flaws) while earlier bugs are exploited for crypto miners
**Why it matters for audit/CISO/VAPT:** RMM platforms have privileged reach into client estates. Confirm the hotfix level on every instance and whether management integrations are still enabled.
N-able released N-central 2026.4 Hotfix 3 as a critical security update. Attackers are already exploiting earlier N-central bugs to deploy crypto miners. ([source](https://thehackernews.com/2026/11/n-able-patches-17-n-central-flaws-as.html))

### 3. ScreenConnect attacks continue; SCKit targets unpatched systems
**Why it matters for audit/CISO/VAPT:** Remote-access tools are a common initial-access path. Verify client versions and hunt for unexpected remote sessions.
ConnectWise finished its investigation into unauthorized access to partner ScreenConnect environments. It says the technician client should be on 26.6.5 or later. Attacks on on-prem systems continue. ([source](https://thehackernews.com/2026/11/connectwise-warns-screenconnect-attacks.html))

### 4. AI-agent campaign hunts LiteLLM, Dify and other AI apps for provider keys
**Why it matters for audit/CISO/VAPT:** Stored LLM-provider keys are high-value secrets. Inventory internet-exposed AI gateways, check LiteLLM and Starlette versions, and rotate keys where exposure is possible.
Amazon's decoy servers captured attacker AI agents targeting LiteLLM, One API and Dify. SANS honeypots also see requests chaining CVE-2026-42271 and CVE-2026-48710 against LiteLLM/Starlette, which can lead to remote code execution. ([source](https://thehackernews.com/2026/11/amazon-uncovers-ai-agent-campaign.html))

### 5. Barracuda cloud breach tied to a stolen key and the ARTEX AI framework
**Why it matters for audit/CISO/VAPT:** A stolen cloud access key was the entry point. Review key lifecycle, scope and rotation, including for security vendors you depend on.
Attackers who breached Barracuda's cloud environment earlier this month used a stolen cloud access key and the ARTEX AI pentest framework. ([source](https://www.bleepingcomputer.com/news/security/barracuda-links-cloud-breach-to-artex-ai-powered-cyberattack/))

### 6. Google: attackers use AI agents to build exploits from patches
**Why it matters for audit/CISO/VAPT:** Patch-to-exploit time is shrinking. Set patch SLAs for internet-facing systems in days, and test detection against AI-driven scanning.
Google reports threat actors moving to autonomous multi-agent frameworks (ARTEX, CAIRN, CyberStrikeAI, PentAGI) that run multi-stage intrusions. Patch diffing is being automated into exploit development. ([source](https://thehackernews.com/2026/11/google-finds-hackers-using-ai-agents-to.html))

### 7. Six unpatched Danfoss refrigeration controller flaws allow takeover without login
**Why it matters for audit/CISO/VAPT:** OT/IoT devices with no patch path need compensating controls. Confirm building-automation controllers are not internet-reachable.
Midnight Blue found six flaws in AK-SM800A controllers, including a Host-header buffer overflow. No patch exists, and the devices lack stack canaries and ASLR. Isolation is the main mitigation. ([source](https://thehackernews.com/2026/11/six-unpatched-danfoss-refrigeration.html))

### 8. NoisyTCP: 11-year-old Linux kernel flaw lets attackers crash servers
**Why it matters for audit/CISO/VAPT:** Availability risk across most Linux fleets. Check kernel patch levels and schedule the fix.
The TCP bug affects almost all distributions and can crash nginx, Apache and SSH servers with default configs. A kernel.org patch exists. Disabling SYN cookies is an emergency workaround only. ([source](https://www.bleepingcomputer.com/news/linux/new-noisytcp-linux-kernel-flaw-lets-attackers-crash-servers/))
