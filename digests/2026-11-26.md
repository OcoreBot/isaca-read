# Security & Audit Digest — 2026-11-26

## Top items

### 1. Drupal warns of a second "highly critical" core flaw under active exploitation
**Why it matters for audit/CISO/VAPT:** The earlier Drupal KEV deadline (2026-11-27) is not enough on its own. A second CVE means patch verification must cover both.
Drupal has warned of CVE-2026-136716 (improper checking of exceptional conditions, CVSS not yet assigned), which it says is exploited in the wild. BleepingComputer reports the separate critical RCE has been exploited since at least Thursday. Check for unexpected admin accounts and new PHP files. ([source](https://thehackernews.com/2026/11/drupal-warns-of-new-highly-critical.html))

### 2. CISA adds 10 flaws to KEV: Mitel MiCollab, Juniper Session Smart, Xen Orchestra, Danfoss
**Why it matters for audit/CISO/VAPT:** Unified-communications and session-routing gear is common enterprise infrastructure, and most federal deadlines are 2026-11-28.
On 2026-11-25 CISA listed five Mitel MiCollab flaws (CVE-2026-133275, -133303, -133311, -133323, -133324), Vates Xen Orchestra (CVE-2026-133469), HPE Juniper Session Smart command injection (CVE-2026-103406) and three Danfoss AK-SM 800A flaws. CVE-2026-133311 is due 2026-12-09. ([source](https://thehackernews.com/2026/11/hackers-exploit-10-vulnerabilities.html))

### 3. 1Password breached through an employee GitHub account
**Why it matters for audit/CISO/VAPT:** A developer-account compromise reached production backend services. Review GitHub access controls, deploy approvals and vendor-trust assessments.
An employee's corporate GitHub account was used to deploy malicious code to backend services, exposing some customer data and source code. 1Password says customer vaults and secrets were not accessed. ([source](https://www.bleepingcomputer.com/news/security/1password-customer-data-stolen-after-employee-github-account-breach/))

### 4. Hex.pm registry hit by CVSS 10.0 RCE; six production servers compromised
**Why it matters for audit/CISO/VAPT:** Package-registry compromise is a supply-chain risk for Elixir/Erlang builds. Verify dependency integrity in pipelines that pulled from Hex.pm.
An attacker ran OS commands on six production servers on 2026-11-23. The flaw had been in the code since February 2016. ([source](https://thehackernews.com/2026/11/hackers-exploited-cvss-100-hexpm-rce.html))

### 5. PAN-OS attacks chain PHP2Shell and Fragnesia against exposed management interfaces
**Why it matters for audit/CISO/VAPT:** Another case for testing whether firewall management planes are internet-reachable.
Palo Alto Networks warns attackers are chaining the two flaws against devices with internet-exposed management interfaces. ([source](https://www.bleepingcomputer.com/news/security/palo-alto-networks-warns-of-fragnesia-flaw-exploited-in-pan-os-attacks/))

### 6. U.S. Treasury FinCEN takes systems offline after intrusion
**Why it matters for audit/CISO/VAPT:** A financial-regulator breach affects institutions that file sensitive data with it. Review what you submit and any notices received.
FinCEN reported unauthorized access to a limited subset of its systems and took some offline as a precaution. ([source](https://thehackernews.com/2026/11/us-treasurys-fincen-takes-some-systems.html))

### 7. Microsoft fixes Azure API Management Classic flaw exploited against customer secrets
**Why it matters for audit/CISO/VAPT:** Exploitation targeted customer secrets, so patching alone may not suffice. Consider rotating credentials held in affected instances.
The flaw was reported by Norway's NSM and has been exploited in attacks. ([source](https://thehackernews.com/2026/11/microsoft-fixes-azure-api-management.html))
