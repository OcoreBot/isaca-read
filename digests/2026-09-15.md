# Security & Audit Digest — 2026-09-15

## Top items

### 1. Cisco Secure Email Gateway SQL Injection Added to KEV, 3-Day Remediation Window
**Why it matters for audit/CISO/VAPT:** Perimeter email-security control with active exploitation and a compressed federal deadline (2026-09-17) — top patch-verification priority this cycle.
CISA added CVE-2026-76461, a SQL injection flaw in Cisco Secure Email Gateway, to the KEV catalog on 2026-09-14 based on evidence of active exploitation. ([source](https://www.cisa.gov/news-events/alerts/2026/09/14/cisa-adds-one-known-exploited-vulnerability-catalog))

### 2. Red Heron Exploits Gitea RCE Across Six Countries
**Why it matters for audit/CISO/VAPT:** Source-code repository compromise is a direct control failure; a suspected Chinese actor scanned 1,386 exposed Gitea instances and breached 13 organizations within days of disclosure.
Red Heron rapidly weaponized a recently disclosed Gitea RCE flaw to compromise internet-facing instances in a multi-national campaign. Audit scope should include Gitea discovery and patch validation for any dev infrastructure. ([source](https://thehackernews.com/2026/09/red-heron-exploits-gitea-rce-to.html))

### 3. Revolut Discloses Breach Exposing Financial Data and Passports
**Why it matters for audit/CISO/VAPT:** A threat actor impersonating a government agency obtained customer data from a major fintech — a control-failure lesson on third-party verification processes and vendor risk for staff using Revolut.
Revolut confirmed a breach after sharing customer data, including financial information and passport scans, with an attacker posing as a government agency. ([source](https://www.bleepingcomputer.com/news/security/revolut-discloses-data-breach-exposing-financial-info-passports/))

### 4. Japan's Digital Agency: VPN Flaw Exposed 246,000 Personnel Records
**Why it matters for audit/CISO/VAPT:** Government VPN infrastructure breach involving PII on staff; raises risk ratings for any organization with employees or partners in affected jurisdictions.
Japan's Digital Agency disclosed that a VPN vulnerability exposed roughly 246,000 rows of government employee personal data. ([source](https://www.bleepingcomputer.com/news/security/japans-digital-agency-says-vpn-flaw-exposed-246-000-personnel-records/))

### 5. Apple Patches Record 261 Vulnerabilities in iOS/macOS 27
**Why it matters for audit/CISO/VAPT:** Largest single-release patch volume in Apple's history increases deployment and regression risk; CISOs should validate third-party tool compatibility before broad rollout.
Apple's annual OS update fixed 261 vulnerabilities; a no-new-features 26.7 branch remains available for organizations wanting security fixes without feature changes. ([source](https://isc.sans.edu/diary/rss/33336))

### 6. Microsoft Ships Emergency Patch After September Updates Break RDS, Audio
**Why it matters for audit/CISO/VAPT:** Patch regressions on Remote Desktop Services illustrate why staged rollout rings and pre-deployment validation belong in patch-management SLAs.
Microsoft's September 2026 security updates caused RDS failures and broken USB audio on some Windows systems; an out-of-band emergency patch was issued to fix both plus refine a March privilege-escalation fix. ([source](https://www.bleepingcomputer.com/news/microsoft/microsoft-releases-emergency-windows-updates-to-fix-rds-failures/))

### 7. DDRop Attack Breaks Intel TDX and AMD SEV-SNP Confidential Computing
**Why it matters for audit/CISO/VAPT:** Undermines hardware-isolation assumptions behind confidential-computing risk models used for regulated workloads, though it requires physical access.
Researchers disclosed DDRop, which silently drops memory writes to make processors read stale encrypted data, defeating memory protections in Intel TDX and AMD SEV-SNP. ([source](https://thehackernews.com/2026/09/new-ddrop-attack-breaks-intel-tdx-and.html))

### 8. Telegram Desktop Flaw Lets Hidden JavaScript Exfiltrate Data From HTML Exports
**Why it matters for audit/CISO/VAPT:** Malicious code can persist in already-exported chat archives even after patching — a data-exfiltration path for organizations that export Telegram chats for records.
A crafted bot message could embed hidden JavaScript that runs when a user opens an HTML export of the chat locally. ([source](https://thehackernews.com/2026/09/telegram-desktop-flaw-lets-hidden.html))
