# Security & Audit Digest — 2026-10-16

## Top items

### 1. Ivanti Connect Secure Triple Zero-Day Chain — One Flaw Still Unpatched
**Why it matters for audit/CISO/VAPT:** A VPN appliance chain combining auth bypass, file write, and privilege escalation — with one link still open as of today's broadcast — is a live perimeter-access control failure that remote-access audits must track until full remediation.
Volexity disclosed on October 13 that an attacker chained three zero-days in Ivanti Connect Secure (including CVE-2026-104935, now on CISA's KEV) to gain root without logging in. Two of three flaws are patched; the privilege-escalation bug remained unpatched as of the SANS Stormcast October 16 broadcast. ([source](https://www.cisa.gov/news-events/alerts/2026/10/13/cisa-urges-patching-newly-exploited-vulnerability-ivanti-connect-secure))

### 2. Atlassian "Files or Directories Accessible" Flaw Added to CISA KEV
**Why it matters for audit/CISO/VAPT:** A federally mandated remediation deadline on widely deployed collaboration platforms directly tests patch-SLA compliance for any Atlassian-hosted environment in audit scope.
CISA added CVE-2026-21589, affecting multiple Atlassian products, to its KEV catalog on October 15 based on evidence of active exploitation, with federal remediation due October 18. ([source](https://www.cisa.gov/news-events/alerts/2026/10/15/cisa-adds-one-known-exploited-vulnerability-catalog))

### 3. SAP Cloud SDK for Python — CVSS 10.0 OAuth2 Credential Theft Flaw
**Why it matters for audit/CISO/VAPT:** Leaking OAuth2 client credentials to an attacker-controlled server from multi-tenant cloud applications undermines identity-and-access controls that audits rely on for cloud trust boundaries.
SAP disclosed on October 13 a maximum-severity flaw in its Cloud SDK for Python that can send an application's OAuth2 client credentials to a server an attacker controls, affecting multi-tenant apps on SAP Business Technology Platform. ([source](https://thehackernews.com/2026/10/sap-discloses-critical-cvss-10-flaw-in.html))

### 4. Next.js Ships Out-of-Band Patch for Two Critical RCE Flaws
**Why it matters for audit/CISO/VAPT:** Unauthenticated RCE in a widely used web framework's caching and image-processing paths is a direct exposure for any web-application audit scope and a fast-moving patch-management test.
Next.js released an out-of-band update on October 14 fixing unauthenticated RCE in React Server Components caching and in the librsvg SVG-processing library, plus a high-severity denial-of-service flaw. ([source](https://thehackernews.com/2026/10/nextjs-ships-out-of-band-patch-for-two.html))

### 5. NGINX Fixes Five Flaws, Including Possible RCE and a TLS Client-Cert Bypass
**Why it matters for audit/CISO/VAPT:** A TLS bug that can skip client-certificate checks undermines mutual-authentication controls, and a flaw dormant since 2005 is a reminder that patch cadence on core infrastructure can't lapse.
F5/NGINX shipped versions 1.30.6 and 1.31.7 on October 14, fixing three memory bugs that could crash a worker process or enable code execution, plus a TLS bug that may skip client-certificate checks. ([source](https://thehackernews.com/2026/10/nginx-fixes-5-flaws-including-possible.html))

### 6. Langflow Critical RCE Hit With 1,423 Honeypot Exploit Attempts
**Why it matters for audit/CISO/VAPT:** Active mass-scanning against an authenticated RCE in a popular AI agentic-workflow platform signals VAPT teams should prioritize AI-pipeline infrastructure in exploit-chain testing.
Security firm Previdian reported on October 15 that threat actors are actively exploiting a critical authenticated RCE flaw in Langflow, logging 1,423 honeypot exploit attempts against the open-source AI workflow platform. ([source](https://thehackernews.com/2026/10/langflows-critical-authenticated-rce.html))
