# Security & Audit Digest — 2026-11-04

## Top items

### 1. CISA adds WordPress core TOCTOU flaw (CVE-2026-119977) to KEV
**Why it matters for audit/CISO/VAPT:** A KEV entry in WordPress core with a 2026-11-06 federal deadline is a direct patch-verification item for any web estate in audit or VAPT scope.
CISA added the time-of-check/time-of-use race condition to the Known Exploited Vulnerabilities catalog on evidence of active exploitation. Confirm WordPress core versions across all managed and shadow sites. ([source](https://www.cisa.gov/news-events/alerts/2026/11/03/cisa-adds-one-known-exploited-vulnerability-catalog))

### 2. cPGuard update channel hijacked to push a backdoor and credential stealer
**Why it matters for audit/CISO/VAPT:** A trusted vendor update channel became a supply-chain vector onto Linux servers; audits should verify installed versions, review install logs and confirm credential rotation.
Attackers broke into cPGuard's update system on November 2 and pushed a script that installed a backdoor and collected password hashes and sensitive files. Per SANS, versions 5.88.12–5.88.19 delivered it; update to 5.88.25 or later and rotate credentials on affected hosts. ([source](https://thehackernews.com/2026/11/cpguard-update-channel-hijacked-to.html))

### 3. FBI attributes $6.43B Binance theft to North Korea's TraderTraitor
**Why it matters for audit/CISO/VAPT:** A concrete fake-recruitment and developer-tooling intrusion path into a major exchange; useful for testing developer-endpoint and social-engineering controls.
The FBI formally attributed the theft to TraderTraitor. Binance's post-mortem says a fake job interview and a tampered Homebrew install led to compromise of its wallet infrastructure. ([source](https://thehackernews.com/2026/11/fbi-links-north-koreas-tradertraitor-to.html))

### 4. Barracuda flaws chain to authorization bypass and root
**Why it matters for audit/CISO/VAPT:** Edge email-security appliances with root-level compromise are high-impact perimeter items; verify patch state and that admin interfaces are not internet-exposed.
Barracuda disclosed a pre-auth authorization bypass and a second flaw that together give root. Per SANS, the IDs are CVE-2026-116606 (CVSS 9.3, Email Security Gateway) and CVE-2026-111560 (CVSS 8.6, command injection). ([source](https://thehackernews.com/2026/11/barracuda-flaws-could-be-chained-to.html))

### 5. Red Hat patches 9.8-rated Linux kernel IPv4 TCP RCE; Ubuntu lags
**Why it matters for audit/CISO/VAPT:** A remote kernel flaw with a patch gap across distributions is a fleet-patch-verification item.
Fixed kernels for a use-after-free in the IPv4 TCP code are available for RHEL 8, 9 and 10. Ubuntu's fixes for its three newest LTS releases are only in opt-in testing, with no general-release date. ([source](https://thehackernews.com/2026/11/red-hat-patches-98-rated-linux-tcp-rce.html))

### 6. Refrigeration controllers at European supermarkets remotely altered
**Why it matters for audit/CISO/VAPT:** Internet-exposed building and OT controls with weak defaults have direct physical and food-safety impact.
Attackers changed refrigeration settings at supermarkets in Belgium, Sweden, Estonia and elsewhere overnight into November 2, warming fridges and freezers and forcing some stores to pull food. SANS notes reports of default passwords on exposed controllers. ([source](https://thehackernews.com/2026/11/second-wave-of-cyberattacks-hits.html))

### 7. CVSS 10.0 LXD and MicroCloud flaw allows client impersonation
**Why it matters for audit/CISO/VAPT:** Virtualization management APIs are high-value targets; confirm API exposure and client certificate trust lists.
Canonical's LXD and MicroCloud let a network attacker authenticate as a trusted client without its private key, provided they hold its public certificate and can reach the HTTPS API. ([source](https://thehackernews.com/2026/11/critical-lxd-and-microcloud-flaw-cvss.html))

### 8. Polymarket traders robbed of ~$2.7M via hijacked third-party script
**Why it matters for audit/CISO/VAPT:** Classic client-side supply-chain compromise; supports reviews of third-party JavaScript inventory, SRI and CSP.
Malicious code replaced a page-speed script loaded from an outside provider on October 29, selling some signed-in traders' positions and moving funds to the attackers. Polymarket is refunding users. ([source](https://thehackernews.com/2026/11/hackers-steal-about-27-million-from.html))

### 9. Google: LLMjacking costing some enterprises up to $1M
**Why it matters for audit/CISO/VAPT:** Stolen cloud and AI API keys now carry direct financial exposure; check key scoping, spend alerts and secrets rotation.
Google warned attackers are hijacking enterprise LLM access to run costly workloads; BleepingComputer reports some organizations losing over $100,000 per day. ([source](https://thehackernews.com/2026/11/google-warns-llmjacking-attacks-are.html))
