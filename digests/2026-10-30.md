# Security & Audit Digest — 2026-10-30

## Top items

### 1. GitLab CVSS-10.0 flaw now actively exploited, already probed on Alpine Linux's own server
**Why it matters for audit/CISO/VAPT:** Maximum-severity unauthenticated RCE added to CISA's KEV catalog with a federal remediation deadline of tomorrow, 2026-11-01 — treat as an emergency change, not routine patching.
CVE-2026-97229, an integer overflow in GitLab CE/EE, was added to KEV on October 29 after an attacker tried exploiting it against Alpine Linux's own GitLab instance just a week after the patch shipped. Audit should confirm GitLab versions and patch evidence today. ([The Hacker News](https://thehackernews.com/2026/10/attacker-tried-to-exploit-alpine-linuxs.html))

### 2. Cisco ASA/FTD firewall flaw exploited to crash VPN devices, federal deadline tomorrow
**Why it matters for audit/CISO/VAPT:** A second KEV addition sharing the same November 1 deadline as item 1 — perimeter VPN availability is at risk, not just confidentiality.
CVE-2026-76418, an unchecked return value causing NULL pointer dereference in Cisco Secure Firewall ASA/FTD, is being exploited in the wild to remotely crash devices. Cisco has patches available; audit should verify deployment before the deadline. ([BleepingComputer](https://www.bleepingcomputer.com/news/security/cisco-warns-of-firewall-zero-day-exploited-to-crash-ssl-vpn-devices/))

### 3. Anthropic's Claude builds a working exploit for a 9.8-CVSS Linux kernel flaw in 48 minutes
**Why it matters for audit/CISO/VAPT:** A concrete, dated example of AI compressing time-to-exploit for unauthenticated root RCE — patch SLAs calibrated to human attacker speed are now outdated.
CVE-2026-98432 is a race-condition use-after-free in the Linux kernel's Multipath TCP listener, affecting Ubuntu, RHEL, and other distributions. Anthropic said its AI model independently found and weaponized the flaw on October 27. VAPT teams should factor AI-assisted exploit speed into patch-window risk models. ([The Hacker News](https://thehackernews.com/2026/10/linux-kernel-tcp-flaw-with-98-cvss.html))

### 4. Binance discloses breach affecting $6.3 billion, nearly $3 billion frozen
**Why it matters for audit/CISO/VAPT:** A top-tier exchange breach of this scale is a live control-failure case study; any organization with crypto treasury exposure or Binance-dependent payment flows needs an immediate exposure check.
Binance said a security incident on October 30 impacted roughly $6.3 billion in assets, with Tether and Circle helping freeze nearly $3 billion on-chain so far. Scope and root cause are still under investigation. ([The Hacker News](https://thehackernews.com/2026/10/binance-suffers-security-breach.html))

### 5. 26,400 working cloud and AI credentials found exposed in public Gitee repos
**Why it matters for audit/CISO/VAPT:** A secrets-hygiene failure at scale — every one of the tested credentials still worked, meaning exposure windows for leaked keys are being badly underestimated.
A researcher scanning 7.25 million public Gitee repositories found 26,400 valid cloud and AI-provider credentials still active. Audit should extend secret-scanning programs to cover Gitee and similar repos, not just GitHub/GitLab. ([The Hacker News](https://thehackernews.com/2026/10/26400-valid-cloud-and-ai-credentials.html))

### 6. Hugging Face GPU-mining malware campaign returns within days of takedown
**Why it matters for audit/CISO/VAPT:** Shows AI model supply-chain attacks are now a repeatable, fast-respawning threat class, not a one-off — self-hosted AI inference infrastructure needs its own controls.
Fake Qwen2 repositories on Hugging Face (32,000+ downloads) deploy fileless crypto miners and reverse shells on GPU hosts when loaded with `trust_remote_code=True`. Audit should inventory self-hosted model deployments and disable unneeded remote-code execution. ([BleepingComputer](https://www.bleepingcomputer.com/news/security/hugging-face-malware-campaign-returns-to-hijack-gpus-for-crypto-mining/))

### 7. Siemens patches Mendix SAML authentication-bypass flaw
**Why it matters for audit/CISO/VAPT:** SAML assertion replay bypassing IdP-initiated auth undermines identity-federation assumptions for any Mendix app relying on SSO.
Siemens released updated Mendix SAML module versions fixing an unauthenticated bypass that let attackers replay a valid SAML assertion to gain access. Audit should confirm patch adoption for any Mendix deployments using SAML. ([CISA](https://www.cisa.gov/news-events/ics-advisories/icsa-26-302-01))

### 8. Telegram Android flaw chain gave full device takeover from a voice call
**Why it matters for audit/CISO/VAPT:** Low-friction attack path — only a phone number is needed — that bypasses typical credential-theft detection; relevant to any BYOD policy permitting Telegram.
Three chained bugs in Telegram for Android allowed code execution once a victim answered a call from an ordinary Telegram account. Telegram has shipped a fix. VAPT teams should flag Telegram in mobile threat models. ([The Hacker News](https://thehackernews.com/2026/10/telegram-android-flaw-lets-attackers.html))
