# Security & Audit Digest — 2026-11-05

## Top items

### 1. CISA adds patched Apple flaw (CVE-2024-27834) to KEV after infostealer attacks
**Why it matters for audit/CISO/VAPT:** A KEV entry with an 2026-11-18 federal deadline is a patch-verification item for every managed Apple fleet, including laptops and phones.
CISA added the medium-severity flaw affecting multiple Apple operating systems after reports of active exploitation. Attackers are using the already-patched bug to deliver information-stealing malware. ([source](https://thehackernews.com/2026/11/hackers-exploit-patched-apple-flaw-to.html))

### 2. Zyxel patches GS1900 switch zero-day exploited against nearly 1,000 devices
**Why it matters for audit/CISO/VAPT:** Network infrastructure compromised for configuration and credential theft means credentials stored on these switches should be treated as exposed.
Zyxel fixed a zero-day in its GS1900 series switches. Attackers used it to compromise nearly 1,000 devices worldwide and steal configuration files and credentials. ([source](https://www.bleepingcomputer.com/news/security/zyxel-fixes-zero-day-exploited-to-hack-nearly-1-000-network-switches/))

### 3. Xen flaws let one malicious VM read and write any other VM's memory
**Why it matters for audit/CISO/VAPT:** This is a cross-tenant isolation failure, so check Xen patch levels and multi-tenant assumptions on in-scope hosts.
Two Xen flaws let a malicious guest read and write memory of other guests on the same host, including dom0. Patches are available and there is no known mitigation. ([source](https://thehackernews.com/2026/11/xen-hypervisor-flaws-let-one-malicious.html))

### 4. Debian and Ubuntu APT flaw lets on-path attackers swap verified packages for root code execution
**Why it matters for audit/CISO/VAPT:** It hits the update path of Debian/Ubuntu fleets. Verify APT versions and whether package traffic can be tampered with in transit.
An attacker who can modify package downloads can replace a checked package with their own, and the code runs as root. Debian, Ubuntu and the APT developers published advisories on November 4. ([source](https://thehackernews.com/2026/11/debian-and-ubuntu-apt-flaw-lets-mitm.html))

### 5. OpenAI pipeline produces 948 Linux privilege-escalation findings in a 30-hour run
**Why it matters for audit/CISO/VAPT:** Automated LPE discovery at scale argues for tighter Linux patch SLAs and a kernel-hardening review, and it affects how VAPT teams scope local-escalation testing.
OpenAI says a pipeline built on an upcoming cyber-focused model validated and patched 948 Linux local privilege-escalation flaws. It analysed 2,308 candidates at about $1.2 million in API cost. ([source](https://thehackernews.com/2026/11/openai-ai-pipeline-generates-948-linux.html))

### 6. Critical Rails flaw allows server file writes via crafted ImageMagick uploads
**Why it matters for audit/CISO/VAPT:** This is an unauthenticated file-write in a common framework. Check Rails versions and ImageMagick use in upload pipelines.
Rails apps that process uploads with ImageMagick are exposed to arbitrary file writes by an unauthenticated attacker. The fix is in Rails 8.1.4.1 and later patch releases. ([source](https://thehackernews.com/2026/11/critical-rails-flaw-lets-attackers.html))

### 7. SonicWall will not patch end-of-life GMS flaws (CVE-2026-109593, CVSS 9.1)
**Why it matters for audit/CISO/VAPT:** An unpatchable EoL management platform needs decommissioning or isolation, and a documented risk acceptance if it stays.
Two flaws affect SonicWall GMS 9.5.2 and earlier. One is unauthenticated and can expose files, and the other can alter database records. ([source](https://thehackernews.com/2026/11/sonicwall-wont-patch-eol-gms-flaws-that.html))

### 8. Google's November Android bulletin fixes a critical zero-click RCE (CVE-2026-58868)
**Why it matters for audit/CISO/VAPT:** Mobile compliance check: confirm devices are at patch level 2026-11-01 or later, especially BYOD.
The flaw affects Android 14 through 17 and can allow remote code execution with no user interaction. ([source](https://thehackernews.com/2026/11/google-patches-critical-android-flaw.html))

### 9. CryptoPayment Gateway WordPress plugin: unpatched CVSS 10.0 flaw under exploit attempts
**Why it matters for audit/CISO/VAPT:** There is no fix, so inventory plugins and apply compensating controls or remove it.
Defused Cyber reports attempts to exploit CVE-2026-81648, which can expose wallet credentials. ([source](https://thehackernews.com/2026/11/attackers-target-unpatched.html))
