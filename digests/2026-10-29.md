# Security & Audit Digest — 2026-10-29

## Top items

### 1. CISA KEV adds VMware ESX logging gap and Linux kernel flaw as actively exploited
**Why it matters for audit/CISO/VAPT:** Two more KEV entries with near-term federal deadlines (Oct 31 and Nov 11) — audit teams should fold these into existing PHP2Shell/Brotli patch tracking rather than treating them as separate workstreams.
CISA added CVE-2026-41709 (Broadcom VMware ESX insufficient logging) and CVE-2026-46300 (Linux kernel missing variable initialization) to the KEV catalog on October 28, confirming active exploitation of both. ([CISA](https://www.cisa.gov/news-events/alerts/2026/10/28/cisa-adds-two-known-exploited-vulnerabilities-catalog))

### 2. PHP2Shell exploitation roots 25 servers, breaches a U.S. government-affiliated network
**Why it matters for audit/CISO/VAPT:** Confirms real-world damage from the PHP2Shell flaws beyond the PAN-OS targeting reported earlier this week, with evidence the intrusion was AI-assisted — a live example of AI lowering the bar for mass exploitation.
A suspected China-nexus actor used PHP2Shell to compromise 25 servers, including a breach of a U.S. government-affiliated network. Audit should verify PHP patch compliance and review logging coverage for the affected period. ([The Hacker News](https://thehackernews.com/2026/10/php2shell-attack-roots-25-servers.html))

### 3. LiteLLM CVSS-10 flaw exposes AI provider master keys and API credentials
**Why it matters for audit/CISO/VAPT:** Any organization routing LLM traffic through LiteLLM has effectively exposed its AI supply-chain credentials — a new category of key material most patch-management programs don't yet track.
An unauthenticated arbitrary file-read vulnerability in the popular LLM-routing framework exposes master keys and connected provider (Claude, ChatGPT, etc.) API keys. Patched in 1.103.10, 1.104.8, 1.105.6, and 1.106.5+. Audit: inventory LiteLLM deployments and rotate exposed keys. ([SANS Stormcast](https://isc.sans.edu/podcastdetail/10156))

### 4. 16-year-old UEFI/EDK II flaw allows pre-boot code execution — no patch yet
**Why it matters for audit/CISO/VAPT:** Code execution before the OS loads defeats every OS-level control; any network-booting infrastructure (labs, data centers, PXE deployment pipelines) is exposed with no fix currently available.
A critical flaw in EDK II, the UEFI firmware base used by most hardware vendors, lets an attacker send oversized ICMP errors during network boot to run code before Secure Boot engages. Audit should inventory PXE-boot-enabled systems and restrict network access to boot infrastructure as a mitigating control. ([The Hacker News](https://thehackernews.com/2026/10/critical-16-year-old-uefi-flaw-can-run.html))

### 5. ShinyHunters' Oracle PeopleSoft exploit was three chained flaws, not one
**Why it matters for audit/CISO/VAPT:** Shows attackers are chaining SSRF, auth bypass, and RCE into a single exploit path shipped under one CVE — a reminder that "patched" doesn't always mean the underlying attack surface is fully understood.
Researchers revealed the PeopleSoft bug ShinyHunters has exploited since May, patched by Oracle in June under CVE-2026-35273, is actually three flaws chained together. VAPT teams should re-test PeopleSoft environments for partial-patch gaps rather than relying on the single CVE as proof of remediation. ([The Hacker News](https://thehackernews.com/2026/10/shinyhunters-exploited-oracle.html))

### 6. Tailscale SSH flaws let a compromised device reach other servers as root
**Why it matters for audit/CISO/VAPT:** Breaks a core zero-trust assumption — that compromising one endpoint shouldn't grant privileged access elsewhere on the mesh.
Tailscale 1.104.4 fixes flaws in its built-in SSH server's connection forwarding that let an attacker on one device reach root-only services and files on other connected servers. Patch immediately and review Tailscale SSH ACLs. ([The Hacker News](https://thehackernews.com/2026/10/tailscale-patches-ssh-flaws-that-could.html))

### 7. Logic bugs alone bypassed Microsoft Edge's sandbox at Pwn2Own
**Why it matters for audit/CISO/VAPT:** Demonstrates a full sandbox-escape chain built entirely from logic flaws, no memory corruption — a technique class that bypasses typical memory-safety mitigations and complicates browser-hardening assumptions.
Orange Tsai (DEVCORE) published the full method behind the $175,000 Pwn2Own win, five months after the chain was patched. VAPT teams should factor logic-bug chaining into browser threat models alongside memory-safety bugs. ([The Hacker News](https://thehackernews.com/2026/10/researcher-reveals-how-logic-bugs-alone.html))
