# Security & Audit Digest — 2026-10-02

## Top items

### 1. Fortinet FortiMail path traversal exploited as zero-day, added to CISA KEV
**Why it matters for audit/CISO/VAPT:** A critical pre-auth RCE in a widely deployed email gateway is under active attack with a federal remediation deadline of 2026-10-04 — audit teams should confirm patch status on all FortiMail instances immediately.
CVE-2026-104286, a path-traversal flaw in Fortinet FortiMail, lets attackers execute arbitrary code on vulnerable gateways. CISA added it to the KEV catalog on October 1 following confirmed in-the-wild exploitation. ([source](https://www.bleepingcomputer.com/news/security/fortinet-warns-of-critical-fortimail-flaw-exploited-in-zero-day-attacks/))

### 2. CISA warns of critical pre-auth RCE in MikroTik RouterOS
**Why it matters for audit/CISO/VAPT:** RouterOS runs core network infrastructure at scale; an unauthenticated RCE here is a network-integrity risk that warrants immediate inventory and patch prioritization, not just a routine advisory.
CVE-2026-84411 affects RouterOS versions before 7.24 and allows remote code execution or denial of service without credentials. CISA published the advisory September 29. ([source](https://www.bleepingcomputer.com/news/security/cisa-warns-of-critical-pre-auth-rce-flaw-in-mikrotik-routeros/))

### 3. Pentagon HR system breach exposes data of nearly 3 million service members
**Why it matters for audit/CISO/VAPT:** A major federal breach of personnel data is a control-failure case study — audit teams should use it to re-examine detection timelines and third-party/HR-system risk in their own environments.
The Defense Manpower Data Center disclosed that attackers breached its human resources management system in October 2025, stealing personal data on nearly 3 million military personnel; the exposure was only recently disclosed. ([source](https://www.bleepingcomputer.com/news/security/hackers-breach-pentagon-human-resources-management-system-steal-data-of-nearly-3-million-people/))

### 4. Kiteworks patches max-severity code injection in Email Protection Gateway
**Why it matters for audit/CISO/VAPT:** Email gateways sit on the perimeter; a max-severity injection flaw in a widely used filtering product demands urgent patch confirmation and post-exploitation hunting, not just a changelog read.
Kiteworks shipped emergency fixes for 126 vulnerabilities, including a maximum-severity code-injection bug in its Email Protection Gateway (EPG) used to filter enterprise mail. ([source](https://www.bleepingcomputer.com/news/security/kiteworks-patches-max-severity-email-protection-gateway-code-injection-vulnerability/))

### 5. Public PoC emerges for exploited Apple CoreGraphics flaw, PDF delivery path suspected
**Why it matters for audit/CISO/VAPT:** New since yesterday's KEV listing — a public proof-of-concept plus a plausible messaging-app delivery path (a crafted PDF via WhatsApp) means VAPT teams should expect broader exploitation attempts soon, not just narrowly targeted ones.
Researchers published the first public PoC for CVE-2026-86950, triggered by a malicious PDF with a crafted embedded font that crashes unpatched CoreGraphics; WhatsApp's PDF handling is being examined as a possible delivery route. ([source](https://thehackernews.com/2026/10/apple-coregraphics-poc-emerges-as.html))

### 6. WordPress backdoor rebuilds itself via filesystem, database, and shared memory
**Why it matters for audit/CISO/VAPT:** Multi-layer persistence defeats single-touch cleanup — incident responders and auditors reviewing WordPress compromises need to check all three storage layers, not just files, before declaring remediation complete.
Researchers detailed a backdoor (codenamed SC) that re-creates itself from redundant copies stored across the filesystem, the database, and shared memory, so removing any one component alone fails to clear the infection. ([source](https://thehackernews.com/2026/10/wordpress-backdoor-rebuilds-itself.html))
