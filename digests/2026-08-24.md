# Security & Audit Digest — 2026-08-24

## Top items

### 1. Zimbra Collaboration Suite Command Injection Added to CISA KEV
**Why it matters for audit/CISO/VAPT:** Actively exploited OS command injection in a widely deployed collaboration platform, with a federal remediation deadline landing today. Any organization running Zimbra should treat this as an emergency patch.
CVE-2026-73570 (OS command injection) was added to CISA's Known Exploited Vulnerabilities catalog on 2026-08-21, with federal agencies required to remediate by 2026-08-24. ([source](https://www.cisa.gov/news-events/alerts/2026/08/21/cisa-adds-one-known-exploited-vulnerability-catalog))

### 2. GitLab CVE-2026-19478 Under Active Exploitation Within Days of Disclosure
**Why it matters for audit/CISO/VAPT:** Unauthenticated code injection against a core source-control platform; attackers can tamper with protected branches. Audit source-code-integrity controls and confirm patch status immediately.
GitLab's CVE-2026-19478 (CVSS 9.4) allows an unauthenticated attacker to modify or delete protected branches, and watchTowr reports exploitation began within days of disclosure. ([source](https://thehackernews.com/2026/08/gitlab-cve-2026-19478-comes-under.html))

### 3. CISA Orders Federal Patching of Actively Exploited TrueConf Server Flaws
**Why it matters for audit/CISO/VAPT:** Active exploitation plus a binding federal directive signals real-world attacker interest; any TrueConf deployments need inventory and immediate patching regardless of sector.
CISA ordered U.S. federal agencies to prioritize patching two actively exploited vulnerabilities in the self-hosted TrueConf Server video-conferencing platform. ([source](https://www.bleepingcomputer.com/news/security/cisa-orders-feds-to-patch-actively-exploited-trueconf-server-flaws/))

### 4. Cisco Patches Nine Crosswork/Secure Workload Flaws, Five at CVSS 10.0
**Why it matters for audit/CISO/VAPT:** Maximum-severity flaws in network orchestration and workload-security infrastructure are a compliance and resilience priority; verify patch status across all instances.
Cisco released updates for Crosswork Data Gateway, Crosswork Network Controller, and Secure Workload as part of an ongoing internal security review, with five of nine flaws rated CVSS 10.0. ([source](https://thehackernews.com/2026/08/cisco-patches-nine-crosswork-and-secure.html))

### 5. Microsoft Patches CVSS 10.0 Entra ID Remote Code Execution Flaw
**Why it matters for audit/CISO/VAPT:** A maximum-severity flaw in enterprise identity infrastructure warrants urgent patch verification even though Microsoft later corrected its advisory to say it was not exploited in the wild.
Microsoft patched a CVSS 10.0 RCE flaw in Entra ID; the bulletin's "Exploited" field was initially marked "Yes" but corrected to "No" on 2026-08-21. ([source](https://thehackernews.com/2026/08/microsoft-entra-id-flaw-cvss-100.html))

### 6. Microsoft Defender's Own Driver Can Be Weaponized to Kill Security Software
**Why it matters for audit/CISO/VAPT:** Abuses a legitimately signed boot-time driver rather than a software flaw, so patching alone won't fix it — VAPT teams should add this technique to endpoint-bypass test plans across Windows 7 through 11 25H2.
Check Point disclosed a technique using Microsoft Defender's signed boot-time remediation driver to perform arbitrary kernel-level file and registry operations. ([source](https://thehackernews.com/2026/08/microsoft-defenders-own-driver-can-be.html))

### 7. Trojanized npm Packages Deliver AI-Assisted RedC2 4.0 Linux Backdoor
**Why it matters for audit/CISO/VAPT:** Supply-chain compromise via package registries remains a top vector; CISOs should ensure SCA/dependency scanning covers newly disclosed malicious packages.
Fourteen npm packages posing as calendar and streak utilities were found delivering RedC2 4.0, an AI-assisted Linux implant with C2 capability. ([source](https://thehackernews.com/2026/08/14-trojanized-npm-packages-drop-redc2.html))

### 8. Over 9,300 Leaked AWS Keys Still Active, Granting Full Account Control
**Why it matters for audit/CISO/VAPT:** Direct evidence of a widespread cloud-credential hygiene gap; a strong prompt for a credential-exposure audit and rotation policy review.
More than 9,300 AWS access keys exposed in public repositories between August 2022 and August 2026 remain valid, giving attackers full account control. ([source](https://www.bleepingcomputer.com/news/security/hundreds-of-leaked-aws-keys-give-full-control-over-corporate-accounts/))
