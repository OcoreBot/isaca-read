# Security & Audit Digest — 2026-09-28

## Top items

### 1. Citrix NetScaler: two RCE zero-days actively exploited, eight CVEs patched
**Why it matters for audit/CISO/VAPT:** Internet-facing ADC/Gateway appliances are prime perimeter targets; confirmed in-the-wild RCE demands emergency patching and KEV-driven remediation tracking.
Citrix confirmed on Sep 27 that CVE-2026-88771 and CVE-2026-88772 are being exploited against NetScaler ADC/Gateway; six additional flaws (including HTTP request smuggling and TCP sequence prediction) were also fixed. Both CVEs were added to the CISA KEV catalog with a federal remediation deadline of 2026-09-30. ([source](https://www.cisa.gov/news-events/alerts/2026/09/27/critical-zero-day-vulnerabilities-exploited-citrix-netscaler-adc-gateway))

### 2. ShinyHunters bypass WAFs to resume mass Oracle PeopleSoft exploitation
**Why it matters for audit/CISO/VAPT:** Shows a live WAF-evasion technique (URL-encoding) defeating a control auditors may have credited as mitigating; PeopleSoft holds HR/payroll data, raising data-protection exposure.
Google reports renewed, widespread exploitation of CVE-2026-35273 (CVSS 9.8) after ShinyHunters found a simple encoding trick to slip past WAF rules meant to block the flaw, deploying web shells across multiple sectors. ([source](https://thehackernews.com/2026/09/attackers-bypass-wafs-to-exploit-oracle.html))

### 3. Kiteworks tells customers to shut down servers over credible zero-day threat
**Why it matters for audit/CISO/VAPT:** A federal-intelligence-driven precautionary shutdown of a secure file-transfer platform is a board-level incident-response event with direct business-continuity and vendor-risk implications.
Kiteworks (formerly Accellion) urged customers worldwide to power down systems for a six-hour window over the weekend after receiving credible threat intelligence of an imminent attack; no CVE has been disclosed yet. ([source](https://thehackernews.com/2026/09/kiteworks-urges-customers-to-shut-down.html))

### 4. Microsoft SharePoint code injection flaw added to KEV
**Why it matters for audit/CISO/VAPT:** SharePoint underpins enterprise document workflows; active exploitation plus a federal deadline (Sep 28) makes this a same-week patch-compliance item for auditors to verify.
CISA added CVE-2026-65660 to its Known Exploited Vulnerabilities catalog on Sep 25 based on confirmed active exploitation. ([source](https://nvd.nist.gov/vuln/detail/CVE-2026-65660))

### 5. WSO2 authentication bypass exploited, added to KEV
**Why it matters for audit/CISO/VAPT:** An auth-bypass in an identity/SSO platform has cascading blast radius across every downstream application relying on it for access control.
CVE-2026-5430, a critical authentication bypass affecting multiple WSO2 products, is under active exploitation per CISA and was added to the KEV catalog. ([source](https://thehackernews.com/2026/09/wso2-and-adobe-commerce-flaws-exploited.html))

### 6. MikroTik RouterOS workflow-enforcement flaw exploited
**Why it matters for audit/CISO/VAPT:** Edge/perimeter routers are frequently unmanaged in asset inventories; active exploitation at this layer can undermine network segmentation controls that audits assume are intact.
CVE-2026-67279 was added to CISA's KEV catalog on Sep 25 with confirmed in-the-wild exploitation; federal remediation was due Sep 28. ([source](https://nvd.nist.gov/vuln/detail/CVE-2026-67279))

### 7. Roundcube pre-auth SQL injection actively exploited
**Why it matters for audit/CISO/VAPT:** Unauthenticated database access via webmail is a low-skill, high-impact vector; the Canadian Centre for Cyber Security's warning signals broad targeting worth checking against exposed instances.
CVE-2026-48842 (CVSS 8.1), a pre-authentication SQL injection in Roundcube's virtuser_query plugin, is being actively exploited. ([source](https://thehackernews.com/2026/09/roundcube-pre-auth-sql-injection-flaw.html))

### 8. WordPress Core remote file inclusion added to KEV
**Why it matters for audit/CISO/VAPT:** Given WordPress's massive install base, this is a high-volume, low-effort attack vector that should be prioritized in any external attack-surface review.
CISA added CVE-2026-87902 to the KEV catalog on Sep 25, with federal remediation due Sep 28. ([source](https://nvd.nist.gov/vuln/detail/CVE-2026-87902))
