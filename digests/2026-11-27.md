# Security & Audit Digest — 2026-11-27

## Top items

### 1. Unpatched Cacti zero-day (4HTTP2SHELL) gives RCE in four HTTP requests via guest access
**Why it matters for audit/CISO/VAPT:** A public PoC exists and no fix or CVE is out yet. Monitoring servers often hold device credentials and sit in privileged network zones.
Researchers published a PoC for a new Cacti flaw, tracked as 4HTTP2SHELL, that reportedly gives remote code execution through guest access. Check for internet-reachable Cacti instances and whether guest access is enabled, and watch for a vendor fix. Details beyond the headline were not verified. ([source](https://thehackernews.com/2026/11/unpatched-cacti-zero-day-enables-rce-in.html))

### 2. Check Point Security Management servers: 24 compromised in suspected AI-driven campaign
**Why it matters for audit/CISO/VAPT:** Management servers control policy for many firewalls, so one compromise has wide reach. Audit console exposure, admin account hygiene and logs.
An unknown actor using AI-driven offensive tooling compromised 24 Check Point Security Management servers across 22 organizations, per GreyNoise tracking. ([source](https://thehackernews.com/2026/11/hackers-compromise-24-check-point.html))

### 3. Switzerland confirms AI-agent attacks breached critical infrastructure operators
**Why it matters for audit/CISO/VAPT:** This is a national agency confirming autonomous attacks in real cases. Update threat models and test detection and response timing, not only point controls.
Swiss authorities said AI-agent-driven attacks succeeded in four of five confirmed cases, the first in the country. Three hit critical infrastructure operators. Italy issued a parallel warning. ([source](https://thehackernews.com/2026/11/switzerland-confirms-ai-assisted.html))

### 4. NFS2ROOT: 12-year-old Linux kernel NFS server flaw allows remote root (CVE-2026-99362)
**Why it matters for audit/CISO/VAPT:** NFS exports are common on Linux servers and NAS. Exploitation is not confirmed in the source.
BleepingComputer reports a critical flaw in the Linux kernel NFS server that lets remote attackers gain root. Check kernel versions, restrict NFS to trusted networks and track vendor advisories. ([source](https://www.bleepingcomputer.com/news/security/new-nfs2root-linux-flaw-can-let-attackers-gain-root-privileges/))

### 5. WordPress removes six backdoored WP Connect plugins after suspected developer-account compromise
**Why it matters for audit/CISO/VAPT:** This is another supply-chain case through a compromised publisher account. Check plugin inventories and whether sites auto-update.
The plugins were backdoored on 2026-11-22 to allow arbitrary code execution. WordPress removed them before the malicious releases went live. ([source](https://thehackernews.com/2026/11/wordpress-blocks-six-backdoored-wp.html))

### 6. North Korea-linked PolinRider poisons 7,600+ GitHub repositories
**Why it matters for audit/CISO/VAPT:** Developer-repo poisoning bypasses perimeter controls. Review dependency vetting and repository integrity checks.
The campaign plants a Python loader in a small `utils` package or in `conftest.py`. SafeDep says activity may date back to February 2025. ([source](https://thehackernews.com/2026/11/north-korea-linked-polinrider-poisons.html))
