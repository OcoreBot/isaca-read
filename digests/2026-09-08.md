# Security & Audit Digest — 2026-09-08

## Top items

### 1. N-able N-Central Max-Severity RCE — Fourth Hotfix in Five Weeks
**Why it matters for audit/CISO/VAPT:** RMM platforms are high-value lateral-movement targets; a fourth emergency hotfix in five weeks signals a persistent vulnerability window and likely ongoing compromise for unpatched on-prem instances.
N-able shipped Hotfix 4 for a maximum-severity RCE affecting all on-premises N-central builds below 2026.3.1.14, including servers already updated to Hotfix 3. N-able's incident notice indicates active exploitation. Inventory and patch immediately. ([source](https://www.bleepingcomputer.com/news/security/n-able-patches-max-severity-n-central-flaw-amid-ongoing-attacks/))

### 2. Magento/Adobe Commerce "StyleSmuggler" Zero-Day — Now Deploying Linux Backdoors
**Why it matters for audit/CISO/VAPT:** Unauthenticated RCE with no vendor patch and confirmed backdoor deployment is a same-day incident-response trigger for any e-commerce environment.
The unpatched Magento/Adobe Commerce flaw Sansec disclosed on Sep 5 now has a name — "StyleSmuggler" — and BleepingComputer reports attackers are using it to install Linux backdoors on compromised stores. Still no official patch; apply vendor workarounds now. ([source](https://www.bleepingcomputer.com/news/security/magento-stylesmuggler-zero-day-exploited-to-deploy-linux-backdoor/))

### 3. BigBear 2.0 Phishing-as-a-Service — MFA Bypassed at 258 Organizations
**Why it matters for audit/CISO/VAPT:** Demonstrates that email security plus MFA alone is insufficient without conditional access and session-risk detection — a board-level control-failure story.
CloudSEK reports the Evilginx2-based BigBear 2.0 AitM framework ran 42 VPS nodes, harvested 5,137 Microsoft 365 credentials, bypassed MFA on 474 accounts, and hit 258 organizations across 40+ countries; custom JS disabled FIDO2/WebAuthn to force weaker auth. ([source](https://www.bleepingcomputer.com/news/security/bigbear-microsoft-365-phishing-service-bypassed-mfa-at-258-organizations/))

### 4. Mathspace Breach — 1M+ Students and Staff via Unpatched Metabase
**Why it matters for audit/CISO/VAPT:** A textbook internal-tool exposure: an internally-facing analytics platform became the breach vector, underscoring the need to inventory and patch non-customer-facing systems.
Mathspace disclosed that attackers breached its internal Metabase reporting system, exposing data on more than 1 million students, staff, and parents. No patch details published yet. ([source](https://www.bleepingcomputer.com/news/security/mathspace-discloses-data-breach-affecting-over-1-million-people/))

### 5. Fake IT Help-Desk Calls Drive M365 Extortion Campaign
**Why it matters for audit/CISO/VAPT:** Blends vishing with AitM token theft to defeat MFA — directly relevant to reviewing help-desk identity-verification and privileged-account recovery procedures.
Threat hunters describe a widespread cluster targeting Microsoft 365 and other SaaS tenants via IT help-desk vishing, adversary-in-the-middle token theft, and extortion. ([source](https://thehackernews.com/2026/09/microsoft-365-attackers-use-help-desk.html))

### 6. Rogue ScreenConnect Clients Spread Worm-Like VBScript Chain
**Why it matters for audit/CISO/VAPT:** Compromised RMM tooling propagating malware to every newly connected host is a supply-chain/lateral-movement scenario auditors should test for in remote-access reviews.
Huntress documented three unrelated incidents where attackers abused compromised ConnectWise ScreenConnect instances to push a four-stage VBScript payload to newly connected systems automatically. ([source](https://thehackernews.com/2026/09/rogue-screenconnect-clients-spread-four.html))

### 7. JSCeal Compiled V8 Malware Bypasses Google Auth via Stolen Sessions
**Why it matters for audit/CISO/VAPT:** Post-compromise malware that reconstructs browser sessions and installs local proxy interceptors shows OAuth/session-cookie protections alone won't stop account takeover.
Researchers unpacked JSCeal, an obfuscated compiled-JS stealer distributed via malvertising that harvests credentials, session cookies, and OAuth tokens, targeting retail traders and crypto investors. ([source](https://thehackernews.com/2026/09/jsceal-malware-can-bypass-google.html))

### 8. PEEP Toolkit Turns Chrome/Edge Into Post-Compromise Backdoors
**Why it matters for audit/CISO/VAPT:** Shows attacker tradecraft moving persistence into trusted browser processes disguised as extensions — a gap most endpoint/browser-extension audits don't yet cover.
Researchers disclosed PEEP, a Chromium-based post-exploitation toolkit masquerading as a bookmarks extension that, once installed with prior code-execution access, enables host command execution and persistence. ([source](https://thehackernews.com/2026/09/peep-turns-chrome-and-edge-into-post.html))
