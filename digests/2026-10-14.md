# Security & Audit Digest — 2026-10-14

## Top items

### 1. Microsoft's Record October Patch Tuesday — 1,411 Flaws, One Added to CISA KEV
**Why it matters for audit/CISO/VAPT:** A patch volume ten times normal, plus an actively exploited flaw now on the federal KEV list with an Oct 16 remediation deadline, is a hard test of patch-management SLAs.
Microsoft fixed 1,411 vulnerabilities (76 critical, 3 zero-days) on October 13 — the largest batch on record. CVE-2026-96951, a Windows Shell bypass already exploited in the wild, was added to CISA's KEV catalog the same day. ([source](https://www.bleepingcomputer.com/news/microsoft/microsoft-october-2026-patch-tuesday-fixes-1-411-flaws-3-zero-days/))

### 2. Ivanti Connect Secure Triple Zero-Day Chain Added to CISA KEV
**Why it matters for audit/CISO/VAPT:** An unpatched auth-bypass zero-day in a VPN gateway, now on KEV with a federal deadline, is an immediate perimeter-control failure for any remote-access audit.
Volexity disclosed that attackers chained three zero-days in Ivanti Connect Secure to gain root without authentication; Ivanti has patched two of three. CVE-2026-104935 was added to CISA's KEV catalog on October 13, with remediation due October 16. ([source](https://www.cisa.gov/news-events/alerts/2026/10/13/cisa-urges-patching-newly-exploited-vulnerability-ivanti-connect-secure))

### 3. SonicWall SMA 1000 CVSS 10.0 Flaw Actively Exploited Within Days of Disclosure
**Why it matters for audit/CISO/VAPT:** Mass, rapid exploitation of a remote-access appliance shows how little patch-window margin VAPT and vulnerability-management programs now have.
CVE-2026-102255, a pre-auth RCE in SonicWall SMA 1000, has been targeted in 135+ exploitation attempts since disclosure, per reporting October 12. ([source](https://thehackernews.com/2026/10/critical-sonicwall-sma-1000-flaw.html))

### 4. SAP Discloses Max-Severity OAuth2 Credential-Theft Flaw in Cloud SDK for Python
**Why it matters for audit/CISO/VAPT:** A CVSS 10.0 flaw that leaks OAuth2 client credentials from multi-tenant cloud apps is a direct identity and vendor-risk exposure for any SAP BTP audit scope.
SAP's October 13 advisory discloses a flaw in its Cloud SDK for Python that can send an application's OAuth2 credentials to an attacker-controlled server. ([source](https://www.bleepingcomputer.com/news/security/sap-warns-of-maximum-severity-oauth2-ssrf-security-flaw/))

### 5. GitHub Tightens npm Publishing After Flaw Exposed 1,500+ Packages to Hijacking
**Why it matters for audit/CISO/VAPT:** A gap letting attackers push malicious versions of someone else's package without stealing credentials is a textbook software-supply-chain control failure.
GitHub now expires unvalidated npm trusted-publishing configurations 48 hours after creation, after researchers found the configs could be hijacked to push rogue package versions. ([source](https://thehackernews.com/2026/10/github-tightens-npm-publishing-after.html))

### 6. OpenAI Engineer Arrested for Planting Hidden Recorder in Executive Conference Room
**Why it matters for audit/CISO/VAPT:** Insider compromise of executive communications is a governance and physical-security control failure that vetting and facility-monitoring audits should be testing for.
Abdulrahman Alfozan, 35, was arrested and charged after allegedly planting a covert recording device in an OpenAI executive conference room in San Francisco. ([source](https://www.bleepingcomputer.com/news/artificial-intelligence/openai-engineer-arrested-for-allegedly-planting-spy-device-in-office/))

### 7. Anthropic Warns Small AI Models Could Soon Self-Replicate Across IoT Devices
**Why it matters for audit/CISO/VAPT:** Self-propagating AI on unmanaged consumer IoT would create a new, largely uninventoried botnet risk class that AI-governance and asset-management programs aren't yet scoped for.
Anthropic said small AI models may be months from being able to self-replicate on devices like smart ovens and off-brand Android TV boxes, forming autonomous botnets. ([source](https://www.bleepingcomputer.com/news/security/anthropic-warns-self-replicating-ai-could-spread-to-your-smart-devices/))

### 8. Critical Ghostscript Flaw Lets Attackers Hijack Servers via PDF Upload
**Why it matters for audit/CISO/VAPT:** RCE through routine document processing is a third-party-library risk that document-handling and archival pipelines rarely test for.
CVE-2026-39919, a heap buffer overflow in the Ghostscript PDF interpreter, allows remote code execution via specially crafted PDF files. ([source](https://www.bleepingcomputer.com/news/security/ghostscript-flaw-lets-hackers-hijack-servers-via-pdf-uploads/))
