# Security & Audit Digest — 2026-09-16

## Top items

### 1. CISA Warns Ransomware Gangs Now Exploiting Critical VMware vCenter RCE
**Why it matters for audit/CISO/VAPT:** A patched-since-July flaw is now weaponized by ransomware operators, underscoring the audit need to verify actual patch application, not just patch availability, on virtualization infrastructure.
CISA warned that ransomware gangs have joined ongoing attacks against a critical VMware vCenter remote-code-execution vulnerability patched in July 2026. Organizations should confirm vCenter patch status and review for signs of prior compromise. ([source](https://www.bleepingcomputer.com/news/security/cisa-critical-vmware-vcenter-rce-flaw-now-exploited-by-ransomware-gangs/))

### 2. Acronis Warns of Actively Exploited cPanel/WHM/Plesk Backup Plugin Flaw
**Why it matters for audit/CISO/VAPT:** Active exploitation of a backup-tooling privilege-escalation bug threatens both hosting infrastructure integrity and backup-data confidentiality — a control area auditors often under-scope.
Acronis disclosed a high-severity Linux local privilege-escalation vulnerability in its backup plugin for cPanel, WHM, and Plesk that is being exploited in the wild. ([source](https://www.bleepingcomputer.com/news/security/acronis-warns-of-actively-exploited-flaw-in-its-cpanel-backup-plugin/))

### 3. LiteSpeed Enterprise Flaw Lets One Hosting Account Gain Root on Shared Servers
**Why it matters for audit/CISO/VAPT:** Breaks tenant-isolation assumptions on shared-hosting platforms; any organization relying on shared hosting for regulated workloads needs vendor patch confirmation.
A critical vulnerability in LiteSpeed Web Server Enterprise could let a low-privilege website user gain root access to an entire shared-hosting server, cPanel warned on September 14. ([source](https://thehackernews.com/2026/09/litespeed-enterprise-flaw-could-let-one.html))

### 4. Malicious Update Backdoors 1,500+ WordPress Sites via Admin Menu Editor Pro
**Why it matters for audit/CISO/VAPT:** A compromised plugin maintainer's site pushed a backdoored update to paying customers — a direct software-supply-chain control failure relevant to third-party/vendor risk audits.
Malicious versions of the Admin Menu Editor Pro plugin were distributed to over 200 customers after attackers compromised the maintainer's site and pushed updates creating hidden admin accounts. ([source](https://www.bleepingcomputer.com/news/security/malcious-admin-menu-editor-pro-plugin-backdoors-1-500-wordpress-sites/))

### 5. CenterPoint Energy Confirms Customer Data Stolen in Cyberattack
**Why it matters for audit/CISO/VAPT:** A breach at a critical-infrastructure utility with confirmed customer-data theft is a board-level disclosure and incident-response test case.
CenterPoint Energy disclosed that customer personal information was compromised after an attacker leaked data allegedly stolen from the utility. ([source](https://www.bleepingcomputer.com/news/security/centerpoint-energy-confirms-customer-data-stolen-in-cyberattack/))

### 6. China-Linked Actor Chains Chrome-Windows Zero-Days to Deploy GRIMWEDGE
**Why it matters for audit/CISO/VAPT:** A spear-phishing campaign chaining two recently patched zero-days shows attackers moving faster than typical patch cycles — validate Chrome/Windows patch timelines against this disclosure.
Volexity attributed a Chinese threat cluster to a spear-phishing campaign exploiting recently patched Chrome and Windows flaws to deliver the GRIMWEDGE JavaScript backdoor. ([source](https://thehackernews.com/2026/09/china-linked-hackers-exploit-chrome.html))
