# Security & Audit Digest — 2026-09-09

## Top items

### 1. Microsoft September 2026 Patch Tuesday — Record 973 Flaws, 113 Critical, 2 Exploited Zero-Days
**Why it matters for audit/CISO/VAPT:** The largest Patch Tuesday on record blows past July 2026's prior high of 664; two zero-days already exploited demand immediate triage rather than blanket patching.
Microsoft patched 973 vulnerabilities (113 critical), including Outlook RCEs and WebP flaws, with two under active exploitation. SANS recommends prioritizing by what's actually deployed in your environment. ([source](https://isc.sans.edu/diary/rss/33320))

### 2. Adobe Magento/Commerce "StyleSmuggler" Patched — CVE-2026-75650 Added to CISA KEV
**Why it matters for audit/CISO/VAPT:** Moves from an unpatched zero-day to a confirmed CVE with a federal remediation deadline — a concrete compliance checkpoint for any e-commerce environment.
Adobe shipped an emergency fix for the maximum-severity (CVSS 10.0) template-injection RCE used to plant Rust backdoors and PHP web shells. CISA added CVE-2026-75650 to its KEV catalog, remediation due 2026-09-11. ([source](https://www.bleepingcomputer.com/news/security/adobe-fixes-critical-magento-zero-day-exploited-to-backdoor-servers/))

### 3. N-able N-central RCE Added to CISA KEV — Federal Deadline September 11
**Why it matters for audit/CISO/VAPT:** Formal KEV listing of the flaw behind N-able's fourth hotfix in five weeks confirms active exploitation and sets a hard compliance deadline for federal agencies and their contractors.
CISA added CVE-2026-86218 (N-able N-central static code injection) to the KEV catalog, requiring FCEB remediation by 2026-09-11. Any org on on-prem N-central below 2026.3.1.14 should treat this as overdue. ([source](https://thehackernews.com/2026/09/n-able-n-central-pre-auth-rce-flaw.html))

### 4. FreeIPA Flaw Chain Lets Anonymous Clients Mint Reusable Admin Credentials
**Why it matters for audit/CISO/VAPT:** Unauthenticated-to-domain-admin escalation in core Linux identity infrastructure is a foundational control failure that audit programs should test for immediately.
Red Hat disclosed a chain letting a client that has never logged in create its own Kerberos identity in FreeIPA and land in the administrators group. FreeIPA governs login authorization across Linux domains. ([source](https://thehackernews.com/2026/09/freeipa-flaw-chain-lets-anonymous.html))

### 5. ShinyHunters Claims Breach of Florida DMV "DAVID" Database
**Why it matters for audit/CISO/VAPT:** A state-government records breach raises third-party platform access-control questions relevant to public-sector audit scopes.
The ShinyHunters extortion gang claims it stole over 200,000 Florida driver records — names, addresses, license numbers — from the state's "DAVID" DMV platform. Florida has not confirmed the claim. ([source](https://www.bleepingcomputer.com/news/security/shinyhunters-hackers-claim-breach-of-florida-david-dmv-database/))

### 6. SAP Patches Maximum-Severity "OVERPASS" Kernel Vulnerability
**Why it matters for audit/CISO/VAPT:** SAP underpins ERP/finance operations at most large enterprises; a max-severity kernel memory-corruption flaw warrants urgent patch-inventory action.
SAP's September updates fixed 20 vulnerabilities, including OVERPASS, a maximum-severity memory-corruption issue in the SAP Kernel with likely RCE/privilege-escalation impact. ([source](https://www.bleepingcomputer.com/news/security/sap-warns-of-maximum-severity-overpass-kernel-vulnerability/))

### 7. F5 BIG-IP APM Devices Breached to Deploy Fileless Linux Rootkit
**Why it matters for audit/CISO/VAPT:** Compromise of network appliances sitting in the application-delivery path enables persistent, hard-to-detect interception — a gap most endpoint audits miss.
A newly documented Linux rootkit targets F5 BIG-IP APM environments, intercepting PHP file loading and injecting a fileless web shell directly into memory without touching disk. ([source](https://www.bleepingcomputer.com/news/security/hackers-breach-f5-big-ip-apm-devices-to-deploy-linux-rootkit/))

### 8. ChatGPT Prompt-Injection Flaw Let Attackers Exfiltrate Gmail Data
**Why it matters for audit/CISO/VAPT:** Shows LLM assistants doing sensitive-data tasks can be silently hijacked mid-conversation — a governance gap most AI-usage policies don't yet cover.
Check Point Research showed a single planted instruction could make ChatGPT quietly read a victim's Gmail data and send it to an attacker-controlled account while answering the user's actual question normally. ([source](https://thehackernews.com/2026/09/chatgpt-flaw-let-planted-prompt-send.html))
