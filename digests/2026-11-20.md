# Security & Audit Digest — 2026-11-20

## Top items

### 1. VMware vCenter zero-day (CVE-2026-123890) exploited by China-linked Armory Castle
**Why it matters for audit/CISO/VAPT:** vCenter controls the whole virtualization estate, and no workaround exists. Confirm build versions now and add vCenter to internal and external test scope.
Broadcom's VMSA-2026-0009 fixes an unauthenticated authentication bypass (CVSS 9.8). The suspected China-nexus group Armory Castle (formerly UNC5221) has exploited it since early September 2026 to gain admin access and steal data. Patching is the only fix. ([source](https://thehackernews.com/2026/11/china-linked-hackers-exploit-critical.html))

### 2. PHP security release fixes critical RCE flaws (8.5.13, 8.4.28, 8.3.37, 8.2.36)
**Why it matters for audit/CISO/VAPT:** PHP is a base layer under many web apps and appliances. Inventory PHP versions and track patching against the new fixed releases.
The release announced earlier this week shipped on 2026-11-19, fixing 7 critical flaws including CVE-2026-115560. BleepingComputer counts 18 fixes in total. SANS notes a session-handling flaw (CVE-2026-126714) can lead to code execution. ([source](https://thehackernews.com/2026/11/php-fixes-7-critical-flaws-including.html))

### 3. Java4Shell (CVE-2026-114938): pre-auth RCE in Jira, Jenkins, Keycloak and others
**Why it matters for audit/CISO/VAPT:** It touches JDK patch cycles on CI/CD and identity hosts. Check JDK versions and whether Oracle's 2026-11-17 CPU is applied.
CISA urged immediate patching of this out-of-bounds write in the HotSpot Base64 decoder. Calif researchers say unauthenticated attackers can run code on Jira, Jenkins, Keycloak and three other apps. Java 17.0.6 and later is affected. ([source](https://www.cisa.gov/news-events/alerts/2026/11/17/critical-java-vulnerability-requires-immediate-patching))

### 4. Perforce Puppet Enterprise RCE (CVE-2026-115731) added to CISA KEV
**Why it matters for audit/CISO/VAPT:** Config-management servers can push changes to every managed host. Confirm versions and look for unexpected manifest or module changes.
CISA added this deserialization flaw on 2026-11-17 citing active exploitation. Federal remediation is due 2026-12-01. ([source](https://thehackernews.com/2026/11/hackers-exploiting-critical-puppet-rce.html))

### 5. Drupal core critical installer flaw allows takeover without login
**Why it matters for audit/CISO/VAPT:** Drupal sites are often public-facing and under-maintained. Check for installer-reachable instances and confirm the patched core version.
In specific configurations, an unauthenticated attacker can use the built-in installer to reinstall a site, leading to takeover or RCE. BleepingComputer reports Drupal warns exploits may surface quickly. ([source](https://thehackernews.com/2026/11/drupal-patches-critical-installer-flaw.html))

### 6. Researcher shows database RCE exploits for PostgreSQL, MySQL and Oracle
**Why it matters for audit/CISO/VAPT:** Restricting table privileges does not stop host compromise. Review DB patch levels and whether user-controlled input can reach DB accounts.
Exploits published on 2026-11-18 show low-privilege accounts, which cannot read application tables, reaching memory-corruption bugs in the SQL engine to run code on the server. ([source](https://thehackernews.com/2026/11/researcher-demonstrates-database-rce.html))

### 7. Optimizely compromise served malware to visitors of 178+ sites
**Why it matters for audit/CISO/VAPT:** This is a third-party script supply-chain failure. Inventory third-party JavaScript on your sites and enforce CSP or SRI where feasible.
An attacker exploited a flaw in Optimizely Web Experimentation to inject malicious code into scripts that customer sites load. Visitors to at least 178 organizations were served card skimmers and iOS exploit kits. ([source](https://krebsonsecurity.com/2026/11/attackers-used-optimizely-to-a-b-test-malware-on-top-websites/))

### 8. N-able cloud breach disables Mail Assure and Spam Experts management in three regions
**Why it matters for audit/CISO/VAPT:** Hosted email security is a third-party dependency. Assess vendor-notification duties and check mail-filtering continuity and configuration changes.
N-able says unknown attackers accessed a server in the hosted cloud, disabling management interfaces and APIs. It says it is containing the threat. ([source](https://thehackernews.com/2026/11/n-able-confirms-hackers-accessed-cloud.html))

### 9. Ruby patches 7 regex and string flaws; 5 have PoC RCE
**Why it matters for audit/CISO/VAPT:** Ruby runs in many web back ends. Identify runtimes exposed to untrusted input and schedule patches.
The seven memory-safety flaws are in the regex engine and case-conversion code. Maintainers say PoCs show crafted input can run code for five of them. ([source](https://thehackernews.com/2026/11/ruby-releases-fixes-for-7-regex-and.html))
