# Security & Audit Digest — 2026-10-01

## Top items

### 1. Cisco Catalyst SD-WAN Manager zero-day exploited in the wild, added to CISA KEV
**Why it matters for audit/CISO/VAPT:** An unauthenticated bypass in a network-management platform is already under active attack, and the federal remediation deadline is 2026-10-03 — audit teams need patch confirmation now, not after the deadline.
CVE-2026-76504, a hex-encoding authentication bypass in Cisco Catalyst SD-WAN Manager, lets a remote attacker with no credentials escalate to admin. Cisco disclosed it September 30 and CISA added it to the KEV catalog the same day. ([source](https://www.cisa.gov/news-events/alerts/2026/09/30/cisa-adds-one-known-exploited-vulnerability-catalog))

### 2. New forensic detail on Citrix NetScaler exploitation: superuser accounts, CSS-masked web shells
**Why it matters for audit/CISO/VAPT:** This updates the ongoing NetScaler compromise with concrete IOCs — VAPT teams can now hunt specific artifacts instead of guessing at post-exploitation behavior.
LevelBlue's THOR team found attackers exploiting the NetScaler flaws to create privileged local accounts, drop PHP web shells disguised as CSS files, exfiltrate `/flash/nsconfig` configuration data, and use self-deleting Perl scripts to erase forensic traces. ([source](https://thehackernews.com/2026/10/citrix-netscaler-post-exploitation.html))

### 3. Bitget confirms $387.5M crypto theft traced to zero-day in a third-party security product
**Why it matters for audit/CISO/VAPT:** A widely-deployed security tool was itself the attack vector — a supply-chain case study for vendor risk management, since Bitget has still not named the affected product.
Bitget confirmed SlowMist's findings that attackers used a zero-day in an unnamed third-party security product to harvest high-level internal credentials and move laterally to steal $387.5 million. ([source](https://thehackernews.com/2026/10/bitget-confirms-third-party-zero-day.html))

### 4. Zimbra Collaboration Suite flaw exploited for web shells and mailbox harvesting
**Why it matters for audit/CISO/VAPT:** Another unauthenticated, pre-auth email-platform RCE under active exploitation — a recurring pattern auditors should flag when reviewing perimeter mail infrastructure patch cadence.
Microsoft Security Research found attackers weaponizing CVE-2026-73570 (CVSS 8.9) in Zimbra Collaboration Suite to deploy web shells and access mailbox data at affected organizations. ([source](https://thehackernews.com/2026/09/attackers-exploit-zimbra-flaw-to-deploy.html))

### 5. Apple CoreGraphics zero-day added to CISA KEV, federal deadline 2026-10-02
**Why it matters for audit/CISO/VAPT:** A second KEV addition this week with an imminent federal deadline reinforces that mobile/endpoint patch SLAs need tightening, not just server-side ones.
CVE-2026-86950, an out-of-bounds write in CoreGraphics affecting older iOS/iPadOS/macOS branches, was exploited in targeted attacks before Apple's September 28 patch. ([source](https://www.cisa.gov/news-events/alerts/2026/09/29/cisa-adds-one-known-exploited-vulnerability-catalog))

### 6. OpenSSL fixes high-severity DTLS flaw that can leak heap memory unencrypted
**Why it matters for audit/CISO/VAPT:** OpenSSL underpins IoT and real-time/UDP services broadly; a heap-leak during handshake retransmission can expose session keys or credentials to a remote peer.
OpenSSL disclosed and patched the DTLS flaw on September 29. Affected deployments should upgrade and treat it as a priority patch for any UDP-based TLS usage. ([source](https://thehackernews.com/2026/09/openssl-fixes-high-severity-dtls-flaw.html))

### 7. Over 543,000 valid credentials found exposed in public GitHub repositories
**Why it matters for audit/CISO/VAPT:** A large-scale, persistent control failure — secrets-scanning and developer hygiene gaps are letting valid credentials sit exposed despite platform-level protections.
Research found more than 543,000 credentials in public GitHub repos were still valid as of July, despite GitHub's existing leak-prevention measures. ([source](https://www.bleepingcomputer.com/news/security/over-543-000-valid-credentials-exposed-in-public-github-repositories/))

### 8. AI coding agents leaked 13,000+ internal images, including billing records, to public GitHub
**Why it matters for audit/CISO/VAPT:** As AI coding agents get asked to post review screenshots, SDLC tooling is creating a new, unmonitored data-exfiltration path that existing DLP controls likely don't cover.
Security firm Glow found over 13,000 internal images from developers at 300+ organizations — including customer data and billing records — had been published publicly via AI coding agent workflows. ([source](https://thehackernews.com/2026/09/ai-coding-agents-exposed-13000-internal.html))
