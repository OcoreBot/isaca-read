# Security & Audit Digest — 2026-10-27

## Top items

### 1. PHP2Shell flaws added to CISA KEV, federal deadline Oct 29
**Why it matters for audit/CISO/VAPT:** Two actively exploited PHP vulnerabilities now carry a binding federal remediation deadline just days out, and the underlying design flaw survives patching.
CISA added CVE-2026-109618 (memory corruption) and CVE-2026-109619 (stale internal request-state) to the KEV catalog on October 26, confirming in-the-wild exploitation. SANS notes exploitation requires ASLR bypass and version-specific offsets, so attacks are targeted at high-value systems, and `session.upload_progress.enabled` should stay disabled permanently even after patching. ([CISA](https://www.cisa.gov/news-events/alerts/2026/10/26/cisa-adds-two-known-exploited-vulnerabilities-catalog))

### 2. Brotli decoder RCE hits Node.js, .NET, PHP, Bun, Python, Envoy
**Why it matters for audit/CISO/VAPT:** One library flaw now has an unusually wide blast radius across the software supply chain, and PHP's Windows fix shipped without a version bump, making patch verification harder.
CVE-2026-111497, a buffer overflow in Google's Brotli decompression library, enables remote code execution via untrusted compressed data and affects Node.js, Microsoft .NET 8/9/10/11 RC3, Python's brotli/brotlicffi packages, Bun, and Envoy proxies. Audit teams should verify .NET patches, check PHP Windows binary hashes, and inventory other Brotli-dependent software. ([The Hacker News](https://thehackernews.com/2026/10/brotli-decoder-flaw-behind-nodejs-rce.html))

### 3. Microsoft 365 token-replay campaign breaches 79 organizations
**Why it matters for audit/CISO/VAPT:** An AitM relay that replays stolen session tokens bypasses MFA entirely, undermining a control CISOs typically treat as sufficient.
Huntress observed an adversary-in-the-middle relay capturing Microsoft 365 sign-in sessions and replaying tokens to compromise 97 accounts across 79 organizations. Audit should review OAuth token revocation policies and conditional-access rules for impossible-travel/unusual sign-in detection. ([The Hacker News](https://thehackernews.com/2026/10/microsoft-365-token-replay-attacks.html))

### 4. CISA KEV: Collabora Online and Arista VeloCloud actively exploited
**Why it matters for audit/CISO/VAPT:** Two more actively-exploited flaws join KEV, directly feeding patch-compliance audits.
CISA added vulnerabilities in Collabora Online's built-in CODE Server and Arista VeloCloud Orchestrator to the KEV catalog on October 24, citing confirmed active exploitation. ([The Hacker News](https://thehackernews.com/2026/10/cisa-flags-two-actively-exploited.html))

### 5. Gheist campaign steals secrets from GitHub Actions logs
**Why it matters for audit/CISO/VAPT:** A supply-chain attack path that plants workflows to leak secrets into logs, then deletes the runs, is a direct hit on CI/CD governance controls.
An automated campaign uses stolen GitHub tokens to plant workflows that print repository secrets into Actions logs, succeeding against private repos and GitHub Enterprise environments. Audit: review token scope/expiration policies, branch protection on workflow changes, and Actions log retention. ([The Hacker News](https://thehackernews.com/2026/10/gheist-uses-stolen-github-tokens-to-steal-private-repository-secrets-via-actions-logs.html))

### 6. Tailscale SSH flaws allow root pivot across the tailnet
**Why it matters for audit/CISO/VAPT:** This undermines the zero-trust assumption behind mesh VPNs — one compromised device with port forwarding enabled can reach root elsewhere on the network.
Unpatched Tailscale SSH vulnerabilities let an attacker on one hacked device gain root on other reachable servers when Tailscale SSH port forwarding is enabled. Audit: disable port forwarding unless required, enforce ACLs, and monitor lateral movement. ([The Hacker News](https://thehackernews.com/2026/10/unpatched-tailscale-ssh-flaws-could-let.html))
