# Security & Audit Digest — 2026-08-25

## Top items

### 1. Oracle HTTP Server / WebLogic Proxy Plug-in Flaw Added to CISA KEV
**Why it matters for audit/CISO/VAPT:** Confirmed active exploitation of widely deployed Oracle middleware, with a three-day federal remediation clock. Any organization running Oracle HTTP Server or WebLogic needs immediate patch verification.
CVE-2026-21962, an improper access control flaw in the Oracle HTTP Server/WebLogic proxy plug-in, was added to CISA's KEV catalog on 2026-08-24, with federal remediation due 2026-08-27. ([source](https://www.cisa.gov/news-events/alerts/2026/08/24/cisa-adds-one-known-exploited-vulnerability-catalog))

### 2. Critical Keycloak Password Reset Flaw Allows Unauthenticated Account Takeover
**Why it matters for audit/CISO/VAPT:** Keycloak underpins identity for many enterprise stacks; an unauthenticated path to full account takeover threatens every downstream application relying on it.
Red Hat and the Keycloak project patched a critical flaw letting unauthenticated attackers force a password reset and take over any account. ([source](https://thehackernews.com/2026/08/critical-keycloak-password-reset-flaw.html))

### 3. GitLab Protected-Branch Flaws Now Have Public PoC, Exploitation Continues
**Why it matters for audit/CISO/VAPT:** Source-code-integrity controls remain exposed; a second CVE and public proof-of-concept raise urgency beyond yesterday's initial disclosure.
Beyond CVE-2026-19478 (covered previously), researchers confirmed a related flaw, CVE-2026-19650, also enabling unauthenticated GraphQL code injection against protected branches — with working PoC code now public. ([source](https://isc.sans.edu/podcastdetail/10064))

### 4. Active Exploitation of miniOrange SAML SSO Plugin on WordPress
**Why it matters for audit/CISO/VAPT:** Forged SAML responses grant admin-level access without valid credentials — a direct authentication-integrity failure worth testing in any WordPress SSO deployment.
Attackers are actively exploiting two critical auth-bypass flaws in the miniOrange SAML 2.0 SSO plugin to forge SAML responses and log in as administrators. ([source](https://www.bleepingcomputer.com/news/security/hackers-target-wordpress-sites-in-miniorange-auth-bypass-attacks/))

### 5. Unpatched Calix Router Flaw Bypasses NAT, Exposes Internal Devices
**Why it matters for audit/CISO/VAPT:** No patch is yet available; unauthenticated attackers can create port-forwarding rules exposing internal devices at customer or branch sites to the open internet.
A flaw in Calix GS7 XGS residential routers, used by several U.S. broadband providers, lets remote attackers bypass NAT and expose internal network devices publicly. ([source](https://www.bleepingcomputer.com/news/security/unpatched-calix-flaw-lets-hackers-bypass-nat-to-expose-internal-devices/))

### 6. UAT-10147 Uses AI to Scale Attacks, Deploys SPECTRE for EDR Bypass
**Why it matters for audit/CISO/VAPT:** AI-scaled operations plus a dedicated EDR-evasion toolkit signal a sophistication jump worth adding to red-team and detection-gap testing.
A Chinese-speaking group, UAT-10147, is using AI to scale attacks on Windows and Linux web servers and deploying the SPECTRE toolkit to bypass EDR, primarily hitting education, media, tech, and gaming targets. ([source](https://thehackernews.com/2026/08/uat-10147-uses-ai-to-scale-server.html))

### 7. South Korean Startup Platform Breach: Encryption Key Exposed in API
**Why it matters for audit/CISO/VAPT:** A textbook key-management control failure — the encryption key travelled alongside the data it was meant to protect. Good prompt for a key-custody control review.
A breach at a South Korean government-backed startup platform exposed encrypted personal data after an encryption key was embedded in an API response. ([source](https://www.bleepingcomputer.com/news/security/south-korean-startup-platform-breach-exposes-key-management-failures/))

### 8. ReliaQuest Confirms Failed Data-Theft Attempt via Impersonation
**Why it matters for audit/CISO/VAPT:** Even security vendors face social-engineering attempts riding on other breaches (ShinyHunters); reinforces the case for verifying identity on internal security-team requests regardless of vendor.
ReliaQuest confirmed an employee was targeted by attackers impersonating a security-team member following the ShinyHunters breach, but the data-theft attempt failed. ([source](https://www.bleepingcomputer.com/news/security/reliaquest-confirms-failed-data-theft-attack-after-shinyhunters-breach/))
