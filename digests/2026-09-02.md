# Security & Audit Digest — 2026-09-02

## Top items

### 1. Attackers Exploit Critical JFrog Artifactory Flaw to Mint Admin Tokens
**Why it matters for audit/CISO/VAPT:** An authentication-bypass CVSS 9.8 flaw in a widely used artifact repository is now under active exploitation just days after disclosure — a supply-chain risk multiplier that demands emergency patching and token-rotation, not routine cycle handling.
CVE-2026-82329 lets attackers bypass authentication in JFrog Artifactory and mint admin tokens, giving full repository control. watchTowr reports in-the-wild exploitation began within days of public disclosure. ([source](https://thehackernews.com/2026/09/attackers-exploit-critical-jfrog.html))

### 2. Langflow and Ruby on Rails Flaws Exploited for Credential Theft and C2
**Why it matters for audit/CISO/VAPT:** Unauthenticated RCE in a popular AI application framework is being actively weaponized to steal cloud and LLM API credentials — audit teams should verify patch status and network exposure for any Langflow deployments.
VulnCheck found threat actors exploiting CVE-2026-0768 (CVSS 9.8, Langflow unauthenticated RCE) alongside a Rails flaw for credential probing and C2 activity; BleepingComputer separately confirmed the same Langflow bug is being used to steal OpenAI and AWS keys. ([source](https://thehackernews.com/2026/09/attackers-exploit-critical-langflow-and.html))

### 3. FBI Probes Dark-Web Service Selling 153M+ Drivers Licenses
**Why it matters for audit/CISO/VAPT:** A dataset of this scale is a precursor to mass account-takeover and identity-fraud campaigns; organizations should brief fraud and identity-verification teams and expect a spike in synthetic-identity attempts.
A new dark-web identity-theft service is selling digital scans of over 153 million US and Canadian drivers licenses; the FBI is investigating the source and legitimacy of the dataset. ([source](https://krebsonsecurity.com/2026/09/fbi-probes-service-selling-153m-drivers-licenses/))

### 4. METR Discloses Theft of API Key, ~$600K in Stolen AI Credits
**Why it matters for audit/CISO/VAPT:** A concrete control-failure lesson in AI-infrastructure key management — audit API key rotation policies, expenditure alerting, and short-lived credential practices anywhere LLM APIs are integrated.
AI safety research nonprofit METR disclosed two security incidents in which attackers stole an API key and ran up roughly $600,000 in AI model usage before detection. ([source](https://thehackernews.com/2026/09/attackers-steal-metr-api-key-and.html))

### 5. Russia-Aligned UAC-0099 Embeds "Nuclear Weapon" Prompt to Disrupt AI Malware Analysis
**Why it matters for audit/CISO/VAPT:** A nation-state actor is now weaponizing prompt-injection against AI-assisted security tooling; VAPT teams should add adversarial-prompt evasion to threat models for any AI-augmented detection or analysis pipeline.
ESET disclosed GuardBreaker, a technique used by Russia-aligned UAC-0099 against a Ukrainian target that embeds a "nuclear weapon" prompt inside malware to interfere with AI-assisted analysis and detection. ([source](https://thehackernews.com/2026/09/russia-aligned-uac-0099-plants-nuclear.html))

### 6. Iranian Nimbus Manticore Poses as Recruiters to Deliver Cross-Platform RATs
**Why it matters for audit/CISO/VAPT:** Recruiter-themed phishing paired with fake coding-test attachments is a low-friction delivery channel now reaching Linux and macOS, not just Windows — a scenario worth adding to social-engineering VAPT exercises.
The Iranian Nimbus Manticore group has been tied to two new cross-platform RAT families delivered via fake recruiter outreach and coding-test lures, expanding its targeting to Linux and macOS. ([source](https://thehackernews.com/2026/09/iranian-hackers-pose-as-recruiters-to.html))

### 7. Breeze Comet Runs Hundreds of Fraudulent Transactions via Brazilian Payment Systems
**Why it matters for audit/CISO/VAPT:** Financially motivated actors scaling transaction fraud against payment infrastructure is a direct hit on fraud-detection and transaction-monitoring controls — relevant to any audit covering payment-system assurance.
Google Threat Intelligence Group and Mandiant describe Breeze Comet (formerly UNC5669), active since 2024, executing hundreds of fraudulent transactions against Brazilian financial services, retail, and e-commerce targets. ([source](https://thehackernews.com/2026/09/breeze-comet-executes-hundreds-of.html))
