# Security & Audit Digest — 2026-09-29

## Top items

### 1. Bitget loses $387.5M after attacker exploits third-party security product
**Why it matters for audit/CISO/VAPT:** A textbook vendor-risk failure — a flaw in a security product the exchange relied on for protection became the entry point, showing why third-party security tooling needs its own patch-compliance and access-review checks.
Bitget confirmed the attacker exploited an unpatched vulnerability in a third-party security product to obtain high-level internal credentials, then used them to steal roughly $387.5 million in cryptocurrency. Withdrawals have since resumed. ([source](https://www.bleepingcomputer.com/news/security/bitget-resumes-bitcoin-withdrawals-after-3875-million-crypto-heist/))

### 2. Apple emergency-patches actively exploited CoreGraphics zero-day
**Why it matters for audit/CISO/VAPT:** Confirmed in-the-wild exploitation against older iOS/macOS branches makes this an immediate mobile/endpoint patch-compliance item, especially for BYOD and executive-device fleets.
Apple released out-of-band patches for CVE-2026-86950, an out-of-bounds write in CoreGraphics affecting iOS 26, macOS 26, and macOS 15, which it says may have been exploited in targeted attacks. iOS/macOS 27 are unaffected. A PoC for a separate macOS CoreServices privilege-escalation flaw (CVE-2026-43786) also surfaced. ([source](https://thehackernews.com/2026/09/apple-patches-coregraphics-flaw.html))

### 3. JADEPUFFER uses hijacked Azure service principals to destroy cloud resources
**Why it matters for audit/CISO/VAPT:** Destructive attacks via compromised service-principal identities bypass traditional ransomware/backup assumptions and put identity governance for non-human accounts squarely in audit scope.
Microsoft (tracking the group as Storm-3168) says JADEPUFFER is using compromised Azure service principals to conduct recon, steal credentials, and delete core cloud resources — an evolution toward agentic, identity-driven destructive attacks. ([source](https://www.bleepingcomputer.com/news/security/jadepuffer-agentic-ai-attacks-target-azure-destroy-cloud-resources/))

### 4. 16,000+ misconfigured Supabase databases expose PII, passwords, tokens
**Why it matters for audit/CISO/VAPT:** Mass, default-configuration data exposure across a popular PaaS backend highlights an audit blind spot: cloud-native database permissions are rarely reviewed with the same rigor as traditional infrastructure.
Researchers found more than 16,000 Supabase-backed applications with readable database tables exposing personal data, passwords, and authentication tokens, pointing to widespread misconfiguration rather than a single vulnerability. ([source](https://www.bleepingcomputer.com/news/security/misconfigured-supabase-apps-expose-data-in-over-16-000-databases/))

### 5. Infostealers have compromised AI logins at 80,000+ organizations
**Why it matters for audit/CISO/VAPT:** Shadow AI usage now shows up directly in breach data, giving CISOs a concrete data point to justify AI credential monitoring and access governance as a control, not just policy.
SOCRadar research found infostealer logs containing AI account credentials and sessions tied to over 80,000 corporate domains, exposing organizations to stolen conversations and "LLMjacking" — unauthorized use of hijacked AI accounts. ([source](https://www.bleepingcomputer.com/news/security/80-000-plus-organizations-had-ai-logins-stolen-from-shadow-ai-to-llmjacking/))

### 6. NeedyMantis malware gives attackers long-term persistence in telecom networks
**Why it matters for audit/CISO/VAPT:** Modular, DLL-based payloads with WebSocket C2 are built to evade behavioral EDR — a useful threat-hunting hypothesis for VAPT teams working critical-infrastructure clients.
Microsoft detailed NeedyMantis, a post-compromise malware family used in a small number of targeted intrusions at telecom and university networks, which abuses legitimate system DLLs and WebSocket channels to maintain access. ([source](https://thehackernews.com/2026/09/hackers-use-needymantis-to-maintain.html))

### 7. Carbonato botnet hijacks exposed Docker hosts to run a hidden AI agent
**Why it matters for audit/CISO/VAPT:** Internet-exposed Docker daemons remain an under-scanned attack surface; this campaign shows attackers repurposing a legitimate open-source AI agent framework for control, complicating detection.
The Carbonato botnet scans for exposed Docker daemons, deploys the open-source Hermes AI agent framework unmodified, then overwrites its behavior with attacker-controlled logic for Telegram-based control. ([source](https://thehackernews.com/2026/09/carbonato-botnet-compromises-docker.html))
