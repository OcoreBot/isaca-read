# Security & Audit Digest — 2026-09-21

## Top items

### 1. CISA Adds Three Actively Exploited Linux Kernel Flaws to KEV Catalog
**Why it matters for audit/CISO/VAPT:** KEV additions carry a federal remediation mandate (due 2026-09-21) and are a standard control point in vulnerability-management audits; confirmed in-the-wild exploitation raises urgency for any Linux fleet.
CISA added CVE-2026-53266 (out-of-bounds write), CVE-2025-39964 (race condition), and CVE-2025-39682 (improper condition checks) to the KEV catalog on 2026-09-18, all Linux kernel issues with evidence of active exploitation. ([source](https://www.cisa.gov/news-events/alerts/2026/09/18/cisa-adds-two-known-exploited-vulnerabilities-catalog))

### 2. Microsoft Patches CVSS 10.0 Azure AI Foundry Privilege Escalation
**Why it matters for audit/CISO/VAPT:** A maximum-severity flaw in cloud AI infrastructure is a direct hit to cloud governance and AI-service risk registers, even though Microsoft handled remediation server-side.
CVE-2026-85889 stemmed from missing authentication controls in Azure AI Foundry, enabling unauthorized privilege escalation. Microsoft patched it and says no customer action is required. ([source](https://thehackernews.com/2026/09/microsoft-patches-cvss-100-azure-ai.html))

### 3. Critical Pre-Auth RCE in Orkes Conductor Exploited in the Wild
**Why it matters for audit/CISO/VAPT:** Unauthenticated RCE under active exploitation demands immediate scanning and patching for any org running this workflow orchestration platform.
CVE-2026-58138 (CVSS 9.8/9.3) allows unauthenticated remote code execution in Orkes Conductor; Fortinet reports active exploitation. ([source](https://thehackernews.com/2026/09/critical-pre-auth-rce-in-orkes.html))

### 4. SolarWinds Patches Hard-Coded Key in Access Rights Manager
**Why it matters for audit/CISO/VAPT:** A hard-coded cryptographic key in identity-governance infrastructure is a textbook audit finding and a direct threat to SOX/IAM control frameworks.
CVE-2026-28326 (CVSS 8.8) in SolarWinds ARM enabled unauthenticated RCE via a hard-coded key; patches are now available. ([source](https://thehackernews.com/2026/09/solarwinds-patches-arm-hard-coded-key.html))

### 5. Claude Opus 5 Used to Chain Flaws and Take Over OpenAI Staff Accounts
**Why it matters for audit/CISO/VAPT:** Demonstrates LLM-assisted vulnerability chaining against privileged accounts — a board-level example of AI-augmented attack capability that CISOs should factor into third-party and AI-tool risk assessments.
Researchers at Hacktron used Claude Opus 5 to chain two bugs, compromising OpenAI employees' ChatGPT/Codex accounts and reaching an internal code repository. ([source](https://thehackernews.com/2026/09/claude-opus-5-helped-researchers-take.html))

### 6. Google Gemini Accessed Real Company Systems After Test/Prod Domain Mix-Up
**Why it matters for audit/CISO/VAPT:** A security-evaluation error causing unauthorized third-party access is a governance and testing-scope failure worth raising in board risk discussions and vendor AI-testing agreements.
Google's Gemini model accessed the internet and broke into other companies' systems in May 2026 after a domain mix-up during a security evaluation, per the Wall Street Journal. ([source](https://thehackernews.com/2026/09/google-gemini-broke-into-real-company.html))

### 7. Researchers Escape OpenAI Codex Sandbox to Run Host Commands
**Why it matters for audit/CISO/VAPT:** Sandbox escapes in AI coding tools are a growing supply-chain risk for development environments; relevant to any org standardizing on AI-assisted coding.
Two escape techniques were demonstrated against Codex's sandbox, one reaching host-level command execution from the most locked-down mode; OpenAI has patched both. ([source](https://www.bleepingcomputer.com/news/security/researchers-escape-openai-codex-sandbox-to-run-commands-on-host/))

### 8. Check Point Flaw Enables Root Code Execution on Management Systems
**Why it matters for audit/CISO/VAPT:** Compromise of security-management infrastructure undermines the very controls audits rely on; patch verification should be prioritized.
Check Point released updates for a critical vulnerability allowing attackers to execute code with root privileges on its management systems. ([source](https://www.bleepingcomputer.com/news/security/check-point-warns-critical-flaw-lets-hackers-execute-code-as-root/))
