# Security & Audit Digest — 2026-10-19

## Top items

### 1. BeyondTrust Remote Support 0-Day Exploited by China-Linked Group, Added to CISA KEV
**Why it matters for audit/CISO/VAPT:** A widely-deployed remote-support platform was exploited as a zero-day for nearly two months before disclosure; federal remediation was due the same day this digest was written, making it an immediate patch-and-verify priority for any audit of privileged remote access.
CISA added CVE-2026-102764 (authentication bypass by spoofing) to its KEV catalog on October 16 after confirming BeyondTrust Remote Support (versions 24.3.1 and earlier) had been exploited since late August. Researchers attribute the activity to China-nexus group Armory Castle (UNC5221/Warp Panda), which used the flaw for espionage access. Patch immediately and review remote-support session logs back to August. ([CISA](https://www.cisa.gov/news-events/alerts/2026/10/16/cisa-urges-patching-critical-vulnerability-beyondtrust-remote-support))

### 2. Fortinet FortiOS Path Traversal (KEV) Delivers PEERSTITCH Malware
**Why it matters for audit/CISO/VAPT:** VPN appliances sit at the network perimeter; a KEV-listed flaw with an active, memory-resident payload demands urgent patch verification and log review for any FortiOS-dependent remote-access control.
CISA added CVE-2025-61624 to the KEV catalog on October 16 alongside the BeyondTrust bug. The path-traversal flaw bypasses checks on tagged VPN sessions and has been used to deliver PEERSTITCH, a previously unreported ARM64 memory-resident malware. Federal remediation was due October 19. ([CISA](https://www.cisa.gov/news-events/alerts/2026/10/16/cisa-adds-two-known-exploited-vulnerabilities-catalog))

### 3. ConnectWise Cloud Backup Breach Compromises 173 Microsoft 365 Tenants
**Why it matters for audit/CISO/VAPT:** A classic MSP supply-chain failure — compromised vendor application identities gave attackers a path into customer M365 tenants, illustrating why third-party access reviews belong in every audit scope.
Attackers obtained unauthorized access to seven ConnectWise Cloud Backup (formerly SkyKick) application identities and used a compromised M365 credential to sign into at least 173 customer tenants. ConnectWise disabled the identities and suspended the service on October 18. Organizations using Cloud Backup should audit M365 sign-in logs since late August and rotate credentials. ([BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-breach-microsoft-365-tenants-via-connectwise-supply-chain-attack/))

### 4. Drupal Patches Critical RCE Flaws, Warns Exploits May Emerge Soon
**Why it matters for audit/CISO/VAPT:** All supported Drupal versions are affected, and the vendor's own warning of imminent exploit code makes this a time-boxed patch window rather than routine maintenance.
Drupal released fixes for two critical remote-code-execution vulnerabilities affecting every supported branch of the CMS. The security team warned working exploits could surface shortly. Patch immediately rather than waiting for the next maintenance cycle. ([BleepingComputer](https://www.bleepingcomputer.com/news/security/drupal-patches-critical-rce-flaws-warns-exploits-may-emerge-soon/))

### 5. SiteGuard WAF Command Injection Lets Attackers Run Commands as Root/SYSTEM
**Why it matters for audit/CISO/VAPT:** A compromised WAF undermines the control it's meant to provide, giving attackers a pivot point with full visibility into protected traffic — a notable new attack technique for VAPT teams to test for.
Attackers are actively exploiting an OS command-injection flaw in SiteGuard Server Edition to gain root or SYSTEM access on affected servers. Review WAF logs for exploitation indicators and patch immediately. ([BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-exploit-siteguard-waf-flaw-to-run-commands-as-system-root/))

### 6. AOMEI Backupper Update Servers Tampered to Deliver Backdoor
**Why it matters for audit/CISO/VAPT:** Backup software is critical infrastructure; a software-update supply-chain compromise that targets it directly threatens ransomware recovery capability and deserves forensic follow-up, not just a patch note.
Attackers repeatedly altered files served by AOMEI Backupper's update servers in short five-to-ten-minute windows between May and July 2026, backdooring any client that checked for updates during those windows. Organizations running AOMEI Backupper should assume possible compromise and review for indicators of persistence. ([The Hacker News](https://thehackernews.com/2026/10/attackers-tampered-with-aomei.html))

### 7. MALFEX npm Package Hides Shellcode Loader in Native Windows Addon
**Why it matters for audit/CISO/VAPT:** Embedding malicious code in a native binary addon rather than plain JavaScript is a technique likely to evade typical dependency scanners — relevant for VAPT teams assessing software supply-chain tooling.
The npm package "imgdecode," uploaded September 30 as part of the MALFEX campaign, conceals a shellcode loader inside a Windows native addon. Review dependency lock files for the package and similar late-September uploads. ([The Hacker News](https://thehackernews.com/2026/10/malfex-npm-package-imgdecode-hides.html))

### 8. Researchers Chain 37-Year-Old OpenBSD Bug for Root Privilege Escalation
**Why it matters for audit/CISO/VAPT:** A public local-privilege-escalation exploit bypassing KARL, SMAP, and SMEP on OpenBSD 7.9 is a notable new PoC for VAPT engagements involving OpenBSD hosts.
Security firm Calif published a local exploit chaining a decades-old integer overflow in shared memory handling with a separate kernel flaw to gain root on OpenBSD 7.9, defeating the OS's kernel-address randomization and hardware memory protections. ([The Hacker News](https://thehackernews.com/2026/10/researchers-demonstrate-openbsd-root.html))
