# Security & Audit Digest — 2026-08-26

## Top items

### 1. Gitea Code Injection Flaw Added to CISA KEV
**Why it matters for audit/CISO/VAPT:** Confirmed active exploitation of a widely deployed source-control platform, with a three-day federal remediation clock. Source-code integrity underpins change-management and supply-chain controls.
CVE-2026-60004, a code injection vulnerability in Gitea, was added to CISA's KEV catalog on 2026-08-25, with federal remediation due 2026-08-28. ([source](https://nvd.nist.gov/vuln/detail/CVE-2026-60004))

### 2. Over 270 Zimbra Servers Compromised in Ongoing RCE Attacks
**Why it matters for audit/CISO/VAPT:** Zimbra Collaboration Suite is widely used in enterprise and government email; successful RCE grants full mailbox and calendar access, a major data-loss vector still expanding.
Threat actors have already compromised more than 270 Zimbra instances by exploiting a high-severity RCE vulnerability, with attacks continuing as of 2026-08-25. ([source](https://www.bleepingcomputer.com/news/security/hackers-breached-over-270-zimbra-servers-in-ongoing-attacks/))

### 3. Mirage2FA PhaaS Campaign Hits 4,500 US and EU Organizations via Microsoft 365
**Why it matters for audit/CISO/VAPT:** MFA bypass at scale, abusing legitimate login flows, undermines a core control many programs treat as sufficient — worth revisiting conditional-access and phishing-resistant MFA posture.
A phishing-as-a-service toolkit called Mirage2FA has compromised over 4,500 organizations since 2024 by abusing legitimate Microsoft 365 login flows to bypass two-factor authentication; 48% of targets are in the US and EU. ([source](https://thehackernews.com/2026/08/mirage2fa-surge-hits-4500-us-and-eu.html))

### 4. NVIDIA NemoClaw Flaw Enables Local AI Model Poisoning via Malicious Webpages
**Why it matters for audit/CISO/VAPT:** AI supply-chain and model-integrity risk is an emerging audit domain; an unauthenticated webpage taking control of a local Ollama instance is a novel attack surface most risk registers don't yet cover.
Oasis Security disclosed a weakness in NVIDIA's NemoClaw framework that lets an attacker-controlled webpage take unauthenticated control of a local Ollama instance and plant hidden instructions inside the AI model itself. ([source](https://thehackernews.com/2026/08/a-malicious-webpage-could-poison-your.html))

### 5. Marimo Notebook Flaw Allowed Attacker-Supplied MCP Command Execution
**Why it matters for audit/CISO/VAPT:** Full code execution via a crafted notebook is a backdoor vector for data-science and AI-engineering environments — a useful test case for reviewing MCP tool-trust boundaries.
Marimo patched a high-severity flaw that allowed execution of attacker-supplied Model Context Protocol commands in specially crafted notebooks before cells run in edit mode. ([source](https://thehackernews.com/2026/08/marimo-notebook-flaw-could-run-mcp.html))

### 6. 24 npm Packages Abuse unpkg Mirrors to Host Fake Cloudflare CAPTCHA Pages
**Why it matters for audit/CISO/VAPT:** Illustrates how easily legitimate package-registry infrastructure is turned into phishing hosting, a gap in most dependency-hygiene and third-party risk reviews.
Researchers disclosed a campaign using 24 npm packages as free phishing infrastructure, redirecting victims to ClickFix-style fake CAPTCHA pages via unpkg mirrors. ([source](https://thehackernews.com/2026/08/24-npm-packages-abuse-unpkg-mirrors-to.html))

### 7. Massive DDoS Attack Disrupts Norway's Government Digital Services
**Why it matters for audit/CISO/VAPT:** A sustained, large-scale disruption of shared government infrastructure is a business-continuity and critical-infrastructure resilience case worth referencing in tabletop exercises.
A large DDoS attack has disrupted Norway's shared government digital infrastructure since 2026-08-24, affecting public-sector services, with the disruption ongoing as of 2026-08-25. ([source](https://www.bleepingcomputer.com/news/security/massive-ddos-attack-disrupts-norways-government-digital-services/))
