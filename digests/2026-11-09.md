# Security & Audit Digest — 2026-11-09

## Top items

### 1. SonicWall SonicOS SSL-VPN MFA bypass added to CISA KEV
**Why it matters for audit/CISO/VAPT:** An internet-facing VPN edge device is under active exploitation, with a short federal deadline (2026-11-20). Patch verification and MFA-configuration review are immediate actions.
CISA added CVE-2026-19868 (SSLVPN single-factor authentication) to KEV on 2026-11-06. SonicWall fixed seven SonicOS flaws. Per SANS, the bypass applies when an alternate authentication method without MFA is also configured. ([source](https://www.cisa.gov/news-events/alerts/2026/11/06/cisa-adds-one-known-exploited-vulnerability-catalog))

### 2. OpenSSH "sshole" (CVE-2026-123158) exploited within hours of disclosure
**Why it matters for audit/CISO/VAPT:** Widely deployed SSH service with a path to sign in to accounts that have no password set. Check OpenSSH versions and audit password-less accounts.
CVSS 8.1. Attackers began attempts within hours, and a Previdian researcher reports root on a honeypot. SANS Cowrie honeypots have logged likely attempts since 2026-11-05. ([source](https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html))

### 3. Chainalysis breach exposes credentials and live tokens for all customers
**Why it matters for audit/CISO/VAPT:** Third-party SaaS compromise with live-token exposure. Drives vendor-risk review, token rotation and notification duties.
Chainalysis says an agentic cyberattack exposed names, usernames, password hashes and live tokens for all users. It removed access to Reactor and Data Solutions while investigating. ([source](https://thehackernews.com/2026/11/chainalysis-breach-exposes-all-users.html))

### 4. Barracuda Email Security Gateway: two-flaw chain to unauthenticated root
**Why it matters for audit/CISO/VAPT:** Public exploit-chain write-up for a high-value perimeter appliance. Verify patch status.
Two flaws can be chained to run commands as root with no login. Patches were released 2026-11-02, and watchTowr published the attack chain. ([source](https://thehackernews.com/2026/11/experts-demonstrate-barracuda-email.html))

### 5. Claude Code "Don't Ask Again" file leaks secrets on public GitHub
**Why it matters for audit/CISO/VAPT:** AI-tool governance and secrets-management gap on developer workstations.
Commands approved with "Yes, and don't ask again" are saved word-for-word, including passwords and API keys. 1,122 public GitHub copies are reported (SANS cites ~1,500). Rotate exposed credentials and review local permission files. ([source](https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html))

### 6. Crédit Mutuel Arkéa: up to $133M fraudulent transactions via service provider
**Why it matters for audit/CISO/VAPT:** Large financial loss routed through third-party access. Supports third-party risk and ICT concentration discussions.
The French bank suspended certain systems after the attack. ([source](https://www.bleepingcomputer.com/news/security/hackers-pull-off-133-million-french-bank-heist-via-service-provider/))

### 7. Control Web Panel backdoor runs commands without logs
**Why it matters for audit/CISO/VAPT:** Log evasion on hosting servers calls for integrity checks and threat hunting.
XLab found a backdoor in the CWP web server that executes attacker commands sent via web requests, designed to avoid logging. ([source](https://thehackernews.com/2026/11/hackers-hide-linux-backdoor-in-control.html))

### 8. QNAP NAS devices breached via Plex2Shell chain
**Why it matters for audit/CISO/VAPT:** NAS devices often hold backups. Check exposure and Plex versions.
QNAP says attackers are exploiting the chain and urges updating Plex Media Server via the App Center. ([source](https://www.bleepingcomputer.com/news/security/qnap-says-hackers-breaching-nas-devices-in-plex2shell-attacks/))
