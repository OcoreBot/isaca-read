# Security & Audit Digest — 2026-09-17

## Top items

### 1. Cisco ISE Authentication Bypass Hits Max Severity, Added to CISA KEV
**Why it matters for audit/CISO/VAPT:** A CVSS 10.0 auth bypass on the platform that enforces network access control undermines every downstream access decision it makes — a single-point-of-failure auditors should flag immediately.
CISA added CVE-2026-76460, an improper-API-validation authentication bypass in Cisco Identity Services Engine, to its KEV catalog on 2026-09-16 with a federal remediation deadline of 2026-09-19. Confirm ISE patch status and review authentication logs for anomalous admin API calls. ([source](https://nvd.nist.gov/vuln/detail/CVE-2026-76460))

### 2. Cisco Secure Email Gateway RCE: Federal Patch Deadline Hits Today
**Why it matters for audit/CISO/VAPT:** The KEV remediation clock (added 2026-09-14, due 2026-09-17) expires today, turning any unpatched instance into a compliance gap as well as an active exploitation risk.
Cisco warned that a SQL injection flaw (CVE-2026-76461, CVSS 9.8) in AsyncOS for Secure Email Gateway enables unauthenticated root command execution and is under active exploitation. New IOCs were released this week to support log review. ([source](https://thehackernews.com/2026/09/cisco-secure-email-gateway-flaw.html))

### 3. CISA Warns of Active Exploitation of Critical ConnectWise ScreenConnect Flaw
**Why it matters for audit/CISO/VAPT:** ScreenConnect underpins remote-support access for many MSPs and internal help desks; compromise gives attackers a ready-made path to lateral movement across client environments.
CISA confirmed active exploitation of a critical remote-code-execution vulnerability in ConnectWise ScreenConnect. Organizations using ScreenConnect for remote support should patch immediately and review session logs for unauthorized access. ([source](https://www.bleepingcomputer.com/news/security/cisa-warns-of-hackers-exploiting-critical-screenconnect-flaw/))

### 4. WSO2 API Manager JWT Bypass Lets Attackers Forge Admin Tokens
**Why it matters for audit/CISO/VAPT:** A cryptographic-verification failure in an API gateway breaks the trust boundary between authenticated and unauthenticated traffic — a core control auditors test for in API security reviews.
watchTowr reported active exploitation attempts against CVE-2026-5430 (CVSS 9.8), an improper JWT signature verification flaw in WSO2 API Manager that allows forged administrator tokens. ([source](https://thehackernews.com/2026/09/active-exploitation-attempts-target.html))

### 5. Google Pixel Modem Zero-Day Added to KEV Amid Targeted Exploitation
**Why it matters for audit/CISO/VAPT:** Enterprise-issued Pixel devices used by field staff and security teams are affected; this is a concrete prompt to check mobile firmware patch levels in BYOD/MAM programs.
Google's September patch bundle fixed CVE-2026-58704, a privilege-escalation flaw in the Pixel Cellular Modem exploited in limited targeted attacks. CISA added it to KEV on 2026-09-16 with a 2026-09-19 deadline. ([source](https://www.bleepingcomputer.com/news/security/google-fixes-actively-exploited-android-zero-day-on-pixel-devices/))

### 6. Single Browser Extension Can Hijack AI Assistants Across Five Chromium Browsers and Claude
**Why it matters for audit/CISO/VAPT:** Demonstrates a new PoC attack surface as organizations adopt AI browser assistants for coding and research — a gap most extension-vetting and DLP policies don't yet cover.
Forever Security researchers showed an ordinary browser extension can take control of AI assistants built into Chrome, Comet, Edge, Opera Neon, and the Claude in Chrome extension, enabling conversation exfiltration and prompt injection. ([source](https://thehackernews.com/2026/09/one-extension-could-hijack-ai.html))
