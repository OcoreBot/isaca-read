# Security & Audit Digest — 2026-08-10

## Top items

### 1. Metabase Zero-Day SQL Injection Gives Unauthenticated Admin Access
**Why it matters for audit/CISO/VAPT:** Maximum-severity (CVSS 10.0), no-CVE zero-day in a widely used BI platform, already exploited against customer instances — an urgent patch/verify action for any team running Metabase.
The unauthenticated flaw in the `/session/reset_password` endpoint allows full database and admin access; Framework and Tally customer instances have already been breached via this bug. ([source](https://thehackernews.com/2026/08/metabase-zero-day-exploited-in-wild.html))

### 2. Progress Kemp LoadMaster Flaw Added to CISA KEV — Federal Deadline Today
**Why it matters for audit/CISO/VAPT:** Active exploitation of a load-balancer command injection bug (CVE-2026-8037), with a federal remediation deadline of 2026-08-10 — a concrete audit checkpoint for patch-status verification across enterprise infrastructure.
CISA added the flaw to its KEV catalog on 2026-08-07 after 792 reported exploitation attempts against Progress Kemp LoadMaster appliances. ([source](https://thehackernews.com/2026/08/progress-kemp-loadmaster-flaw-hits-cisa.html))

### 3. N-Able N-Central RMM — Second Hotfix Amid Ongoing Exploitation
**Why it matters for audit/CISO/VAPT:** RMM compromises cascade to every downstream managed customer, making this a supply-chain risk for MSP-dependent organizations; CISOs should confirm patch status with any MSP partner.
N-Able shipped a second hotfix after confirming attackers reached managed systems and established persistence, with new IOCs published in the advisory. ([source](https://thehackernews.com/2026/08/n-central-attackers-reach-managed.html))

### 4. Levi Strauss & Co. Data Theft via Social Engineering
**Why it matters for audit/CISO/VAPT:** A textbook control-failure case — three employees were socially engineered, no technical exploit required — useful evidence for audit reviews of help-desk verification and account-recovery procedures.
Levi's confirmed attackers used social engineering against three staff members to access and exfiltrate corporate data from their machines. ([source](https://www.bleepingcomputer.com/news/security/levi-strauss-and-co-says-hackers-stole-corporate-data-in-cyberattack/))

### 5. UNC6671 Vishing Campaign Targets Personal Phones for SaaS Data Theft
**Why it matters for audit/CISO/VAPT:** Bypasses technical controls entirely; a direct prompt to review security-awareness training, help-desk identity verification, and privileged password-reset workflows.
The extortion group UNC6671 is calling employees at financial services, private equity, and professional-services firms, posing as IT help desk to harvest SaaS credentials. ([source](https://thehackernews.com/2026/08/unc6671-vishing-attacks-target-personal.html))

### 6. Malware Can Abuse Windows Hello for Business Keys for Persistent Entra ID Access
**Why it matters for audit/CISO/VAPT:** Undermines the assumption that hardware-backed Windows Hello keys are immune to session-level malware abuse; CISOs should revisit Entra ID risky sign-in and device-compliance policies.
Researcher Dirk-jan Mollema showed malware in a signed-in Windows session can silently reuse the victim's Windows Hello for Business key to authenticate to Entra ID and establish longer-term cloud access. ([source](https://thehackernews.com/2026/08/malware-can-abuse-windows-hello-for.html))

### 7. TeamPCP Linked to Redis Attacks Since 2020, Now Targeting Open-Source Supply Chain
**Why it matters for audit/CISO/VAPT:** A long-dwelling threat actor pivoting into OSS supply-chain compromise — reinforces the case for SBOM coverage and dependency-scanning policy reviews.
New analysis ties TeamPCP to internet-facing infrastructure compromises dating back to 2020, with a recent shift toward software supply-chain campaigns. ([source](https://thehackernews.com/2026/08/teampcp-linked-to-redis-attacks-dating.html))
