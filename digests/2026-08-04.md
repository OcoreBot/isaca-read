# Security & Audit Digest — 2026-08-04

## Top items

### 1. N-able N-central Auth Bypass Under Active Exploitation, KEV Deadline Aug 6
**Why it matters for audit/CISO/VAPT:** N-central is a widely used RMM platform for MSPs and enterprises; unauthenticated admin access to managed endpoints is a critical VAPT and patch-verification priority with a hard federal deadline.
Attackers are exploiting CVE-2026-18577, an authentication bypass in N-able N-central, to gain remote administrative access; N-able's first fix was incomplete and build 2026.3.1.7+ is required. CISA added it to the KEV catalog on 2026-08-03 with federal remediation due 2026-08-06. ([source](https://thehackernews.com/2026/08/n-able-says-attackers-take-over-n.html))

### 2. INC Ransomware Dominant in SonicWall SMA 1000 Exploitation
**Why it matters for audit/CISO/VAPT:** VPN appliances are perimeter-critical; a ransomware group actively weaponizing recently disclosed flaws means organizations running SMA 1000 face immediate compromise risk.
Resecurity reports INC Ransomware has become the leading actor exploiting recently disclosed SonicWall SMA 1000 series VPN flaws, with active exploitation observed over the weekend. VAPT scopes should add SMA 1000 appliances and CISOs should prioritize patching or retiring end-of-life units. ([source](https://thehackernews.com/2026/08/inc-ransomware-emerges-as-dominant.html))

### 3. PNLD Breach Exposes 100,000+ UK Police and Government Contacts
**Why it matters for audit/CISO/VAPT:** A large-scale exfiltration of contact data from a government legal database points to reconnaissance for social-engineering campaigns and raises questions about export logging and access controls.
The Police National Legal Database confirmed a breach exposing names, organizations, and work emails of over 100,000 police and criminal justice staff, published on the dark web by actor ExfilSquad between July 31 and August 3. ([source](https://www.bleepingcomputer.com/news/security/exfilsquad-hackers-leak-info-of-over-100-000-uk-police-officers-staff/))

### 4. Hotel Wi-Fi Campaign Delivers Custom Malware to Breach Microsoft 365
**Why it matters for audit/CISO/VAPT:** Nation-state targeting of travel infrastructure to reach corporate M365 tenants is a classic initial-access vector auditors should test in travel-heavy organizations.
Microsoft has linked a global campaign abusing hospitality Wi-Fi networks to Russian threat actor Midnight Blizzard (APT29), which deploys custom malware to breach Microsoft 365 accounts. CISOs should reinforce VPN and MFA enforcement for traveling staff. ([source](https://www.bleepingcomputer.com/news/security/hotel-wi-fi-attacks-use-custom-malware-to-breach-microsoft-365-accounts/))

### 5. "Pass-ta-key" Attacks Bypass Google-Synced Passkeys
**Why it matters for audit/CISO/VAPT:** Passkeys are marketed as phishing-resistant, but this shows device-level malware can still extract usable credentials from cloud sync — a gap VAPT should specifically test for.
Unit 42 disclosed three attack paths letting malware on an already-compromised Windows device sign into passkey-protected accounts and extract private keys from Google Password Manager's cloud sync, without triggering biometric or PIN prompts. ([source](https://www.bleepingcomputer.com/news/security/new-pass-ta-key-attacks-let-malware-hijack-google-synced-passkeys/))

### 6. Hugging Face Diffusers Flaws Enable AI Supply-Chain Code Execution
**Why it matters for audit/CISO/VAPT:** Organizations pulling open-source models into production need provenance and sandboxing controls; this is an emerging AI supply-chain attack surface auditors should start scoping.
Three high-severity flaws in Hugging Face's Diffusers library let crafted model repositories stealthily execute arbitrary code on machines that load them, without warning. Auditors should verify model provenance checks and inference-environment sandboxing. ([source](https://thehackernews.com/2026/08/hugging-face-diffusers-flaws-could-let.html))

### 7. Thermo Fisher Patches Near-Undetectable DNA File Tampering Flaw
**Why it matters for audit/CISO/VAPT:** Undetectable alteration of forensic/analytical data files is a data-integrity and evidentiary control failure directly relevant to regulated biotech and forensics audits.
Thermo Fisher's July 31 bulletin disclosed a flaw in Applied Biosystems human-identification software that allowed .fsa/.hid data files to be altered before analysis software loads them, with changes nearly undetectable. A patch is available. ([source](https://thehackernews.com/2026/08/thermo-fisher-patches-flaw-that-could.html))
