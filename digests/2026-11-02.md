# Security & Audit Digest — 2026-11-02

## Top items

### 1. Ivanti Connect Secure zero-days chained for unauthenticated root access
**Why it matters for audit/CISO/VAPT:** Federal remediation for CVE-2026-111357 was due 2026-11-02; any org still unpatched is now past deadline and should assume compromise, not just patch.
CISA added CVE-2026-111357 (missing authentication, CVSS 8.8) and CVE-2026-118527 (predictable upload IDs) to the KEV catalog on 2026-10-30. Volexity confirmed attackers are chaining both with an earlier Ivanti flaw for unauthenticated root code execution. Patch to 25.1.1.3 or 22.8R2.6 immediately. ([source](https://www.cisa.gov/news-events/alerts/2026/10/30/cisa-adds-two-known-exploited-vulnerabilities-catalog))

### 2. Trojanized Claude Code extension distributed via Cursor Marketplace
**Why it matters for audit/CISO/VAPT:** A supply-chain compromise in a third-party IDE marketplace — not the vendor's own channel — shows extension provenance controls need auditing beyond "official" package names.
A fake build of Anthropic's Claude Code extension (versions 2.1.312/2.1.313) sat on Cursor's marketplace for ~11 hours on Oct 29, installing attacker SSH keys and reverse-tunnel persistence on up to 5,000 developer machines. Cursor has published IOCs and remediation scripts. ([source](https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html))

### 3. FBI attributes record $6.3B Binance heist to North Korea's TraderTraitor
**Why it matters for audit/CISO/VAPT:** The largest crypto heist on record is a board-level case study in state-sponsored attack capability and asset-freeze response speed for financial-sector incident playbooks.
The FBI officially linked the theft to TraderTraitor (aka Jade Sleet, UNC4899), a North Korea-aligned group. Nearly $3 billion of the stolen assets have been frozen on-chain so far. ([source](https://thehackernews.com/2026/11/fbi-links-north-koreas-tradertraitor-to.html))

### 4. Chainalysis breach attributed to "offensive agentic techniques"
**Why it matters for audit/CISO/VAPT:** Explicit vendor attribution of an intrusion to autonomous AI-agent tooling signals a new category auditors should start asking about in third-party risk reviews and logging controls.
Chainalysis confirmed external actors used agentic techniques to access internal tools, exposing customer names, emails, user IDs, and roles. Investigation content and authentication systems were not compromised. ([source](https://thehackernews.com/2026/10/chainalysis-confirms-intrusion-into.html))

### 5. VOLTA infostealer uses Claude, Gemini, and Kimi to prioritize victims
**Why it matters for audit/CISO/VAPT:** This operationalizes stolen data at scale using public LLM APIs, which argues for monitoring outbound traffic to LLM endpoints as a detection signal, not just blocking it.
VOLTA-AUTODOXER, a new Windows infostealer, uploads exfiltrated files to LLM APIs so they can rank victims by monetization value, speeding up resale of stolen credentials and PII. ([source](https://thehackernews.com/2026/11/new-volta-infostealer-uses-claude.html))

### 6. CVSS 10.0 flaw in Canonical LXD/MicroCloud allows client impersonation without a private key
**Why it matters for audit/CISO/VAPT:** Max-severity, low-prerequisite auth bypass in a container/cloud management plane — a priority item for any VAPT scope covering LXD or MicroCloud deployments.
An attacker with network access to the HTTPS API and a trusted client's public certificate (no private key needed) can impersonate that client. Patch immediately. ([source](https://thehackernews.com/2026/11/critical-lxd-and-microcloud-flaw-cvss.html))

### 7. Drupal Commerce Core authorization bypass under active exploitation
**Why it matters for audit/CISO/VAPT:** Unauthenticated access-control bypass on e-commerce infrastructure, already being exploited — an immediate patch-verification item for audit teams covering online payment platforms.
CVE-2026-118539 lets unauthenticated attackers bypass access controls in Commerce Core versions 0.0.0–2.41 and 3.0–3.x, risking data exfiltration and fraudulent transactions. ([source](https://thehackernews.com/2026/10/hackers-actively-exploit-highly.html))

### 8. Linux kernel MPTCP flaw gives unauthenticated root RCE
**Why it matters for audit/CISO/VAPT:** Discovered using AI-assisted analysis, this is an early real-world example of AI lowering the bar for finding kernel-level RCE chains — relevant to VAPT teams assessing exposure timelines going forward.
CVE-2026-98432 is a use-after-free race condition in kernel MPTCP code enabling unauthenticated remote root execution on servers with an MPTCP listener (not default). Workaround: disable MPTCP (`net.mptcp.enabled=0`) until patched. ([source](https://isc.sans.edu/podcastdetail/10158))
