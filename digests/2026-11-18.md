# Security & Audit Digest — 2026-11-18

## Top items

### 1. Java4Shell (CVE-2026-114938): CISA urges immediate patching
**Why it matters for audit/CISO/VAPT:** Pre-auth RCE in CI/CD and identity platforms is a top patch-SLA and testing priority. Scope JVM versions and check Jenkins, Jira and Keycloak hosts.
CISA says the flaw is a memory-corruption bug in the Base64 decoder of the x86-64 HotSpot JVM. Calif says it can give unauthenticated RCE in Jira, Jenkins, Keycloak and other apps. Oracle fixed it in its November Critical Patch Update. Sources differ on exact affected versions and CPU scope, so confirm against Oracle's advisory. ([source](https://www.cisa.gov/news-events/alerts/2026/11/17/critical-java-vulnerability-requires-immediate-patching))

### 2. Microsoft Agent Framework PyPI package compromised to steal cloud credentials
**Why it matters for audit/CISO/VAPT:** Direct software supply-chain risk for teams building AI agents. Check whether versions 1.26.1 or 1.26.2 were installed in dev, CI or production, and rotate cloud credentials on those hosts.
Attackers published malicious versions 1.26.1 and 1.26.2 carrying a credential stealer, about 33 minutes after the legitimate releases. Several security vendors reported it independently. ([source](https://thehackernews.com/2026/11/attackers-compromise-microsofts-agent.html))

### 3. Optimizely hijack update: Krebs details malware A/B testing on top sites
**Why it matters for audit/CISO/VAPT:** Third-party JavaScript on payment pages is a PCI DSS 6.4.3 / 11.6.1 issue. Inventory third-party tags and check SRI and CSP.
Reporting now says at least 178 organizations served exploits and skimmers to visitors. The count varies by source. Stormcast suggests blocking optimizely.com and the .icu TLD as a stopgap. First covered yesterday. ([source](https://krebsonsecurity.com/2026/11/attackers-used-optimizely-to-a-b-test-malware-on-top-websites/))

### 4. Puppet Enterprise (CVE-2026-115731) added to CISA KEV
**Why it matters for audit/CISO/VAPT:** Puppet servers hold configuration and secrets for whole fleets. KEV means active exploitation, so treat it as a short-SLA patch.
The flaw is a deserialization of untrusted data in Perforce Puppet Enterprise. Federal remediation is due 2026-12-01. Confirm the version on all masters. ([source](https://www.cisa.gov/news-events/alerts/2026/11/17/cisa-adds-one-known-exploited-vulnerability-catalog))

### 5. Cold Relic turns one Google Workspace compromise into linked intrusions
**Why it matters for audit/CISO/VAPT:** One cloud identity or data-theft event can spread to partners. Review Workspace audit logs, OAuth grants and third-party data sharing.
Google's Mandiant and GTIG say the Russia-linked group (formerly COLDRIVER/UNC4057) used stolen Workspace data to breach a second U.S. organization and related third parties. ([source](https://thehackernews.com/2026/11/russian-cold-relic-hackers-use-stolen.html))

### 6. Stolen Fireworks AI key led to trojanized Claude Code extension on Cursor; Uber drivers notified
**Why it matters for audit/CISO/VAPT:** Vendor-issued API keys are a third-party risk. Inventory keys issued to AI vendors, scope them, and rotate after a vendor breach.
Cursor says an access key it issued to Fireworks was stolen and used to compromise the Claude Code extension on its marketplace. Uber is notifying nearly 150,000 drivers whose data was stolen in the early-October Fireworks breach. ([source](https://thehackernews.com/2026/11/stolen-fireworks-ai-key-led-to-cursor.html))

### 7. Cloud keys leaked in Docker Hub images are stolen within seconds
**Why it matters for audit/CISO/VAPT:** Secrets baked into images are a common audit finding. Add secret scanning to image build pipelines and review the organization's public repositories.
Credentials in public Docker Hub images are being extracted and used in as little as eight seconds after publication. ([source](https://www.bleepingcomputer.com/news/security/cloud-keys-leaked-in-docker-hub-images-are-stolen-within-seconds/))

### 8. GitDoor and GraphDoor backdoors use GitHub and SharePoint for C2
**Why it matters for audit/CISO/VAPT:** C2 over trusted SaaS is hard to block by domain. Hunt for unusual GitHub and SharePoint API traffic from servers and review egress rules.
A campaign against government sectors in Asia and Africa uses two previously undocumented backdoors that rely on legitimate GitHub and Microsoft SharePoint services. ([source](https://thehackernews.com/2026/11/new-gitdoor-and-graphdoor-backdoors.html))
