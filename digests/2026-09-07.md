# Security & Audit Digest — 2026-09-07

## Top items

### 1. MikroTik SSH Auth Bypass — Actively Exploited, Assume Compromise
**Why it matters for audit/CISO/VAPT:** Unauthenticated full admin takeover on internet-exposed routers is a critical perimeter failure; auditors should treat any exposed MikroTik device as compromised until proven otherwise.
CERT Polska and SANS ISC warn attackers are hijacking internet-exposed MikroTik SSH services without authentication, adding accounts to maintain persistence. MikroTik shipped a patch, but exploitation predates it — assume breach and hunt for rogue accounts. ([source](https://thehackernews.com/2026/09/attackers-hijack-mikrotik-routers.html))

### 2. Chrome V8 Zero-Day Added to CISA KEV — Federal Deadline Sep 18
**Why it matters for audit/CISO/VAPT:** Concrete compliance deadline for federal-adjacent orgs, plus a live exploited browser bug that VAPT teams should expect in phishing/drive-by chains.
CVE-2026-85046, a V8 type-confusion bug (CVSS 8.8), is under active exploitation and was added to CISA's KEV catalog on Sep 4 with remediation due Sep 18. Validate Chrome patch adoption org-wide. ([source](https://www.cisa.gov/news-events/alerts/2026/09/04/cisa-adds-one-known-exploited-vulnerability-catalog))

### 3. CrowdStrike Falcon "FalconFlank" Zero-Day — SYSTEM Privilege Escalation
**Why it matters for audit/CISO/VAPT:** A privesc bug in an EDR agent undermines the control that many audits rely on as a compensating control; no patch yet.
Researcher "Nightmare Eclipse" published a zero-day (FalconFlank) letting attackers escalate to SYSTEM on fully patched Windows hosts running CrowdStrike Falcon. No fix is available; monitor for detection signatures. ([source](https://www.bleepingcomputer.com/news/security/new-crowdstrike-falconflank-zero-day-grants-system-privileges/))

### 4. Unpatched Magento/Adobe Commerce Zero-Day — Active Backdoor Campaign
**Why it matters for audit/CISO/VAPT:** Unauthenticated RCE with no patch and active in-the-wild backdooring is a same-day incident-response trigger for e-commerce environments.
Sansec disclosed active exploitation of an unpatched Magento Open Source/Adobe Commerce flaw allowing unauthenticated code execution and backdoor installation on online stores. ([source](https://thehackernews.com/2026/09/unpatched-magento-and-adobe-commerce.html))

### 5. JetBrains Cadence Breached via Unpatched TeamCity — Credential Rotation Urged
**Why it matters for audit/CISO/VAPT:** Supply-chain/vendor-risk lesson: JetBrains' own infrastructure was breached through an unpatched CVE, exposing AWS credentials — a textbook control-failure case for audit writeups.
JetBrains disclosed that attackers exploited a recently disclosed critical TeamCity vulnerability to breach its Cadence environment last month, extracting AWS credentials. All Cadence users are urged to rotate credentials immediately. ([source](https://thehackernews.com/2026/09/attackers-breached-jetbrains-cadence.html))

### 6. Citrix NetScaler Auth Bypass (CVE-2026-19490) Under Active Attack
**Why it matters for audit/CISO/VAPT:** NetScaler sits at the network perimeter; an auth-bypass there is a complete access-control failure and a priority item for any external attack-surface review.
Vulnerability intelligence firm Previdian reports active in-the-wild targeting of a critical Citrix NetScaler authentication bypass. Inventory and patch/segment all instances immediately. ([source](https://www.bleepingcomputer.com/news/security/hackers-target-critical-citrix-netscaler-auth-bypass-in-attacks/))

### 7. VMware Workstation/Fusion Critical RCE (CVE-2026-59346, CVSS 9.3)
**Why it matters for audit/CISO/VAPT:** Hypervisor-escape-class bug affecting any developer/research workstation running untrusted code in a VM — a common gap in endpoint patch audits.
Broadcom patched two flaws in VMware Workstation and Fusion, including an integer-overflow RCE (CVSS 9.3) that can allow VM guest-to-host code execution under certain conditions. ([source](https://thehackernews.com/2026/09/critical-vmware-workstation-and-fusion.html))

### 8. PaperCut Flaws Exploited Against Schools and Universities
**Why it matters for audit/CISO/VAPT:** Active credential-theft exploitation against a widely deployed print-management platform in a sector with weak baseline security controls.
Arctic Wolf observed attackers exploiting CVE-2026-81578 and CVE-2026-82078 in PaperCut to steal credentials from U.S. and European education-sector targets. Patch and rotate credentials. ([source](https://thehackernews.com/2026/09/attackers-exploit-papercut-flaws-to.html))
