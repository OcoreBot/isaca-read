# Security & Audit Digest — 2026-08-07

## Top items

### 1. CISA KEV Trio Hits Federal Deadline Today: Langflow, N-central, Tomcat
**Why it matters for audit/CISO/VAPT:** Three actively exploited flaws added to KEV on 2026-08-04 carry a federal remediation deadline of 2026-08-07 — today — making this the most time-critical patch-verification item in the window.
CISA added CVE-2026-9198 (IBM Langflow code injection), CVE-2026-18556 (N-able N-central auth bypass), and CVE-2026-34486 (Apache Tomcat missing encryption), all confirmed under active exploitation. Auditors should confirm remediation evidence exists today; VAPT should retest exposure wherever patches are still pending. ([source](https://www.cisa.gov/news-events/alerts/2026/08/04/cisa-adds-three-known-exploited-vulnerabilities-catalog))

### 2. Snowflake Breach Hacker Pleads Guilty to Attacks on 165+ Organizations
**Why it matters for audit/CISO/VAPT:** Legal resolution confirms the scale (100M+ records, 165 organizations) of a breach driven by missing MFA on customer accounts — durable evidence for third-party SaaS-risk audits.
Connor Riley Moucka pleaded guilty in Seattle federal court on 2026-08-06 to computer fraud, wire fraud, and aggravated identity theft over the 2024 Snowflake customer-account breaches. Audit teams can cite this case when justifying mandatory MFA and credential-hygiene controls for SaaS platforms. ([source](https://thehackernews.com/2026/08/snowflake-hacker-pleads-guilty-over.html))

### 3. Ransom Cartel RaaS Operator Sentenced to 16 Years
**Why it matters for audit/CISO/VAPT:** Removes an active ransomware-as-a-service operator from circulation and confirms RaaS attribution and prosecution are increasingly viable — useful for board-level threat-landscape reporting.
Maksim Silnikau was sentenced on 2026-08-05 for creating and running Ransom Cartel, which attacked at least 18 companies between 2021 and 2023. No direct control action needed; CISOs can cite it in threat-landscape updates. ([source](https://thehackernews.com/2026/08/ransom-cartel-creator-gets-16-years-in.html))

### 4. Over 4,400 Internet-Exposed Rockwell PLCs, 22 in Cities Hit by Water-Utility Attacks
**Why it matters for audit/CISO/VAPT:** Internet-facing industrial control systems in already-targeted municipalities is a concrete OT exposure finding, not a theoretical risk.
Forescout's August 3 scan found 4,407 exposed Rockwell Automation PLCs worldwide, including 22 in US cities recently hit by water-utility cyberattacks, 19 sharing the same mobile carrier network. Audit and VAPT teams supporting critical-infrastructure clients should prioritize external-exposure scans of OT/ICS assets. ([source](https://thehackernews.com/2026/08/over-4400-rockwell-plcs-exposed-online.html))

### 5. Swiss Government SharePoint Breach Compromises 200 Accounts
**Why it matters for audit/CISO/VAPT:** A national government IT office falling to exploited SharePoint vulnerabilities is a control-failure case study directly applicable to enterprise SharePoint patch-audit scope.
Switzerland's federal IT office confirmed attackers exploited vulnerabilities to breach its Microsoft SharePoint servers, compromising roughly 200 accounts. Audit should verify SharePoint patch cadence and account-monitoring controls. ([source](https://www.bleepingcomputer.com/news/security/swiss-government-sharepoint-breach-compromised-200-accounts/))

### 6. AWS, Google, and Vercel Agent Flaws Let Attackers Trigger Tools Without the Model Running
**Why it matters for audit/CISO/VAPT:** Trust-boundary failures in AI-agent infrastructure — untrusted instructions reached production tools with no model-authorization check — are a governance gap distinct from prompt injection that boards are now asking about.
Researchers disclosed flaws across AWS, Google, and Vercel agent platforms letting forged instructions reach an agent's tools with no check that a model turn had authorized them; in several paths the model never ran. Audit should add tool-authorization checks to AI-agent deployment reviews. ([source](https://thehackernews.com/2026/08/aws-google-and-vercel-patch-agent-flaws.html))

### 7. Zapscape KVM Flaw Lets Privileged Guest Code Escape to the Linux Host
**Why it matters for audit/CISO/VAPT:** A guest-to-host virtualization escape is a top-tier finding for VAPT engagements covering nested-virtualization or multi-tenant hosting.
A newly disclosed Linux kernel flaw, dubbed Zapscape, lets an attacker with kernel privileges inside a nested (L1) guest VM escape KVM isolation and run code on the host when nested virtualization is exposed to untrusted guests. Audit should confirm nested virtualization is disabled for untrusted tenants. ([source](https://thehackernews.com/2026/08/new-zapscape-kvm-flaw-could-let.html))

### 8. New Interrupt-Injection Attack Bypasses Spectre v2 Defenses on Intel and AMD
**Why it matters for audit/CISO/VAPT:** A working technique that defeats deployed Spectre v2 mitigations on mainstream CPUs undermines a control many organizations already treat as closed.
MIT CSAIL researchers showed an unprivileged Linux program can time a hardware interrupt to re-poison the branch predictor after Spectre v2 mitigations run. Audit should not treat Spectre v2 mitigation as a closed finding pending vendor guidance. ([source](https://thehackernews.com/2026/08/new-interrupt-injection-attack-can.html))

### 9. Cisco Patches 12 SD-WAN and IOS XE Flaws, Three Rated CVSS 9.8
**Why it matters for audit/CISO/VAPT:** Critical flaws in widely deployed SD-WAN and IOS XE software, found via an internal Cisco security review, are a direct network-infrastructure patch-verification item.
Cisco released updates for 12 vulnerabilities in Catalyst SD-WAN and IOS XE, including three rated CVSS 9.8, affecting devices regardless of configuration. Audit should confirm patch deployment; VAPT should retest perimeter devices post-patch. ([source](https://thehackernews.com/2026/08/cisco-patches-12-sd-wan-and-ios-xe.html))
