# Security & Audit Digest — 2026-09-01

## Top items

### 1. CISA Adds PaperCut Flaws to KEV; Public Metasploit Exploit Now Available
**Why it matters for audit/CISO/VAPT:** KEV listing plus a public Metasploit module means unauthenticated RCE against PaperCut is now trivial to weaponize; federal remediation is due 2026-09-14, and any organization running PaperCut should treat this as an emergency-change item, not routine patching.
CISA added CVE-2026-81578 (missing authentication) and CVE-2026-82078 (unsafe reflection) in PaperCut NG/MF to its Known Exploited Vulnerabilities catalog on 2026-08-31. SANS reports a working Metasploit exploit chaining both flaws is now public. ([source](https://www.cisa.gov/news-events/alerts/2026/08/31/cisa-adds-two-known-exploited-vulnerabilities-catalog))

### 2. China-Linked Fire Ant Hijacks Cisco Routers and TACACS Servers, Blinds Security Logs
**Why it matters for audit/CISO/VAPT:** A nation-state actor tampering with authentication servers and log integrity on network infrastructure defeats standard detection and evidentiary controls — a direct control-failure lesson for network-device change management and log-tamper monitoring audits.
Fire Ant, a China-nexus espionage group previously known for VMware hypervisor compromise, has expanded to Cisco IOS XR routers, TACACS authentication servers, and Linux management hosts, using an unexplained GRE tunnel to route traffic while suppressing logs. ([source](https://thehackernews.com/2026/08/china-linked-fire-ant-hijacks-cisco.html))

### 3. Anthropic Ships Compliance API for Claude Code Visibility and Identity Governance
**Why it matters for audit/CISO/VAPT:** AI coding agents run shell commands and hold developer credentials with little existing oversight; this closes a governance gap boards and auditors have been flagging, and should be evaluated for enablement wherever Claude Code is in use.
Anthropic's new Compliance API endpoints give security teams visibility into Claude Code's file access, shell commands, and MCP tool invocations, plus identity-governance controls over agent credentials. ([source](https://thehackernews.com/2026/08/securing-claude-code-new-compliance-api.html))

### 4. Microsoft Details TerminalFix: Reverse-Tunnel Backdoor via Fake Cloudflare CAPTCHA
**Why it matters for audit/CISO/VAPT:** Expands on the 2026-08-29/30 initial reports with Microsoft's own technical detail — DLL side-loading, steganographic payloads, and persistent SOCKS-proxy tunnels — giving VAPT teams concrete detection targets beyond the original ClickFix pattern.
Microsoft disclosed that TerminalFix, a ClickFix variant using spoofed Cloudflare CAPTCHA pages, tricks users into pasting commands into Windows Terminal/PowerShell, then deploys a persistent backdoor with SOCKS-proxy capability for lateral movement and exfiltration. ([source](https://www.bleepingcomputer.com/news/security/microsoft-warns-of-terminalfix-attacks-deploying-reverse-tunnels/))

### 5. Aurora Ransomware Operators Weaponize Cursor AI Coding Assistant
**Why it matters for audit/CISO/VAPT:** First documented case of ransomware operators using an AI coding assistant as an intrusion tool against real targets — VAPT teams should factor AI-assisted exploitation speed into engagement scoping and detection baselines.
CloudSEK and Gambit Security independently found Aurora (Aur0ra) ransomware affiliates using the Cursor AI coding assistant to breach at least 10 target networks. ([source](https://thehackernews.com/2026/08/aurora-ransomware-operators-use-cursor.html))

### 6. ValleyRAT Backdoor Hides in Signed Adware, Bypassing AV Exclusions
**Why it matters for audit/CISO/VAPT:** Abuses the common practice of excluding "trusted" signed software from AV scanning — audit endpoint-exclusion policies and code-signing trust decisions, since a valid signature is no longer a sufficient control.
Silver Fox is distributing the ValleyRAT backdoor disguised as a signed Chinese adware application, running under a trusted process so it evades detection once users add it to antivirus exclusions. ([source](https://thehackernews.com/2026/08/valleyrat-backdoor-hides-in-signed.html))

### 7. Exposed LLM Inference Endpoints Hijacked and Resold as "Free" AI Backends
**Why it matters for audit/CISO/VAPT:** A new AI supply-chain risk: attackers repurpose compromised inference endpoints as convincing fake commercial models, capturing coding-agent sessions and data passed through them — procurement and cloud audit should verify LLM API provenance.
A SANS ISC honeypot posing as an exposed inference endpoint was discovered, relabeled with sought-after model names, and folded into infrastructure offering "free" LLM backends, then received a real coding-agent session. ([source](https://isc.sans.edu/diary/rss/33298))

### 8. DoJ Corrects Claim: Federal Agencies Were Targets, Not Confirmed Victims, of China Hacking
**Why it matters for audit/CISO/VAPT:** A walked-back scope claim on nation-state targeting of US agencies is a reminder to verify incident-scope statements before updating risk registers or vendor-notification obligations tied to federal-customer exposure.
The DoJ corrected an earlier statement, clarifying that several federal agencies were among the parties targeted by Chinese threat actors rather than confirmed victims of compromise. ([source](https://thehackernews.com/2026/08/doj-corrects-china-hacking-claim-says.html))
