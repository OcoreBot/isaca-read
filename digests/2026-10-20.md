# Security & Audit Digest — 2026-10-20

## Top items

### 1. Plex2Shell: Unauthenticated RCE Chain Actively Exploited for Crypto Mining and Backdoors
**Why it matters for audit/CISO/VAPT:** A public PoC turned into real-world exploitation within 24 hours, underscoring why internet-facing media/file servers need the same patch-SLA rigor as core infrastructure.
A four-CVE chain in Plex Media Server (SSRF to loopback plus admin-token theft) lets unauthenticated attackers run code remotely. Threat actors are already deploying cryptocurrency miners and a Linux reverse-proxy backdoor on exposed instances. Audit teams should inventory internet-facing Plex servers and verify patch status immediately. ([The Hacker News](https://thehackernews.com/2026/10/hackers-exploit-plex2shell-flaws-to.html))

### 2. F5 Issues Out-of-Band Patches for Critical NGINX Vulnerabilities
**Why it matters for audit/CISO/VAPT:** NGINX underpins a huge share of web and API infrastructure; an out-of-band (not scheduled) release signals urgency that should trigger expedited change-management review.
F5 released emergency patches for multiple NGINX flaws, including three critical-severity bugs permitting remote code execution. Organizations running NGINX should confirm version status and prioritize patching outside the normal cycle. ([BleepingComputer](https://www.bleepingcomputer.com/news/security/f5-releases-out-of-band-patches-for-critical-nginx-vulnerabilities/))

### 3. OVHcloud CLI Tooling Briefly Compromised with Infostealer
**Why it matters for audit/CISO/VAPT:** A trusted infrastructure vendor's own CLI distribution channel was briefly weaponized — a reminder that supply-chain audits must cover tooling, not just application dependencies.
OVHcloud's command-line tools were compromised for several hours on October 18 and bundled an infostealer; the issue surfaced when users noticed unexpected package-hash changes. Version 0.16.0 remediates the flaw. Organizations should audit for credential exposure and consider hash-pinning as a control. ([SANS Stormcast](https://isc.sans.edu/podcastdetail/10142))

### 4. ROMULUS ClickFix Platform Fuels LegionLoader and Other Malware Delivery
**Why it matters for audit/CISO/VAPT:** A dedicated "malware delivery as a service" platform using ClickFix-style social engineering is a new technique VAPT teams should factor into phishing-simulation and endpoint-detection testing.
Researchers at Forescout's Vedere Labs disclosed ROMULUS, a ClickFix delivery platform distributing LegionLoader and other payloads via fake fix-it prompts. Review email/web filtering and user-awareness controls against this technique. ([The Hacker News](https://thehackernews.com/2026/10/romulus-clickfix-platform-tricks-users.html))

### 5. GhostAction Supply-Chain Campaign Expands: Stealer Hidden in Fake Font File Across 94 Repos
**Why it matters for audit/CISO/VAPT:** The same actor behind GitHub Actions workflow injection is now phishing developers directly, showing supply-chain attacks are diversifying beyond CI/CD pipeline abuse.
The GhostAction threat actor planted a credential-stealing payload disguised as a font file across 94 GitHub repositories, expanding from its earlier workflow-injection technique. Organizations with public repos should review for the indicator and tighten contributor/dependency review. ([The Hacker News](https://thehackernews.com/2026/10/ghostaction-attackers-plant-credential.html))
