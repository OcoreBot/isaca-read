# Security & Audit Digest — 2026-08-21

## Top items

### 1. Zimbra Collaboration Suite RCE flaw now under active exploitation
**Why it matters for audit/CISO/VAPT:** Unauthenticated remote code execution on mail/collaboration servers is a critical, no-user-interaction risk — priority item for emergency patch-verification audits and mail-infrastructure VAPT.
CERT Polska warned that attackers have begun exploiting CVE-2026-73570 (CVSS 8.9), an SNMP-handling flaw in Zimbra Collaboration Suite, to achieve remote code execution. ([source](https://www.bleepingcomputer.com/news/security/critical-zimbra-rce-flaw-now-actively-exploited-in-attacks/))

### 2. Critical Citrix NetScaler flaw allows authentication bypass on Gateway/AAA
**Why it matters for audit/CISO/VAPT:** NetScaler sits at the perimeter for remote access and application delivery; an auth-bypass here is a direct access-control audit finding and a mandatory VAPT scope item for any remote-access review.
Citrix released updates for two NetScaler ADC and Gateway vulnerabilities, including a critical-severity flaw that can bypass authentication on certain Gateway and AAA server configurations, and urged admins to patch immediately. ([source](https://www.bleepingcomputer.com/news/security/citrix-urges-admins-to-patch-new-netscaler-flaws-as-soon-as-possible/))

### 3. CISA adds two TrueConf Server flaws to KEV, deadlines Aug 23 and Sep 3
**Why it matters for audit/CISO/VAPT:** Hard federal remediation dates give audit teams a concrete control-test window; TrueConf is used in public-sector communications, making patch-verification a near-term priority.
CISA added CVE-2026-72529 (missing authentication for a critical function) and CVE-2026-72530 (code injection) to its Known Exploited Vulnerabilities catalog, with federal remediation due 2026-08-23 and 2026-09-03 respectively. ([source](https://www.cisa.gov/news-events/alerts/2026/08/20/cisa-adds-two-known-exploited-vulnerabilities-catalog))

### 4. Rust supply-chain attack poisons crates with 245 million downloads
**Why it matters for audit/CISO/VAPT:** Build-time compromise bypasses runtime security controls entirely — audit teams should extend SDLC checks to crate provenance and build-script review, and VAPT should test dev/build environments for artifact tampering.
A compromised maintainer account published malicious versions of three widely used Rust crates, including arrayref, adding a typosquatted dependency whose build script fetched and ran a remote payload during compilation; the Rust Project has removed the malicious releases. ([source](https://www.bleepingcomputer.com/news/security/hackers-poison-arrayref-rust-crate-to-push-infostealer-malware/))

### 5. Critical Elementor Pro flaw enables unauthenticated RCE on WordPress
**Why it matters for audit/CISO/VAPT:** Elementor Pro is deployed on thousands of production CMS sites; unauthenticated file upload leading to RCE (CVSS 9.0) should be in every WordPress VAPT scope and flagged as an urgent audit finding where unpatched.
Researchers disclosed CVE-2026-32475, a critical flaw in the Elementor Pro WordPress plugin that lets unauthenticated attackers upload PHP files and execute code on the server. ([source](https://www.bleepingcomputer.com/news/security/critical-elementor-pro-bug-exposes-wordpress-sites-to-rce-attacks/))

### 6. Manic Android malware exfiltrates data via nearby devices, targets banks and government
**Why it matters for audit/CISO/VAPT:** A P2P exfiltration path that works even on offline phones defeats standard network-based DLP; financial-sector and government CISOs should update mobile-threat awareness, and VAPT mobile scopes should add offline-exfiltration scenarios.
New Android malware dubbed Manic targets Ukrainian banks and government identity services along with European fintech and crypto platforms, using a fallback mechanism that exfiltrates data through nearby infected devices when the target phone is offline. ([source](https://www.bleepingcomputer.com/news/security/new-manic-android-malware-can-exfiltrate-data-through-nearby-devices/))

### 7. Suspected Russian actors abuse Google OAuth and WhatsApp linking to hijack accounts
**Why it matters for audit/CISO/VAPT:** Weaponizing legitimate authentication flows evades typical phishing controls; high-risk organizations should audit access logs for unusual OAuth grants and device-linking events and review MFA/account-recovery policy gaps.
Three suspected Russian espionage clusters are abusing legitimate Google OAuth and WhatsApp device-linking flows to hijack accounts of individuals in academia, aerospace, defense, and government across Europe. ([source](https://thehackernews.com/2026/08/suspected-russian-hackers-abuse-google.html))
