# Security & Audit Digest — 2026-11-16

## Top items

### 1. Check Point gateways exploited via PHP2Shell and a Gaia root escalation
**Why it matters for audit/CISO/VAPT:** Root-level persistence on a perimeter security device. Audit and VAPT should hunt for web shells, not just check version numbers.
Attackers have hit unpatched Check Point Security Gateways since late October. They chain PHP2Shell (CVE-2026-109618, CVE-2026-109619) with a Gaia OS privilege escalation (CVE-2026-123039). Payloads include the TSGA backdoor and a VMware ESXi wiper. CISA added CVE-2026-123039 to KEV on 2026-11-13 with a 2026-11-16 federal deadline, and Check Point has shipped emergency hotfixes. ([source](https://www.bleepingcomputer.com/news/security/check-point-gateways-hacked-via-php2shell-to-deploy-vmware-esxi-wiper/))

### 2. UnrealIRCd command injection added to CISA KEV (CVE-2026-114713)
**Why it matters for audit/CISO/VAPT:** KEV entries carry short federal deadlines and are a standard audit test. Confirm UnrealIRCd is patched or removed.
CISA added the high-severity delimiter-neutralization flaw after reports of active exploitation. It allows server-level command injection. Remediation is due 2026-11-16. ([source](https://thehackernews.com/2026/11/attackers-exploit-unrealircd-flaw-that.html))

### 3. Cursor breach: stolen Fireworks AI key led to trojanized Claude Code extension
**Why it matters for audit/CISO/VAPT:** A supply-chain and secrets-management failure. Credential inventories and rotation must be complete and cover third-party channels.
Cursor confirmed attackers used an access key exposed in the Fireworks AI breach to push a malicious Claude Code extension through its marketplace. Cursor says an earlier rotation missed a credential, which was later used in the compromise. ([source](https://www.bleepingcomputer.com/news/security/cursor-confirms-security-breach-led-to-malicious-claude-code-extension/))

### 4. FBI warns attackers are using the ARTEX AI pentest framework
**Why it matters for audit/CISO/VAPT:** Automated offensive tooling speeds up exploitation. VAPT teams should check how their own tools are controlled, and defenders should test detection of AI-driven scanning.
The FBI says ARTEX automates attacks on organizations worldwide. Reporting ties it to a ConnectWise supply-chain breach that affected Microsoft 365 customer environments. ([source](https://www.bleepingcomputer.com/news/security/fbi-warns-artex-ai-hacking-tool-is-powering-global-cyberattacks/))

### 5. N-central flaws exploited; 21 servers infected
**Why it matters for audit/CISO/VAPT:** RMM platforms have privileged reach into client estates. Check patch level and whether management integrations are still enabled.
Attackers are exploiting the newly disclosed 4EverAble2Shell and Agent2Shell flaws. 19 of the 21 infected servers ran Hotfix 2. N-able is restricting some N-central features and integrations. ([source](https://thehackernews.com/2026/11/hackers-exploit-n-central-flaws-to.html))

### 6. Trezor confirms implants in three CryptoBilis-resold wallets
**Why it matters for audit/CISO/VAPT:** Hardware tampering is a real third-party risk. Procurement should require authorized channels and device verification.
Three Safe 5 wallets from reseller CryptoBilis contained an extra circuit board that reads recovery phrases from the screen and sends them over cellular networks. Trezor has released a fix. ([source](https://thehackernews.com/2026/11/trezor-confirms-hidden-hardware.html))

### 7. PostgreSQL patches 52 flaws, including a 22-year-old authenticated RCE
**Why it matters for audit/CISO/VAPT:** Patching the server isn't enough. Audit should confirm C-language extensions were rebuilt.
A type-confusion flaw lets a user who can create objects run code on the server. Full protection requires rebuilding installed C extensions. ([source](https://thehackernews.com/2026/11/postgresql-patches-52-flaws-including.html))

### 8. Mior and Skyfall attacks break AMD SEV-SNP guarantees
**Why it matters for audit/CISO/VAPT:** Confidential computing is often cited as a control against malicious hosts. Cloud risk assessments should reflect that attestation can be forged.
A malicious host can read data inside SEV-SNP VMs. Mior can also modify VM memory and fake the signed attestation report. ([source](https://thehackernews.com/2026/11/new-mior-and-skyfall-attacks-let-rogue.html))

### 9. Italy fines Meta €805M over default-on gallery access
**Why it matters for audit/CISO/VAPT:** A privacy-by-default enforcement example for reviewing consent and default settings.
The Garante found a Facebook for Android photo-suggestion feature accessed phone galleries by default without explicit consent. ([source](https://thehackernews.com/2026/11/italy-fines-meta-805-million-over.html))
