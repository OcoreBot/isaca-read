# Podcast Notes — Week 2026-W43

## Risky Business — Risky Business #856: 8-bit encryption, PHP megabugs and more (2026-10-21)
- The PHP Foundation is rushing patches for critical bugs the hosts expect to see exploited quickly once releases land — teams running PHP should be ready to patch fast rather than on a normal cycle.
- Private keys behind some certificate authority certs turned out to have only 8 bits of entropy, making them effectively guessable; this breaks the trust chain for any cert issued with those keys, not just a theoretical weakness.
- An OpenCode breach exposed users' AI-provider API keys, adding developer AI tooling to the list of places credentials leak — alongside a DHS ban on DeepSeek for federal civilian agencies and Microsoft's latest large patch batch.

[Episode link](https://risky.biz/RB856/)

## CISO Series / Defense in Depth — How Do You Demonstrate Resilience? (2026-10-22)
- Host David Spark frames resilience as a capability distinct from security posture — boards now expect leaders to prove both, so a single "we're secure" narrative isn't enough.
- Co-host Eddie Contreras (CISO, Frost Bank) argues the evidence of resilience has to change for the audience: the easier the story is for the board and execs to follow, the more productive the conversation.
- Sponsored guest Snehal Antani (CEO, Horizon3.ai) pushes back on surface-level incident reporting — e.g. don't just report "we had a phishing incident," report whether it led to real compromise (did the credential get domain admin?) — resilience should be shown through repeated testing and retesting, not static compliance snapshots.

[Episode link](https://cisoseries.com/how-do-you-show-resilience/)

## ISACA Podcast — COBIT at 30: A Global Framework Uniting IT Governance Across Borders (2026-10-22)
- Mark Thomas and a panel of global practitioners trace COBIT's path from a narrow set of control objectives in 1996 to a full governance framework — the point being it had to stay adaptable to local regulation while keeping one common IT-governance language across regions.
- The discussion ties COBIT's 30-year run to "digital trust": its value now is less about a single control checklist and more about giving structure to technology change as environments get more complex.
- The episode lands alongside ISACA's own anniversary newsletter noting a COBIT update is planned later this year, delivered mostly in digital form — a signal that the framework practitioners are relying on is about to shift.

[Episode link](https://isacapodcast.podbean.com/e/cobit-at-30-a-global-framework-uniting-it-governance-across-borders/)

## Audit, CISO & VAPT angle
The 8-bit-entropy CA key failure is a direct VAPT and audit talking point: it's a reminder to actually test key-generation randomness and certificate issuance controls rather than assume CA-issued keys are automatically strong. The OpenCode/AI-provider key exposure extends the same lesson to developer tooling — credential handling in AI-assisted dev workflows is now fair game for engagement scoping. On the governance side, Defense in Depth's resilience-vs-posture distinction is worth bringing into board reporting: clients should be pushed past "we didn't get breached" toward evidence that controls were tested and held under pressure. And with ISACA flagging a COBIT update later this year right as it marks the framework's 30th anniversary, audit teams should start watching for scope changes rather than be caught assessing against a framework version that's about to move.
