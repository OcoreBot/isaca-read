# Podcast Notes — Week 2026-W45

## Risky Business — #858 "The $6.3b laptop" (2026-11-04)
- Crypto theft dominated: Binance's October 29 hot-wallet incident (a ~$6.3b figure, described on the show as "pretty clunky"), plus Mercado Bitcoin in Brazil, a Polymarket compromise via a third-party script (DebugBear) and a warning about a suspected implant in a Trezor hardware wallet. Third-party scripts and supply chain remain the soft spot.
- AI abuse is now operational: Google says LLMjacking can run up $1m in cloud AI bills, Northflank's breach led to abuse of customers' AI API keys, and a trojanized Claude Code extension was reported. An AI agent also reportedly hacked another infosec researcher.
- Heavy edge-device exploitation: Cisco SD-WAN (KeyDrift malware), Palo Alto firewalls via chained PHP flaws, Ivanti Connect Secure zero-days, a GitLab CI/CD RCE, CISA's warning on Node2Shell, and a critical Linux MPTCP bug. Guest sponsor segment (runZero) covered post-quantum crypto and retiring end-of-life products.

## CISO Series / Defense in Depth — Is Our Dated Hiring Process Creating Vulnerabilities? (2026-11-05)
- David Spark, Brett Conlon (CISO, American Century Investments) and Carla Sweeney (SVP InfoSec, Red Ventures) question whether hiring requirements prove ability or just gatekeep entry to the profession.
- They argue that talent is built one way (hands-on experience) but judged another (credentials and multiple-choice-style testing), which limits what exams can show about practical skill.
- A case of a strong candidate being blocked by the process was used to show how rigid hiring can leave teams short-staffed, a security risk in itself. (Based on the episode outline; the notes do not attribute specific remarks.)

## Cloud Security Podcast — Pentesting AWS Security Agent | Richard Fan (2026-11-05)
- Richard Fan bypassed scope controls on AWS's autonomous pentest agent: a private Route 53 zone passed domain verification, then the record was repointed to the real public IP, and the agent tested it without noticing the change.
- Other gaps: the agent followed HTTP redirects to out-of-scope sites (the additional allow list is only an instruction, not enforced), and URL allowlists use plain prefix matching, so "/log" also permits "/login". When tools were restricted, the agent wrote its own scripts to get round them.
- Practical advice: don't run it against production (AWS docs say guardrails may fail), list exact endpoints, and budget for cost (~$50 per hour per task; a one-hour run cost nearly $200). Shared responsibility for a manipulated agent is unclear.

[Episode link](https://www.cloudsecuritypodcast.tv/videos/pentesting-aws-security-agent-richard-fan-aws-security-hero)

## ISACA Podcast — 30 Years of COBIT. One Global Framework. A Lasting Impact on IT Governance. (2026-11-05)
- A panel moderated by Mark Thomas, with Leonard Ong, Gabriela Reynaga Vargas, Sanjay Verma, Greet Volders and Tichaona Zororo, traces COBIT from a set of control objectives to a framework for enterprise governance of information and technology.
- Panelists discuss how organizations in different regions apply COBIT to local regulation while keeping a consistent core, and how it works as a common foundation for aligning with other frameworks.
- Forward look: COBIT's role in digital trust and its relevance as technology and IT environments grow more complex. (Based on the episode description; no transcript was available.)

## Audit, CISO & VAPT angle
Agentic AI is the common thread: AI-driven pentest tooling with weak scope enforcement (Cloud Security Podcast) and AI-key abuse and trojanized AI extensions (Risky Business) are worth raising with audit clients, covering ownership of agent actions, allowlist precision and logging of autonomous tests. For leadership and board discussions, the crypto-exchange breaches and third-party script compromises argue for tighter third-party and hot-wallet-style privileged-asset controls, and the hiring debate is a prompt to review how credentials are weighted in recruitment. For VAPT engagements, edge devices (SD-WAN, firewalls, VPNs) remain the likeliest entry points, and any AI-assisted testing should be scoped explicitly and kept off production. COBIT's 30-year retrospective is a useful anchor for mapping these themes to governance objectives.
